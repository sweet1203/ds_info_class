기계학습은 인공지능 분야의 주요 기술로, 우리의 일상생활과 산업 전반에 큰 영향을 미치고 있어요. 디지털 아트 부문 1위를 차지한 인공지능 그림 「스페이스 오페라 극장」, 글과 그림을 만들어 내는 생성형 인공지능, 스스로 길을 판단하는 자율주행 자동차에도 기계학습이 쓰여요.

오늘은 컴퓨터가 데이터로 스스로 규칙을 찾는 기계학습을 배워요. 직접 규칙을 찾아 예측해 보고, 사람이 규칙을 만드는 전통적인 프로그래밍과 비교한 뒤, 기계학습의 세 가지 유형을 나눠 봐요.

중단원 도입 · 2. 기계학습

기계학습 기반의 인공지능은 데이터와 기계학습 모델을 활용해 문제를 해결해요. 데이터는 학습과 예측에 필요한 정보를 담고 있고, 기계학습 모델은 데이터를 기반으로 패턴을 학습해 효과적으로 문제를 해결해요.

생각해 볼까요? · 미래 혁신의 핵심 기술

기계학습 기술은 인간의 노동력을 절약하고 정확한 분석을 가능하게 해 여러 분야에 혁신적인 변화를 가져왔어요. 인간의 고유 영역이라고 여겼던 예술에서도 인공지능이 창조적인 작품을 만들어 내요.

🎨 인공지능 그림✍️ 생성형 인공지능🚗 자율주행 자동차

기계학습은 이미 성과를 얻은 분야뿐만 아니라 미래에 더 많은 분야에서 변혁을 이끌 핵심 기술이에요.

02

전통적인 프로그래밍과 기계학습의 차이

교과서 178쪽 · 사람이 만든 규칙과 학습된 규칙, 스스로 해결하기

쉽게 말하면전통적인 프로그래밍은 사람이 규칙을 직접 정해 코드로 쓰고, 컴퓨터가 그 규칙으로 정답을 내요. 기계학습은 입력과 정답을 많이 주면 컴퓨터가 규칙을 스스로 배워요.

⚖️ 두 방법 비교 · 스팸 이메일 분류 (그림 Ⅳ-2를 다시 그림)

💻 전통적인 프로그래밍

입력규칙→ 프로그래밍 →정답

입력 이메일의 제목, 내용, 발신자 정보 등
규칙 사람이 미리 정한 단어에 따라 분류 · 「제목에 ‘이벤트’, ‘우승’이 있으면 스팸」
정답 스팸 또는 정상 이메일

🧠 기계학습

입력정답→ 기계학습 →규칙

입력 이메일의 제목, 내용, 발신자 정보 등
정답 이메일마다 스팸인지 아닌지에 대한 레이블
규칙 ‘당첨’, ‘무료’, ‘이벤트’, ‘우승’ 같은 단어가 스팸에 자주 나타나는 현상을 스스로 파악

레이블: 각 입력 데이터에 대해 원하는 출력값(정답) 또는 목푯값이에요.

✉️ 내가 규칙을 만드는 스팸 필터

전통적인 프로그래밍처럼 규칙을 직접 정해 봐요. 「제목에 이 단어가 있으면 스팸」으로 분류할 단어를 쉼표로 나눠 적고, 몇 통을 맞히는지 확인해요. 그다음 새 이메일이 오면 어떻게 되는지 봐요.

전통적인 프로그래밍은 새로운 상황이 생길 때마다 규칙을 바꾸거나 추가해야 해요. 기계학습은 충분한 데이터를 학습해 규칙을 스스로 배우므로 새로운 문제가 생겨도 규칙을 새로 만들 필요가 없어요. 성능을 높이려면 더 많은 데이터를 학습하거나 모델을 개선해요. 그래서 사람이 규칙을 만들기 어려운 복잡한 문제를 효율적으로 해결할 수 있어요.

🧩 스스로 해결하기 · 어떤 방법으로 해결할까?

문제 6개를 읽고 더 알맞은 해결 방법을 골라요. 「사람이 규칙을 분명하게 쓸 수 있을까?」를 먼저 떠올려요.

03

기계학습의 유형은 어떻게 나눌까?

교과서 179쪽 · 지도학습, 비지도학습, 강화 학습, 개념 정리하기

쉽게 말하면기계학습은 학습하는 방식에 따라 세 가지로 나뉘어요. 정답(레이블)과 함께 배우면 지도학습, 레이블 없이 비슷한 것끼리 묶으면 비지도학습, 행동을 해 보고 보상을 받으며 배우면 강화 학습이에요.

🧭 세 가지 유형 살펴보기 (교과서 그림을 새 예로 다시 그림)

🎯 어떤 유형일까?

상황 6개를 읽고 알맞은 기계학습 유형을 골라요. 「데이터에 정답이 붙어 있나?」「행동하고 보상을 받나?」를 살펴봐요.

📝 개념 정리하기

빈칸에 들어갈 말을 먼저 떠올린 뒤 눌러서 확인하세요. 한 번 더 누르면 다시 가려져요.

  1. 지난 10년의 교통량 기록에서 컴퓨터가 스스로 규칙을 찾아 내일 아침 교통량을 예측하는 것은 의 예이다.
  2. ‘정상’, ‘고장’이 적힌 엔진 소리 녹음으로 학습해 새로 녹음한 소리를 판단하는 방식은 이다.
  3. 아무 표시가 없는 손님들의 주문 기록만으로 주문 습관이 비슷한 손님끼리 묶는 방식은 이다.
  4. 드론이 넘어지지 않고 오래 날수록 점수를 받으며 나는 방법을 익히는 방식은 이다.
04

마무리

핵심 문장 · 처음 생각과 비교 · 마무리 퀴즈 · 질문폼

기계학습은 컴퓨터가 데이터를 기반으로 스스로 학습해 규칙을 찾고, 찾아낸 규칙으로 새로운 데이터의 결과를 예측하는 것이다. 사람은 경험으로, 기계학습은 데이터로 예측한다.
전통적인 프로그래밍은 사람이 규칙을 정해 정답을 얻고, 기계학습은 입력과 정답(레이블)으로 규칙을 배운다. 그래서 규칙을 만들기 어려운 복잡한 문제를 효율적으로 해결할 수 있다.
정답이 붙은 예시로 배워 새 데이터를 예측하면 지도학습, 정답 없이 특성이 비슷한 것끼리 묶어 숨은 패턴을 찾으면 비지도학습, 변화하는 환경에서 행동하며 보상이 가장 큰 행동을 익히면 강화 학습이다.
