명령어 실행 순서는 어떻게 바꿀까?

교과서 132쪽 · 제어 구조, 순차 구조, 선택 구조, 반복 구조

쉽게 말하면제어 구조는 컴퓨터에 명령어를 어떤 순서로 실행할지 알려 주는 방법이에요. 차례대로(순차), 골라서(선택), 되풀이해서(반복) — 이 세 가지를 조합하면 어떤 문제든 해결할 수 있어요.

🍳 김치 부침개를 만드는 알고리즘

  1. 오목한 볼에 부침 가루 2컵, 물 1컵을 넣고, 부침 가루가 보이지 않을 때까지 반죽을 젓는다.
  2. 김치 1/4 쪽을 2cm 크기로 잘라서 반죽에 넣는다.
  3. 프라이팬에 식용유 4스푼을 넣고 불을 켜 팬을 달군다.
  4. 달궈진 팬에 반죽을 올려 반죽 앞뒤가 노릇해질 때까지 굽는다.

순서를 지키지 않고 반죽을 프라이팬에 먼저 구운 뒤 김치를 넣는다면 어떻게 될까요?

🧭 제어 구조

제대로 김치 부침개를 만들려면 조리 순서가 중요한 것처럼, 프로그램을 작성할 때도 명령어가 실행되는 순서가 중요해요. 그래서 명령어의 실행 순서를 설계하는데, 컴퓨터에 명령어 실행 순서를 알려 주는 구조를 제어 구조라고 해요.

제어 구조는 일의 순서를 정하는 방법으로, 순차, 선택, 반복의 세 가지가 있어요. 어떤 문제이든 이 세 가지 제어 구조를 조합하여 해결할 수 있어요.

🔀 세 가지 제어 구조 (그림 Ⅲ-9를 다시 그림)

순차 구조

순서대로 차례차례 위에서 아래로 실행하는 구조로, 프로그램 실행 과정의 가장 기본적인 구조예요.

선택 구조

조건이 참(명령 1)이냐 거짓(명령 2)이냐에 따라 명령을 선택하여 실행하는 구조로, if문, if~else문, if~elif~else문 등이 있어요.

반복 구조

조건을 만족하는 동안 명령을 반복하여 실행하는 구조로, for문, while문 등이 있어요.

02

조건에 따라 다른 명령을 실행하려면? ① if문과 if~else문

교과서 133쪽 · 선택 구조, if문, 비교 연산자, if~else문, % 연산자

쉽게 말하면선택 구조는 「만약 ~라면」처럼 조건식이 참인지 거짓인지에 따라 실행할 명령을 고르는 구조예요. 파이썬에서는 들여쓰기로 어떤 명령이 조건에 속하는지 나타내요.

1 if문

선택 구조는 어떤 상황 또는 조건에 따라 서로 다른 선택이나 행동을 해야 할 때 활용하는 구조로, 조건식이 참인지 거짓인지에 따라 일의 순서가 달라져요. if문은 조건이 참이라면 if문 뒤에 오는 명령을 실행하고, 조건이 거짓이라면 실행하지 않고 들여쓰기 없는 명령부터 실행해요.

  • if 뒤에 흐름을 제어할 조건이 오고, 그 뒤에 콜론(:)을 붙여요.
  • if문 뒤의 명령들은 들여쓰기를 해야 하며, if문의 조건이 참일 때 실행돼요.
  • if문에 실행될 명령들은 들여쓰기 위치가 같아야 해요.
  • 들여쓰기를 삭제하면 if문이 끝나요.
비교 연산자설명
==같음
!=같지 않음
>큼(초과)
>=크거나 같음(이상)
<작음(미만)
<=작거나 같음(이하)
==는 좌항과 우항이 같은지 비교하는 연산자, !=는 반대로 좌항과 우항이 다른지 비교하는 연산자예요.
앞에서 배운 =는 값을 저장하는 대입 연산자예요. 같은지 물어볼 때는 등호를 두 번 써요.

🔍 코드 읽고 예측하기 ① 버스 하차 안내

「하차」일 때 문이 열리고 다음 정거장을 알리는 프로그램이에요. y와 n을 각각 골라 예측해 봐요.

2 if~else문

if~else문은 if문의 조건이 참이라면 if문 뒤에 오는 명령(명령1)을 실행하고, 조건이 거짓이라면 else문 뒤에 오는 명령(명령2)을 실행해요.

  • else는 if문 없이 사용할 수 없고, 조건식이 필요하지 않아요.
  • if문의 조건식이 거짓이라면 else에 속한 명령들이 실행돼요.
  • % 연산자는 나눗셈의 나머지를 계산해요. 어떤 숫자의 배수인지 판단할 때 많이 써요. 예) 5의 배수 판단식 n % 5 == 0

🔍 코드 읽고 예측하기 ② 짝수일까, 홀수일까?

짝수인지 홀수인지를 판단하는 프로그램이에요. 숫자를 바꿔 넣으며 두 번 이상 예측해 봐요.

03

조건에 따라 다른 명령을 실행하려면? ② if~elif~else문

교과서 134쪽 · if~elif~else문, end 옵션, 스스로 해결하기(선택 구조 형식)

쉽게 말하면확인할 조건이 여러 개일 때는 elif를 이어 붙여요. 위에서부터 조건을 하나씩 확인하다가 처음으로 참이 되는 곳의 명령만 실행하고 선택 구조를 끝내요. 모두 거짓이면 else의 명령을 실행해요.

3 if~elif~else문

여러 경우의 조건을 확인하고 싶을 때 사용해요. 조건식이 더 많으면 확인하고 싶은 조건의 수만큼 if 뒤에 elif를 추가해요.

  • elif는 else if의 약자로 if문 없이 사용할 수 없고, 이전 조건이 거짓일 때 뒤의 elif의 조건2를 확인해요.
  • 이후 elif는 필요한 조건만큼 추가하여 사용할 수 있어요.
end 옵션 출력된 문자열 끝에 무엇이 올지를 결정해요. print문의 기본값은 '\n'이고, 줄바꿈을 의미해요. 만약 end 옵션을 ''로 수정하면, 다음 출력이 줄바꿈 없이 나와요.

🔍 코드 읽고 예측하기 ③ 양수일까, 음수일까, 0일까?

숫자를 입력받아 양수, 음수, 0을 판단하는 프로그램이에요. 양수·음수·0을 하나씩 넣어 세 번 예측해 봐요. 실행 결과가 왜 한 줄로 나오는지도 살펴봐요.

쉽게 말하면온라인 쇼핑몰은 정기 회원 여부에 따라 배송비를 다르게 받아요. 먼저 입력값에 따라 결과가 어떻게 나와야 하는지 예측하고, 코랩에서 선택 구조로 프로그램을 완성해요.

📦 문제 상황 · 실행 결과 먼저 예측하기

온라인 쇼핑몰에서는 정기 회원 여부에 따라 배송비를 부과하고 있어요.

  1. 회원 여부를 입력받은 후, 총결제 금액을 계산하여 안내하는 프로그램을 완성해요. 정기 회원이면 배송비가 면제되고, 아니면 배송비 3000원이 부과돼요.
  2. 1의 프로그램에 조건을 추가하여 주문 금액에 따라서 배송비를 면제하도록 수정해요. 정기 회원이 아니어도 주문 금액이 50000원 이상이면 배송비가 면제돼요.

2번처럼 수정한 프로그램에 아래 값을 넣으면 총금액이 얼마로 나올까요? 숫자만 적고 「예측 확인」을 눌러요.

마무리

핵심 문장 · 처음 생각과 비교 · 마무리 퀴즈 · 질문폼

제어 구조는 컴퓨터에 명령어 실행 순서를 알려 주는 구조로, 순차·선택·반복의 세 가지가 있다. 어떤 문제이든 이 세 가지를 조합하여 해결할 수 있다.
if문은 조건이 참일 때만 들여쓴 명령을 실행하고, if~else문은 거짓일 때 else의 명령을 실행한다. 조건식에는 ==, !=, >, >=, <, <= 같은 비교 연산자를 쓴다.
if~elif~else문은 여러 조건을 위에서부터 차례로 확인해 처음 참인 곳의 명령을 실행한다. 같은 제어 구조에 속한 명령은 들여쓰기 위치가 같아야 한다.
