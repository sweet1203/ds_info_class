지난 시간에 내려받은 칼로리 데이터로 효율적인 운동 계획을 세우려고 해요. 그런데 파일이 두 개로 나뉘어 있고, 열어 보면 숫자가 1만 5천 줄이나 돼요. 어딘가 비어 있는 칸이나 터무니없는 값이 섞여 있을지도 몰라요. 수집한 데이터 가운데 문제를 해결하는 데 필요한 데이터는 무엇이고, 그것을 어떻게 손봐야 할까요?

01

데이터 전처리는 무엇이고, 어떻게 하는 것일까?

교과서 70쪽 · 데이터 전처리의 뜻과 작업, 데이터 처리 과정

쉽게 말하면요리하기 전에 재료를 씻고, 상한 부분을 떼고, 크기를 맞춰 써는 것처럼, 분석하기 전에 데이터를 쓸 수 있는 모양으로 다듬는 일이 데이터 전처리예요. 여러 데이터 처리 작업 가운데 가장 기초가 되는 단계예요.

🧹 데이터 전처리

원시 데이터를 원하는 형식으로 변환하는 작업
🧽

데이터 정리

데이터에서 오류, 불일치 또는 누락된 데이터를 제거하거나 수정해요. 예: 중복 항목 제거, 맞춤법 오류 수정, 누락된 값 채우기

🔗

데이터 통합

서로 유사하거나 동질성을 가진 데이터를 하나의 데이터로 합해요. 예: 중복되는 데이터 속성값을 통합해 효율성을 높여요.

📐

데이터 정규화

데이터를 분석하기 쉽고 일관성을 유지하도록 공통 척도 또는 일정 범위로 바꿔요. 예: 속성값을 일정한 범위에 속하도록 조정해요.

이 밖에 데이터 크기를 줄이는 데이터 축소, 데이터 형식을 바꾸는 데이터 변환도 데이터 전처리 작업이에요.

🎯 왜 전처리를 할까?

데이터 전처리의 목표는 데이터 분석 또는 기계학습을 준비하는 것이에요. 데이터를 적절하게 전처리하면 데이터 분석이나 기계학습의 정확도와 신뢰도가 높아지고, 데이터의 통찰력이나 경향성을 알아볼 수 있어요.

기계학습 컴퓨터가 데이터를 기반으로 스스로 학습하여 규칙을 찾고, 찾아낸 규칙을 토대로 새로운 데이터의 결과를 예측하는 것. 인공지능 단원에서 자세히 배워요.

02

결측치와 이상치는 어떻게 찾아 고칠까?

교과서 72~73쪽 · 오렌지3를 열기 전에 브라우저에서 먼저 해 보기

쉽게 말하면결측치는 데이터가 빠져서 비어 있는 칸, 이상치는 다른 데이터와 달리 혼자 동떨어진 값이에요. 둘 다 그대로 두면 분석 결과가 엉뚱하게 나올 수 있어서 찾아서 처리해요.
🕳️

결측치

데이터셋에서 일부 데이터가 누락된 빈값이에요. 결측치는 데이터 분석이나 기계학습을 할 때 문제를 일으킬 수 있어서 처리해야 해요.

🎯

이상치

일반적이지 않은 데이터예요. 밥을 많이 먹고 운동을 적게 하면 살이 찔 거라고 예상하지만, 많이 먹고 움직이지 않는데도 마른 사람이 있는 것처럼요. 이상치는 분석 결과를 왜곡할 수 있으므로 제거해요.

x축 습도, y축 태양광 발전량(kW) · 점을 누르면 표에서 그 줄이 강조돼요.

03

「태양광 발전」 데이터는 어떻게 전처리할까?

교과서 71~73쪽 · 오렌지3 실습 ① 결측치 제거 · 이상치 제거

쉽게 말하면02에서 한 일을 이번에는 5만 줄이 넘는 진짜 데이터로 해요. 위젯 이름만 다를 뿐 순서는 같아요. 살펴보기(Feature Statistics) → 결측치 처리(Impute) → 이상치 찾기(Scatter Plot) → 표시하기(Formula) → 남기기(Select Rows).
1 문제 상황 이해하기환경 보호와 지속적인 태양광 발전을 위해 태양광 발전 데이터를 분석해요.
2 데이터 수집하기교과서는 데이콘에서 내려받아요. 우리는 선생님이 알려 주는 폴더의 태양광 발전.xlsx를 써요.
3 데이터 탐색하기불러와 속성과 통계를 살펴요(아래 1~3).
4 데이터 전처리하기결측치와 이상치를 없애요(아래 4~11).

핵심 문장 · 마무리 퀴즈 · 생각 정리 질문폼

수집한 그대로의 데이터를 분석에 쓸 수 있는 모양으로 바꾸는 일이 데이터 전처리이다. 잘못된 것을 고치는 정리, 여러 데이터를 합하는 통합, 값의 범위를 맞추는 정규화 등이 있으며, 잘 전처리할수록 분석과 기계학습의 정확도와 신뢰도가 높아진다.
데이터가 빠져서 비어 있는 값이 결측치, 다른 값들과 동떨어진 값이 이상치이다. 둘 다 그대로 두면 분석을 흐트러뜨리므로 찾아서 처리한다.
데이터는 문제 상황 이해하기 → 데이터 수집하기 → 데이터 탐색하기 → 데이터 전처리하기의 과정으로 처리한다. 오렌지3에서는 Impute로 결측치를, Formula와 Select Rows로 이상치를 처리하며, Merge Data로 두 데이터를 합친다.
