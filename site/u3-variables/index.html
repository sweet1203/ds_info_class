💻 파이썬은 어디에서 실행할까?

교과서는 컴퓨터에 파이썬을 설치해 쓰는 통합 개발 환경(IDLE 등)을 안내해요. 우리 수업에서는 설치하지 않고 웹 브라우저에서 바로 실행하는 구글 코랩을 써요. 학교 구글 계정으로 로그인하면 돼요. 코랩은 04 화면에서 열어요.

🐢 선택 · 집에서 파이썬을 설치했다면 터틀로 그림 그려 보기

터틀(turtle) 그래픽스 모듈을 쓰면 간단한 그림을 그릴 수 있어요. 그림판 창이 열려야 해서 웹 환경인 코랩보다 설치형 파이썬 IDLE를 권장해요. 아래 코드는 사각형을 그려요(교과서 153쪽 선택 활동). 숫자를 바꿔 원하는 모양을 그려 보세요. for 반복문은 뒤에서 배워요.

import turtle   # turtle 모듈 불러오기
t = turtle.Turtle()   # turtle 객체 생성
for i in range(4):
    t.forward(100)   # 앞으로 100픽셀 이동
    t.right(90)   # 오른쪽으로 90도 회전
turtle.done()   # 그림판 유지

01

변수에 값을 저장해요

교과서 119~120쪽 · 변수, 대입 연산자, 변수명 생성 규칙

쉽게 말하면변수는 값을 넣어 두는 이름표 붙은 상자예요. = 기호는 「같다」가 아니라 오른쪽 값을 왼쪽 상자에 넣어라는 뜻이에요.

📦 변수에 저장되어 있는 값은 어떤 종류일까?

변수는 어떤 값을 저장하고 나중에 참조하기 위한 기억 장소로, 데이터를 수정하거나 검색, 조작하는 데 꼭 필요해요. 변수를 쓰려면 기억 장소에 연결된 이름을 붙여 주고 대입 연산자(=)를 사용해서 값을 저장해요.

변수컴퓨터 메모리
…
num15
x사과
y오렌지
…
←
num = 15
x = '사과'
y = '오렌지'
좌변 변수=우변 값

우변에 있는 값이 좌변에 있는 변수에 저장돼요.

대입 연산자(=) 파이썬에서 등호는 「대입 연산자」라 불러요. 「같다」라는 뜻이 아니라 우측의 데이터를 좌측의 변수에 저장하라는 뜻이에요. 예를 들어 x = x + 1은 변수 x에 있는 값에 1을 더한 뒤 다시 변수 x에 저장하라는 뜻이에요.

계산할 때는 +(더하기), -(빼기), *(곱하기), /(나누기) 기호를 써요. 곱하기는 ×가 아니라 *예요.

🔬 코드 읽고 예측하기 ① 변수 상자 따라가기

▶ 버튼을 누를 때마다 코드가 한 줄씩 실행돼요. 오른쪽 변수 표가 어떻게 바뀌는지 보고, 질문이 나오면 먼저 예측해요.

🏷️ 변수 이름은 아무렇게나 지을 수 있을까?

변수명 생성 규칙 (120쪽)
  1. 대소문자를 구별한다.
  2. 숫자로 시작할 수 없다.
  3. 공백과 특수 문자는 사용할 수 없다.
  4. 한글, 영문, 숫자, _(언더바)만 사용한다.
  5. if, while, for 등 파이썬에서 미리 정의된 예약어는 사용할 수 없다.

이름을 하나씩 보고, 변수 이름으로 쓸 수 있는지 골라요.

02

자료형의 종류

교과서 119쪽 · 단일형과 컨테이너형, 표 Ⅲ-1 자료형의 종류

쉽게 말하면값에도 종류가 있어요. 정수인지, 소수점이 있는지, 따옴표로 감싼 글자인지, 참/거짓인지에 따라 자료형이 달라져요. 한 개의 값을 담으면 단일형, 여러 개의 값을 담으면 컨테이너형이에요.

파이썬은 변수에 저장하는 데이터의 형태와 데이터의 양에 따라 여러 가지 자료형으로 구분해 값을 저장해요. 이때 어떤 종류의 데이터가 저장되어 있는지 이해해야 연산을 올바르게 처리할 수 있어요.

한 개의 값을 담는 단일형(literal)에는 정수형(int), 실수형(float), 문자열형(str), 불형(bool) 등이 있고, 여러 개의 값을 담는 컨테이너형(container)에는 리스트(list), 튜플(tuple), 딕셔너리(dictionary), 집합(set) 등이 있어요.

구분자료형표현 방법특징
단일형
(literal)		정수형(int)-100, 0, 100소수점이 없는 정수를 표현한다.
실수형(float)-3.5, 1.246, 100.0소수점이 포함된 실수를 표현한다.
문자열형(str)'hello'("hello"), '정보'("정보")작은따옴표나 큰따옴표로 감싸 표현한다.
불형(bool)True, False‘예/아니요’처럼 참/거짓으로 판단하는 자료를 표현한다.
컨테이너형
(container)		리스트(list)[1, 2, 3, 4, 5], ['김정보', '남', 18, 179.5]대괄호로 묶어서 저장한다.
튜플(tuple)(10,20,30), ('빨강', '주황', '보라')괄호로 묶어서 저장하고 한 번 생성하면 수정할 수 없다.
딕셔너리(dictionary){'사과':'apple', '배':'pear'}{키 : 값}의 쌍으로 이루어지며 순서가 없다.
집합(set){'Python', 'Java', 'C'}순서가 없고 중복된 요소를 저장할 수 없다.

표 Ⅲ-1 자료형의 종류(교과서 119쪽). 컨테이너형은 괄호 모양으로 구별해요 — 대괄호 [ ], 괄호 ( ), 중괄호 안에 키:값 {키:값}, 중괄호 { }. 리스트와 딕셔너리는 「다차원 데이터」에서 자세히 배워요.

🎯 값을 보고 자료형 고르기

값 8개를 하나씩 보고 단일형 네 가지 가운데 알맞은 자료형을 골라요. 따옴표와 소수점을 잘 봐요.

03

자료형을 적합하게 활용하기

교과서 120~121쪽 · type() 함수, 값이 바뀌면 자료형도 바뀌어요, 자료형과 연산

쉽게 말하면파이썬은 값을 보고 자료형을 알아서 정해요. type()으로 확인할 수 있고, 변수에 새 값을 넣으면 자료형도 새 값에 맞게 바뀌어요. 자료형이 다르면 같은 +라도 결과가 달라져요.

🔍 파이썬은 저장되는 데이터에 맞게 자동으로 자료형을 지정해요

type() 함수를 쓰면 변수에 저장된 자료형을 확인할 수 있어요. print() 함수는 화면에 결과를 출력해요.

a = 100
b = 3.1415
c = 'Python'
d = True
print(a, type(a))
print(b, type(b))
print(c, type(c))
print(d, type(d))
100 <class 'int'>
3.1415 <class 'float'>
Python <class 'str'>
True <class 'bool'>
colors = ['빨', '주', '노', '초', '파']
weekday = ('월', '화', '수', '목', '금')
students = {'혜민':'131-9898', '서준':'457-4777'}
print(type(colors), type(weekday), type(students))
<class 'list'> <class 'tuple'> <class 'dict'>

문자열은 좌우만 일치시키면 작은따옴표(' ')와 큰따옴표(" ") 둘 다 쓸 수 있어요.

🔄 변수는 한 번에 한 개의 값만 저장해요

이미 값이 있는 변수에 새로운 값을 저장하면 기존 값은 지워지고 새로운 값이 저장돼요. 이때 자료형도 새로운 자료형으로 바뀌어요.

a = 100
print(a, '을 저장했을 때 a의 자료형', type(a))
a = 'Python'
print(a, '을 저장했을 때 a의 자료형', type(a))
100 을 저장했을 때 a의 자료형 <class 'int'>
Python 을 저장했을 때 a의 자료형 <class 'str'>

05

마무리

핵심 문장 · 처음 생각과 비교 · 마무리 퀴즈 · 질문폼

값에 이름을 붙여 메모리에 넣어 두면 그 이름으로 언제든 다시 꺼내 쓸 수 있다. 이 이름 붙은 자리가 변수이고, =(대입 연산자)는 오른쪽 값을 왼쪽 변수에 넣으라는 명령이다. 새 값을 넣으면 이전 값은 지워진다.
값의 종류를 자료형이라고 한다. 값 하나를 담는 단일형에는 정수형·실수형·문자열형·불형이, 값 여러 개를 담는 컨테이너형에는 리스트·튜플·딕셔너리·집합이 있다.
파이썬은 저장되는 값에 맞게 자료형을 자동으로 지정하고 type()으로 확인할 수 있다. 자료형에 따라 연산 결과가 달라지고, 맞지 않는 자료형끼리 연산하면 TypeError가 생긴다.
