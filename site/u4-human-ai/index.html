경쟁할까, 협력할까?

인공지능은 시간이 흐를수록 계속 발전하고 있어요.
규칙을 하나하나 입력받던 인공지능은 이제 데이터에서 스스로 배우고, 글과 그림까지 만들어요. 그렇다면 인간과 인공지능은 서로 경쟁하는 관계일까요, 아니면 서로 협력하는 관계일까요?

오늘은 인공지능이 발전하면서 인간과 인공지능의 역할이 어떻게 바뀌어 왔는지 살펴보고, 창의성과 혁신 · 의사 결정 지원 · 노동력 분배의 세 측면에서 둘이 어떻게 협력하는지 알아봐요. 마지막으로 지능 에이전트 단원을 정리해요.

01

인간과 인공지능의 역할은 어떻게 변화하고 있을까?

교과서 170~171쪽 · 규칙 기반 인공지능, 데이터 기반 인공지능

쉽게 말하면처음에는 사람이 규칙을 직접 만들어 넣어야 인공지능이 움직였어요. 기계학습과 딥러닝이 나오면서 인공지능이 데이터에서 스스로 배우게 되었고, 사람의 역할은 데이터 준비 · 모델 성능 관리를 거쳐 협력 · 윤리 · 인간 가치를 지키는 일로 바뀌고 있어요.

🕰️ 시기별 인간과 인공지능의 역할 (시기를 눌러 봐요)

🔭 앞으로 인간과 인공지능의 역할은?

초기의 규칙 기반 인공지능에서는 시스템을 설계, 유지, 관리하기 위해 인간이 해야 할 역할의 비중이 매우 컸어요. 데이터 기반 인공지능에서는 인간의 역할이 데이터 준비, 모델 성능 관리 등으로 바뀌었고, 최근 딥러닝과 생성형 인공지능의 등장으로 인간과 인공지능의 협력, 윤리적 문제, 인간 가치의 중요성이 새롭게 논의되고 있어요.

미래의 인공지능은 지금보다 자율성이 커지면서 인간과의 협력과 윤리적 가치가 더욱 강조될 거예요. 인공지능 구현에서 인간의 개입은 점점 줄어들겠지만, 인간은 모든 것의 주체로서 앞으로도 그 역할이 매우 중요해요.

02

인간과 인공지능은 어떻게 협력할까?

교과서 172쪽 · 창의성과 혁신, 의사 결정 지원, 노동력 분배

쉽게 말하면인간은 새로운 아이디어, 최종 결정, 사람 사이의 조율을 잘하고, 인공지능은 많은 데이터의 빠른 분석, 예측, 반복 작업을 잘해요. 서로의 강점을 살려 나누면 더 좋은 결과를 얻을 수 있어요.

🤝 협력의 세 측면

인간과 인공지능의 협력은 공존을 위해 필요하며 다양한 분야에서 인간에게 도움을 줄 수 있어요.

🙋 인간🤖 인공지능
💡 창의성과 혁신인공지능에 비해 창의적인 아이디어를 가지고 있으므로, 인공지능의 도움을 받아 더욱 혁신적인 문제 해결 방안을 도출할 수 있다.인간의 창의력을 보완하고 확장시키는 역할을 해 인간의 창의적인 아이디어 도출과 새로운 기술 개발에 기여한다.
🧭 의사 결정 지원더욱 효과적으로 의사 결정을 할 수 있게 되며, 인간의 주관적 판단과 인공지능의 객관적 분석이 서로 보완하여 작용할 수 있다.대량의 데이터를 빠르게 분석하고 패턴을 찾아내 인간에게 중요한 정보를 제공하고 문제 해결에 활용할 수 있다.
🛠️ 노동력 분배일부 노동 관련 직업이 자동화되어 더 높은 수준의 전문성을 띤 업무에 집중할 수 있게 된다.작업의 자동화와 함께 업무 생산성을 높이고, 반복적이고 단순한 작업을 맡아 인간의 노동 부담과 비용을 줄여 준다.

☀️ 예시 · 태양열 기반의 에너지 시스템 개발 (표 Ⅳ-5)

인공지능이 추천해 준 ‘태양열 기반의 에너지 시스템’을 인간과 인공지능이 함께 연구한다고 해 봐요. 측면을 눌러 각자의 역할을 확인해요.

🚲 누가 맡으면 좋을까? · 우리 동네 공공 자전거 대여소 늘리기

구청이 인공지능과 함께 공공 자전거 대여소를 새로 늘리려고 해요. 각 일을 인간과 인공지능 가운데 누가 맡는 것이 알맞을지 골라요.

03

함께 해결하기 · 인간과 인공지능의 협력

교과서 172~173쪽 · 분석 · 토의

쉽게 말하면기사를 읽고 인간과 인공지능이 일을 어떻게 나누었는지 찾아요. 협력해서 좋았던 점과 걱정되는 점을 모둠에서 토의하고, 다른 협력 사례를 세 측면으로 정리해요.

📰 기사 읽기 · 반도체 공정 개발 개선을 위한 인간과 인공지능의 협력 (교과서 173쪽 기사 요약)

인간과 인공지능이 역할을 나눠 협력한 결과, 반도체 설계를 최적화하면서 비용을 50%나 줄였다는 연구 결과가 과학 저널 『네이처』에 실렸어요.

🙋 인간 엔지니어 · 전반부

뛰어난 직관을 살릴 수 있는 초기 설계 단계를 맡았어요.

🤖 컴퓨터 알고리즘(AI) · 후반부

복잡한 계산력이 필요한 후반 미세 조정 단계를 맡았어요.

이 연구는 인간 엔지니어의 고유한 가치와 독창성은 살리고, 복잡한 공학적 부분은 그 과제에 알맞은 기계(AI)에 맡기면 인간의 가치와 독창성을 최대로 끌어낼 수 있음을 보여 줘요.

📝 개념 정리하기

빈칸에 들어갈 말을 먼저 떠올린 뒤 눌러서 확인하세요. 한 번 더 누르면 다시 가려져요.

  1. 1970년대의 한 진단 프로그램은 의사들이 적어 준 「만약 ~이면 ~이다」 문장들을 차례로 적용해 결론을 냈다. 이런 인공지능을 인공지능이라고 한다.
  2. 스스로 판단하고 행동하는 인공지능이 늘어날수록 사람과 함께 일하는 과, 옳고 그름을 따지는 가 더 중요해진다.
  3. 작곡가가 떠올린 짧은 멜로디를 인공지능이 여러 가지 편곡으로 넓혀 보여 주는 것은 측면의 협력이다.
  4. 날씨와 교통 데이터를 분석한 인공지능의 예측을 참고해 축제 날짜를 사람이 정하는 것은 측면의 협력이다.
  5. 물류 센터에서 로봇이 상자 분류를 맡고 사람은 배송 계획을 세우는 데 집중하는 것은 측면의 협력이다.

✅ 학업 성취도 점검

평가 기준을 읽고, 할 수 있게 된 것을 골라요.

모두 고를 수 있으면 심화, 고르지 못한 것이 있으면 보충 활동을 해 봐요.

보충 · Frozen Lake(얼어붙은 호수) 지능 에이전트가 미끄러운 얼음 위를 건너 목적지에 무사히 도착하는 최적의 경로를 찾는 문제예요. 에이전트가 왼쪽 위(출발)에서 오른쪽 아래(도착)까지 구멍에 빠지지 않고 가는 과정을 관찰해요.

① 직접 건너 보기 화살표를 누르면 한 칸씩 움직여요. 얼음이 미끄러워 생각한 방향으로 가지 않을 때가 있어요.

② 코랩에서 애니메이션 실행하기 교과서 소스 코드를 바탕으로 만든 노트북이에요.

  1. 아래 버튼으로 노트북을 열고, 선생님이 알려 주는 계정으로 로그인해요.
  2. 셀을 위에서부터 차례로 실행해 무작위로 움직이는 에이전트의 애니메이션을 봐요.
  3. 시간이 있으면 「더 해 보기」에서 경험으로 배우는 에이전트와 견주어 봐요.
코랩에서 노트북 열기 ↗노트북 파일 받기

무작위로 움직이는 에이전트에게는 학습과 추론이 없어요. 직접 건너 본 나(또는 잘 건너는 지능 에이전트)라면 단계마다 무엇을 할지 적고, 무작위 에이전트에게 없는 단계도 「없음 — 그래서 ○○」처럼 적어요.

심화 · 로봇 고양이 설계하기 집에서 로봇 고양이를 키운다고 해 봐요. 실제 고양이와 비슷하게 행동하려면 지능 에이전트를 어떻게 설계해야 할까요? 지능 에이전트의 특성(자율성·협력성·목표 지향성)과 효율적인 구현 과정을 바탕으로 설명해요.

05

마무리

핵심 문장 · 학업 계획 점검 · 마무리 퀴즈 · 질문폼

규칙 기반 인공지능 시기에는 인간이 규칙을 만들고 관리하는 역할이 컸고, 데이터 기반 인공지능 시기에는 데이터 준비와 모델 성능 관리로, 지금은 협력 · 윤리적 고려 · 인간 중심의 가치 유지로 인간의 역할이 옮겨 가고 있다.
인간과 인공지능은 창의성과 혁신, 의사 결정 지원, 노동력 분배의 측면에서 서로의 강점을 살려 협력할 수 있다. 최종 결정과 윤리적 검토는 인간이, 대량 데이터 분석과 반복 작업은 인공지능이 잘한다.
인공지능의 자율성이 커져 인간의 개입이 줄어들더라도, 인간은 모든 것의 주체로서 협력하고 윤리적 가치를 지키는 역할이 더욱 중요해진다.
