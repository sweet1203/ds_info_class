2. 기계학습 · 지도학습

지도학습은 입력 데이터와 그에 맞는 레이블을 함께 학습해 새로운 데이터의 예측값을 출력해요. 지난 시간에 배운 지도학습을 오늘은 무엇을 예측하느냐에 따라 두 유형으로 나누고, 각 유형에 쓰는 알고리즘을 살펴봐요.

핵심 질문

배우고 나면 할 수 있는 것

  • 분류 알고리즘과 회귀 알고리즘의 방법을 설명할 수 있다.

01

지도학습의 유형 · 분류와 회귀

교과서 180~181쪽 · 독립 변수와 종속변수, 분류와 회귀, 스스로 해결하기

쉽게 말하면지도학습은 예측하려는 값(종속변수)의 특성에 따라 두 가지로 나뉘어요. 「맑음·흐림·비」처럼 딱 나뉘는 값을 고르면 분류, 「22.5℃」처럼 이어지는 수칫값을 맞히면 회귀예요.

🔤 독립 변수와 종속변수

독립 변수

종속변수에 영향을 주는 변수로, 예측에 사용하는 입력 변수예요.

종속변수(레이블)

예측하려는 변수로, 결과 변수 또는 출력 변수라고도 해요.

🌱 같은 입력, 다른 종속변수 (표 Ⅳ-6·7을 새 데이터로 다시 만듦)

학교 텃밭 식물을 잰 데이터예요. 버튼을 눌러 종속변수를 바꿔 보세요. 독립 변수는 그대로인데 지도학습의 유형이 달라져요.

🧭 분류와 회귀를 이용한 문제 해결 예시

🗂️ 분류 모델

음악의 특성에 따른 장르 분류 · 얼굴 표정에 따른 감정 분류

분류의 목적: 새로운 데이터가 어느 범주에 속하는지 예측

📈 회귀 모델

영화 관람객 수에 따른 팝콘 판매량 예측 · 축구 선수 성적에 따른 연봉 예측

회귀의 목적: 독립 변수들을 기반으로 종속변수의 값을 예측하거나 설명

회귀에서 가장 많이 쓰는 간단한 모델은 선형 회귀예요. 독립 변수 1개로 예측하면 단순 선형 회귀, 2개 이상으로 예측하면 다중 선형 회귀라고 해요.

🎯 스스로 해결하기 · 분류일까, 회귀일까?

문제 6개를 읽고 어디에 해당하는지 골라요. 「예측하려는 값이 딱 나뉘는 범주인가, 이어지는 수칫값인가?」를 살펴봐요.

02

분류 알고리즘 ① k-최근접 이웃

교과서 182쪽 · 거리를 이용한 분류, k값, 정규화

쉽게 말하면k-최근접 이웃(k-NN)은 새로운 데이터와 가장 가까운 k개의 데이터를 찾아, 그중 더 많은 클래스로 분류하는 방법이에요. 「끼리끼리 모인다」를 떠올리면 쉬워요.

📏 k-최근접 이웃의 분류 과정 (그림 Ⅳ-5의 4단계)

1단계

2개의 클래스로 구성된 데이터를 준비해요.

2단계

새로운 데이터가 등장해요. 둘 중 하나로 분류해야 해요.

3단계

새로운 데이터와 모든 데이터의 거리를 재서 짧은 순서대로(오름차순) 정렬해요.

4단계

가까운 k개 가운데 더 많은 클래스로 분류해요. k값에 따라 결과가 바뀔 수 있어요.

🍊 귤일까, 레몬일까? · k-최근접 이웃 체험

무게와 길이를 재고 레이블(귤·레몬)을 붙인 데이터예요. 그래프를 눌러 새로운 데이터(★)를 놓고, k값을 바꿔 가며 어떻게 분류되는지 보세요.

🎯 미션 k = 3일 때와 k = 5일 때 분류 결과가 달라지는 자리를 찾아요. 귤과 레몬 두 무리 사이 경계 근처에 ★를 놓아 보세요. 미션은 정규화한 거리로 판정하고, 찾으면 자동으로 기록돼요.

📌 알아 둘 점

정규화

k-NN은 거리에 민감해서 속성의 범위(scale)가 다르면 모두 0~1 사이의 값으로 조정해야 해요. 각 속성의 최솟값을 0, 최댓값을 1로 맞추는 거예요. 체험에서 「정규화하지 않고 거리 재기」를 켜 보세요.

하이퍼 파라미터

k의 값처럼 사용자가 직접 지정해 줘야 하는 값이에요. k값에 따라 클래스가 바뀌므로 k값을 잘 조절해야 해요.

레이블과 클래스

레이블은 데이터에 대한 정답으로 예측하려는 대상이고, 클래스는 데이터를 분류하는 범주(그룹)예요. k-NN은 분류에 더 많이 쓰이지만 회귀에도 쓸 수 있어요.

03

분류 알고리즘 ② 의사결정트리 · 로지스틱 회귀

교과서 183~184쪽 · 루트 노드와 리프 노드, 로지스틱 함수, 지식 키우기(앙상블, 선택)

쉽게 말하면의사결정트리는 「예/아니요」 질문을 이어 가며 데이터를 나누는 방법이고, 로지스틱 회귀는 S자 곡선으로 0과 1 사이의 값을 구해 두 클래스 중 하나로 나누는 방법이에요.

🌳 의사결정트리 직접 만들기

의사결정트리는 트리 구조로 분류해요. 서로 다른 클래스가 섞인 노드를 속성으로 질문해 나누고, 한 개의 클래스만 남을 때까지 나눠요. 맨 위의 시작점이 루트 노드, 더 이상 나누지 않는 끝 부분이 리프 노드예요.

탈것 6개(자전거·자동차·비행기 클래스)가 섞인 루트 노드에서 시작해요. 섞인 노드마다 질문을 골라 나눠 보세요. 한 번 완성하면 돼요. 다 만들면 옆 친구의 트리와 첫 질문과 질문 수를 비교해 봐요.

사람의 의사 결정 방식과 비슷해서 매우 직관적이고 해석하기 쉬워요. 어떤 속성으로 먼저 나누느냐에 따라 의사결정트리의 성능이 달라질 수 있어요.

〰️ 로지스틱 회귀 · S자 곡선으로 나누기

로지스틱 회귀는 S자 곡선을 그린 결과를 이용해 예측해요. 로지스틱 함수(시그모이드 함수)는 입력값을 0과 1 사이의 출력값으로 바꿔요. 주로 두 클래스 가운데 어디에 속하는지 판별하는 이진 분류에 써요.

과일의 당도(연속적인 입력값)로 「수확 가능(1)」과 「수확 보류(0)」를 나누는 예예요. 막대를 움직여 출력값이 0.5 이상이 되는 곳을 찾아보세요. (교과서 그림 Ⅳ-7의 강아지 털 길이 예를 새 상황으로 바꿈)

🌲🌲🌲 지식 키우기 · 앙상블 (보충·심화 · 시간이 남으면 펼쳐 보기)

앙상블은 여러 모델을 결합해 성능을 높이는 방법이에요. 대표 알고리즘인 랜덤 포레스트는 여러 개의 랜덤한 의사결정트리를 병렬로 연결해 마지막에 다수결 투표로 최종 예측값을 정해요. 여러 전문가의 의견을 모아 결정하는 방식과 비슷해요.

원본 데이터셋→ 랜덤 샘플링(부트스트랩) → 🌳 트리 1결과: 자전거🌳 트리 2결과: 자동차🌳 트리 3결과: 자전거 → 다수결 투표 →최종 결과: 자전거
  • 과적합: 모델이 훈련 데이터에 지나치게 맞춰져 새로운 데이터에 대한 성능이 떨어지는 현상
  • 부트스트랩: 원본 데이터셋에서 중복을 허용해 랜덤하게 샘플을 뽑는 방식 → 각 모델이 특정 훈련 데이터에 지나치게 의존하지 않게 해 과적합을 줄여요.
  • 배깅: 각 의사결정트리의 예측 결과를 종합해 결과를 내는 방식. 의사결정트리가 나무 한 그루라면 랜덤 포레스트는 나무들이 모인 숲이에요.
04

회귀 알고리즘 · 선형 회귀

교과서 185쪽 · 오차에 기반한 학습, 오차를 최소화하는 직선

쉽게 말하면선형 회귀는 데이터 사이를 가장 잘 지나는 직선을 찾는 방법이에요. 「잘 지난다」는 것은 직선으로 예측한 값과 실젯값의 차이(오차)가 가장 작다는 뜻이에요. 그래서 선형 회귀의 목표는 오차를 최소화하는 직선을 찾는 거예요.

📈 직선을 맞춰 봐요 · 기온과 아이스크림 판매량 (그림 Ⅳ-9 (A)·(B)를 새 데이터로)

어느 학교 매점에서 8일 동안 기록한 하루 최고 기온(독립 변수)과 아이스크림 판매량(종속변수)이에요. 막대로 직선의 기울기를 바꾸면 왼쪽의 빨간 점선(오차)과 오른쪽의 오차 그래프가 함께 움직여요. 오차가 가장 작아지는 기울기를 찾아보세요.

❓ 궁금해요 · ‘회귀’라는 이름은 어디서 왔을까?

회귀란 ‘평균으로 돌아간다’는 뜻이에요. 영국의 유전학자 프랜시스 골턴은 부모와 자녀의 키를 연구하며, 두 키는 선형적 관계가 있지만 평균으로 돌아가려는 경향(회귀)이 있다는 것을 알아냈어요. 이 경향이 없다면 키가 작은 부모의 자녀는 계속 작아지고, 키가 큰 부모의 자녀는 계속 커질 수 있겠지요.

  1. 「코랩에서 노트북 열기」를 눌러요(학교 구글 계정으로 로그인).

  3. 마지막 그래프에서 파란 점(데이터)과 빨간 선(학습된 직선)을 확인해요.
  4. 노트북 끝의 스스로 해결하기 빈 셀을 채워요. 더 해 보기도 있어요.

📝 개념 정리하기 (시간이 남으면 · 빈칸을 떠올린 뒤 눌러서 확인)
  1. 새로 들어온 책과 줄거리가 가장 비슷한 책 5권을 찾아, 그중 많은 쪽의 장르로 정하는 방법은 이다.
  2. 「바퀴가 있는가?」, 「날 수 있는가?」처럼 질문을 이어 가며 한 개의 클래스만 남을 때까지 나누는 방법은 이다.
  3. 공부한 시간을 넣으면 0과 1 사이의 값이 나와, 0.5를 넘으면 ‘통과’로 판단하는 S자 곡선 방법은 이다.
  4. 자동차의 주행 거리와 중고 가격 사이를 가장 오차가 작게 지나는 직선을 찾는 방법은 이다.
05

마무리

핵심 문장 · 처음 생각과 비교 · 마무리 퀴즈 · 질문폼

지도학습은 종속변수 값의 특성에 따라 나뉜다. 종속변수가 범주처럼 이산적인 값이면 분류, 온도처럼 연속적인 값이면 회귀이다.
분류 알고리즘에는 새 데이터 주변 이웃 k개의 투표로 정하는 k-최근접 이웃(범위가 다른 속성이 있을 때는 정규화), 예/아니요 질문을 이어 가는 의사결정트리, 0~1 사이 출력값을 기준값 0.5와 비교하는 로지스틱 회귀가 있다. 앙상블은 여러 모델을 결합해 성능을 높인다.
회귀 알고리즘인 선형 회귀는 예측값과 실젯값의 차이(오차)를 줄여 가며, 데이터의 분포를 가장 잘 설명하는 오차가 가장 작은 직선을 찾는다.
