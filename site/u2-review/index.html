데이터 분석가가 되어 보자
여름 휴가철에는 도로, 바다와 계곡, 사람이 붐비는 곳에서 사고가 늘어나요. 교통사고, 물에 빠지는 사고, 아이를 잃어버리는 일, 「설마 괜찮겠지」 하는 안전 불감증까지. 오늘은 모둠이 함께 안전사고 유형 하나를 정하고, 데이터 분석 과정에 따라 해결 계획을 세워 발표를 준비해요.

계획은 문제 → 필요한 데이터와 수집 방법 → 전처리 → 시각화 → 기대 효과 순서로 세워요. 그다음 데이터 마이너의 이야기를 읽고, 발표를 준비한 뒤 Ⅱ단원 전체를 정리해요.

오늘 우리는

모둠별로 여름 휴가철 안전사고 유형 하나를 정하고, 지난 시간까지 배운 빅데이터 수집 · 전처리 · 시각화를 이용해 문제를 해결하는 계획을 세웁니다. 계획을 프로젝트 카드로 정리해 발표를 준비하고, 압축과 암호화의 관점에서 데이터를 어떻게 관리할지도 생각합니다.

01

문제 상황 이해하기

교과서 84쪽 · 프로젝트 1단계

쉽게 말하면먼저 어떤 안전사고를, 왜 줄이고 싶은지 분명히 해요. 문제가 분명해야 어떤 데이터가 필요한지 정할 수 있어요. 같은 사고라도 해결 방법에 따라 필요한 데이터가 달라질 수 있어요.

🔍 해결할 안전사고 유형

📋 문제 해결에 필요한 데이터

언제?

날짜, 요일, 시간대, 날씨처럼 사고가 일어난 때를 알려 주는 속성

어디서?

지역, 장소, 위도·경도처럼 사고가 일어난 곳을 알려 주는 속성

얼마나 · 왜?

사고 건수, 다친 사람 수, 원인처럼 규모와 까닭을 알려 주는 속성

02

데이터 수집 · 전처리 · 시각화 계획

교과서 84~85쪽 · 프로젝트 2~4단계 (68~81쪽 복습)

쉽게 말하면지난 시간까지 한 데이터 처리 과정(문제 상황 이해 → 데이터 수집 → 탐색 → 전처리 → 시각화)을 우리 문제에 적용해요. 칸을 채우면 아래 프로젝트 카드가 저절로 완성돼요. 이 카드가 발표 자료의 뼈대가 돼요.

📥 2. 데이터 수집 및 전처리

공공 데이터 · 민간 데이터 · 웹크롤링 · 직접 수집은 68~69쪽, 결측치 · 이상치 · 데이터 합치기 · 구간 나누기는 72~75쪽에서 배웠어요.

📊 3. 데이터 시각화 · 4. 확인할 사실과 기대 효과

✏️ 시각화 스케치 (선택 · 값을 넣으면 그래프가 그려져요)

🗂️ 우리 모둠 프로젝트 카드 (적은 내용이 바로 나타나요)

03

데이터로 미래를 예측하는 데이터 마이너

교과서 86쪽 · 상상을 현실로 도전하는 사람들

쉽게 말하면광산에서 광물을 캐내는 광부처럼, 수많은 자료에서 의미 있는 정보를 캐내는 사람이 데이터 마이너(data miner)예요. 쇼핑몰 구매 목록, 검색 기록, SNS 데이터 같은 방대한 빅데이터를 분석해 미래에 도움이 될 정보를 만들어요. 카드를 눌러 인터뷰 내용을 확인해 봐요.

04

발표 준비 · 성찰하기 · 평가하기

교과서 85쪽 · 프로젝트 5단계와 평가

쉽게 말하면02에서 완성한 프로젝트 카드를 보며 1분 발표를 준비해요. 카드 순서대로 말하면 듣는 사람이 따라오기 쉬워요. 그리고 우리가 모을 데이터를 압축과 암호화의 관점에서 어떻게 관리할지 생각해요.

🎤 1분 발표: 프로젝트 카드를 보고 말하기

대본을 따로 쓰지 않아요. 아래 카드를 위에서부터 문제 → 수집 → 전처리 → 시각화 → 기대 효과 순서로 짚으며 말해요. 모둠원이 칸을 나눠 맡아도 좋아요.

🔐 5. 성찰하기: 효율적인 데이터 관리 방법

데이터에 기반한 문제 해결 경험을 토대로, 우리 프로젝트의 데이터를 어떻게 관리하면 좋을지 압축과 암호화 관점에서 정리해요.

🗜️ 압축의 관점

사진 · 영상 · 큰 표처럼 용량이 큰 데이터를 저장하고 주고받을 때 저장 공간과 전송 시간을 어떻게 줄일까?

🔒 암호화의 관점

사람의 위치 · 연락처처럼 유출되면 안 되는 데이터를 권한이 있는 사람만 보게 하려면 어떻게 할까?

06

마무리

핵심 문장 · 마무리 퀴즈 · 생각 정리 질문폼

빅데이터로 문제를 해결할 때는 문제 상황 이해 → 데이터 수집 및 전처리 → 시각화 → 분석 및 결과 확인 → 성찰 순서로 한다. 문제에 따라 필요한 데이터와 알맞은 시각화 방법이 달라진다.
데이터 마이너는 방대한 빅데이터에서 의미 있는 정보를 캐내 미래에 도움이 될 정보를 만든다. 통계 · 프로그래밍으로 기르는 수리력과 논리력, 세상을 바라보는 안목이 필요하다.
데이터는 압축으로 효율적으로, 암호화로 안전하게 관리하고, 수집 · 전처리 · 시각화를 거쳐 목적에 맞게 분석한다.
