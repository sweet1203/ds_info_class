01

디지털 사회에서 정보 보안은 왜 필요할까?

교과서 228쪽 · 정보 보안, 가용성 · 무결성 · 기밀성

쉽게 말하면정보 보안은 정보가 만들어지고, 처리되고, 저장되고, 전송되는 모든 과정에서 허락받지 않은 사람이 정보를 보거나 쓰거나 바꾸거나 망가뜨리지 못하게 지키는 방법과 절차예요. 세 가지 원칙이 함께 지켜져야 해요.

🔐 정보 보안이란?

가정, 사회, 산업 등 모든 부문에서 디지털 기술을 많이 쓰면서 허락받지 않은 사용자가 시스템의 취약점을 공격하여 정보를 악용하거나 훼손하는 사례가 늘고 있어요.

정보 보안은 정보의 생성, 처리, 저장, 전송 등의 전 과정에서 허가되지 않은 접근, 사용, 공개, 중단, 수정, 파괴로부터 정보를 안전하게 유지하는 방법과 절차를 의미해요.

가용성

사용자가 필요한 시점에 정보에 접근할 수 있어야 한다.

무결성

허가되지 않거나 우연한 변경으로부터 정보가 보호되어야 한다.

기밀성

허가된 사용자만 정보에 접근할 수 있어야 한다.

네트워크에서나 디지털 기술에 쓰이는 모든 장치에서 가용성, 무결성, 기밀성의 원칙이 지켜질 때 정보 보안이 유지될 수 있어요.

02

정보 보안을 위협하는 것은 무엇일까?

교과서 228쪽 · 해킹, 악성 코드, 위조, 변조, 접근과 유출, 훼손과 파괴

쉽게 말하면시스템 관리자가 아무리 애써도 정보를 노리는 위협은 곳곳에 있어요. 남의 시스템에 몰래 들어가는 해킹, 해를 끼치려고 만든 악성 코드, 정보를 거짓으로 만들거나 바꾸거나 빼내거나 망가뜨리는 행위가 모두 위협이에요.

⚠️ 정보 보안 위협 요소

🕵️ 해킹

  • 악의적인 목적으로 타인의 컴퓨터나 정보 시스템에 무단으로 침입하여 정보를 빼내는 행위이다.
  • 웹 사이트의 취약점을 공격하는 웹 해킹, 운영체제 또는 프로그램을 분석하여 권한을 얻는 시스템 해킹, 네트워크에 있는 취약점을 찾아 공격하는 네트워크 해킹 등이 있다.

🦠 악성 코드

  • 사용자에게 해를 끼치기 위해 만들어진 코드이다.
  • 웹이나 앱을 통해 감염되기 때문에 빠르게 퍼지고, 감염된 시스템은 해킹 같은 피해로 이어진다.
  • 여러 속성이 결합되고 있어 한 가지 유형으로 정의하기 어렵기도 하다.

🎭 위조

거짓 정보를 정확한 정보처럼 보이게 하는 행위

✏️ 변조

원래의 정보를 다른 내용으로 바꾸는 행위

📤 접근과 유출

허락받지 않은 사람이 정보를 확인하거나 외부로 내보내는 행위

💥 훼손과 파괴

정보를 변경하거나 파괴하여 정상적인 작동을 못 하게 하는 행위

🦠 대표적인 악성 코드 (카드를 눌러 뒤집어 봐요)

📱 처음의 스마트폰 다시 보기

내가 찍지 않은 사진, 설치한 적이 없는 앱, 너무 빨리 닳는 배터리. 이제 어떤 위협 요소 때문일 수 있을지 다시 생각해 봐요.

💡 대부분의 악성 코드는 사용자의 정보 기기에 침투해 다른 기기를 공격하는 도구로 활용돼요. 내가 모르는 사이에 내 기기가 공격에 쓰이고 있을 수도 있어요.

정보 보안 기술과 실천 방법은 무엇이 있을까?

교과서 230쪽 · 암호화, 방화벽, 전자 서명, 정보 공급자와 정보 사용자

쉽게 말하면정보를 지키는 대표 기술은 암호화(알아볼 수 없게 바꾸기), 방화벽(밖에서 들어오는 수상한 접근 막기), 전자 서명(인터넷에서 신원 확인하기)이에요. 기술을 알았다면 이제 03의 사례에 연결해 봐요.

🧰 대표적인 정보 보안 기술

🔏

암호화

데이터를 보낼 때 불법적인 방법으로 탈취되거나 변경되는 상황에 대비해 데이터를 변환하여 보내는 방법이에요. 남이 알아볼 수 없는 암호문 형태로 저장하거나 전송하므로 잃어버려도 비밀을 지킬 수 있어요.

Ⅱ단원에서 배운 암호화(교과서 62쪽)를 떠올려요.
🧱

방화벽

네트워크에서 외부의 불법적 침입을 막고 정상 접근만을 허용해 내부의 정보를 보호하는 시스템이에요. 바이러스 같은 위험한 정보는 차단하고, 외부의 접근 시도를 허용할지 판단해 네트워크를 보호해요.

✍️

전자 서명

일상에서 학생증이나 주민 등록증으로 신원을 확인하듯, 인터넷에서도 신원을 확인하거나 안전하게 거래하기 위해 증명서 역할을 하는 것이 필요한데, 이것이 전자 서명이에요.

05

스스로 해결하기 · 정보 보호와 보안 실천 방법

교과서 231쪽 · 분석 · 표현

쉽게 말하면정보를 쓰고, 주고, 관리하는 모든 사람이 실천해야 사회가 안전해요. 정보 공급자는 정보 보안 실천에, 정보 사용자는 정보 보호 실천에 집중해요. 개인 정보의 주체인 우리는 정보의 사용자이면서 공급자이기도 해요.

🤝 정보 공급자와 정보 사용자, 모두 함께

📦 정보 공급자

개인 정보를 포함한 여러 가지 정보를 수집, 저장하여 정보를 가치 있게 활용할 수 있도록 하는 역할을 하는 기관이나 개인

🙋 정보 사용자

정보 공급자가 쌓은 정보를 이용하는 기관이나 개인

누구나 쉽게 접속해 정보를 만들고 나눌 수 있는 인터넷의 특성 때문에, 정보를 악용하려는 사람까지 시스템에 쉽게 접속할 수 있어요. 또 인터넷 서버 운영체제와 인터넷 표준 규약은 소스 코드가 공개되어 있어 해커들이 시스템의 취약점을 찾아 공격하기 쉽고, 해킹 정보도 공유할 수 있어요.

정보를 공급하거나 사용하는 개인과 기관이 정보 보안에 대한 인식이 부족해 대책을 소홀히 세우면, 단 한 명의 부주의로 같은 시스템을 쓰는 사용자 전체가 피해를 입을 수 있어요.

🙋 정보 사용자로서 나의 정보 보호 실천 점수

수칙을 읽고 나의 실천 정도에 별을 눌러요. (아주 잘함 5 · 잘함 4 · 보통 3 · 미흡 2 · 매우 미흡 1)

📦 정보 공급자의 정보 보안 수칙

암호화

전송 중이거나 정지 상태인 데이터를 보호하기 위해 암호화를 사용한다.

사고 대응 계획

정보 보안 침해 사고가 생겼을 때 취해야 할 단계에 대한 계획을 미리 세워 놓는다.

위험 평가

정보 시스템을 이루는 인프라의 잠재적 위험을 평가하여, 이에 대비하는 정보 보안 전략을 세운다.

보안 모니터링

사용자의 의심스러운 활동, 시스템과 네트워크를 항상 모니터링하여 위험이 생겼을 때 빠르게 감지하고 대응하도록 준비한다.

직원 교육

직원들에게 정보 보안과 보안 정책을 교육하여 업무를 할 때 정보 보호를 실천하도록 돕는다.

액세스 제어

개인별로 권한을 주어 정보와 시스템에 대한 접근을 제어하고, 정보를 무분별하게 쓰지 않도록 한다.

🔑 시간 되면 · 강력한 비밀번호 규칙 점검기 (예시 문자열로만)

교과서의 수칙: 계정을 다른 사람이 쉽게 알 수 없도록 세 가지 종류 이상의 문자를 섞은, 강력하고 고유한 여덟 자리 이상의 비밀번호를 만든다.

⚠️ 실제로 쓰는 비밀번호는 절대 넣지 마세요. 입력한 글자는 이 화면에서만 판정하고, 저장하거나 어디로 보내지 않아요. 영문, 숫자, 특수 문자로 넣어 보세요. 이름, 생일, 학번처럼 나와 관련된 정보는 점검기가 알아채지 못하니, 그런 것은 스스로 피해요.

    「고유한」은 다른 사이트에 쓰는 비밀번호와 같지 않다는 뜻이라 점검기가 확인할 수 없어요. 이것은 스스로 지켜야 해요.
