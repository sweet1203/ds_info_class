01

멈출 때까지 계속 · 무한 루프

교과서 142쪽 · 무한 루프, while True, break

쉽게 말하면while 뒤의 조건에 True를 쓰면 조건이 늘 참이라 끝없이 반복해요. 이것이 무한 루프예요. 반복 안에서 원하는 상황이 되면 break로 빠져나와요.

5 무한 루프

반복 횟수를 정하지 않고 반복하고 싶을 때는 while 다음의 조건에 True를 작성해서 무한 루프를 만들 수 있어요. 무한 루프를 그만두기 위해서 break 명령어를 함께 작성해요.

다음은 정답을 맞힐 때까지 반복하여 곱셈 문제를 내는 프로그램이에요. 직접 문제를 풀면서, 매번 어느 줄이 실행되는지 살펴봐요. 일부러 한두 번 틀려 보세요.

02

입력을 나누고 바꾸기 · split() 메소드와 map() 함수

교과서 142~143쪽 · 지식 키우기(split() 메소드와 map() 함수), 스스로 해결하기(폭탄 맵 체험)

쉽게 말하면input()으로 받은 「2 0」은 문자열 하나예요. split()으로 잘라 리스트로 만들고, map(int, …)으로 각 요소를 정수로 바꾸면 x와 y 두 변수에 바로 담을 수 있어요.

📘 지식 키우기 · split() 메소드와 map() 함수

메소드는 클래스에 포함된 함수예요. 함수는 오늘 03 화면에서, 객체와 클래스는 다음 시간(146쪽)에 배워요.

split() 메소드

문자열에 관한 함수로 문자열.split('구분자')와 같은 형식으로 사용해요. 문자열을 구분자를 기준으로 잘라 리스트로 만들어 주는데, 만약 구분자를 생략한다면 공백을 기준으로 잘라요.

['1', '3', '5']

map() 함수

반복 가능 객체의 각 요소들에 특정한 함수를 적용하고 싶을 때 사용해요. map(함수, 반복 가능 객체)와 같은 형식으로 사용해요.

1 3 5

✂️ split()·map() 실험실

입력한 문자열이 단계마다 어떻게 바뀌는지 봐요. 따옴표가 붙은 '2'는 문자열, 따옴표가 없는 2는 정수예요. 「6 8」, 「3,4」, 「1 2 3」, 「a b」도 넣어 보세요.

💣 스스로 해결하기 · 폭탄 맵

6×6 크기의 게임 맵에 폭탄을 놓을 좌표를 입력받아 폭탄이 있는 위치를 ★로 표시하는 프로그램이에요. 먼저 아래에서 알고리즘 설계대로 프로그램이 돌아가는 모습을 보고, 04 화면에서 코랩으로 직접 작성해요.

  1. 0으로 채워진 6 x 6 크기의 2차원 리스트를 만든다.
  2. 폭탄을 놓고 싶은 좌표 x, y를 입력한다. 이때 좌표 x와 좌표 y는 공백으로 구분하여 입력한다.
  3. 입력한 좌표의 범위가 올바른지 확인하고, 범위가 잘못되었다면 다시 입력한다.
  4. 범위가 올바르다면, x, y좌표에 해당하는 리스트의 값을 1로 바꾸어 준다.
  5. 폭탄이 있는 좌표는 ★로, 아무것도 없는 좌표는 □로 출력한다.

폭탄의 개수는 정해져 있지 않으며, 사용자가 폭탄을 그만 입력하고 싶다면 「n」 키를 입력하여 반복을 종료하고 게임 맵을 출력해요. x는 행(위에서 몇째 줄), y는 열(왼쪽에서 몇째 칸)이고 0부터 세요.

직접 작성은 04 화면에서 코랩 노트북 2-1로 해요. 지금 넣어 본 좌표를 기억해 두었다가 그대로 넣어 결과를 비교해요.

4 자주 사용하는 기능을 한 번에 표현할 수 있을까?

프로그램을 작성하다 보면 특정 기능을 반복하여 처리하는 경우가 있어요. 이때 자주 사용하는 기능을 함수로 정의해서 사용할 수 있어요. 함수를 사용하면 함수 안에서 처리되는 명령어를 몰라도 특정 기능을 사용할 수 있는데, 특히 사용자가 직접 작성해서 사용하는 함수를 사용자 정의 함수라고 해요.

1 함수 정의와 함수 호출

  • def는 define의 줄임말로, 함수를 만들 때 함수명 앞에 적어요.
  • 매개 변수는 함수를 호출할 때 넘겨주는 값을 전달받기 위해 사용하는 변수예요. 전달받을 값이 없다면 생략할 수 있고, 여러 개의 값을 전달받는다면 필요한 만큼 매개 변수를 추가할 수 있어요.
  • 반환값은 함수를 처리한 결과를 호출한 쪽으로 되돌려주는 값이에요. 없다면 생략할 수 있어요.
  • 함수명을 호출해서 함수에 정의된 기능을 사용할 수 있어요. 인수는 함수를 호출할 때 넘겨주는 값이에요.

🔍 한 줄씩 따라가기 · 1부터 입력받은 수까지 누적 합을 구하는 함수

1행(def)을 지난 뒤 바로 함수 안으로 들어가는지, 7행에서 호출하면 실행 흐름이 어디로 가는지, return 뒤에 어디로 돌아오는지 봐요. 오른쪽 아래 지역 변수 칸이 언제 생기고 언제 사라지는지도 살펴봐요.

2 지역 변수와 전역 변수

함수를 사용하게 되면 코드를 재사용해서 편리하지만, 만약 변수도 함께 재사용하게 된다면 기억 장소를 독립적으로 사용하지 못하는 문제가 생겨요. 그래서 함수에서만 사용하는 지역 변수와 모든 영역에서 공유하는 전역 변수를 구분하여 사용해요.

전역 변수지역 변수

· 모든 영역에서 자유롭게 값을 불러올 수 있지만, 함수 내부에서 값을 변경할 수 없다.		· 함수 내부에서 선언된 변수
· 선언된 함수 내에서만 사용할 수 있다.
· 함수가 종료되면 메모리에서 제거된다.

Tip · 함수 내부에서 선언된 지역 변수를 함수 밖에서 사용하고 싶다면, global을 붙여 전역 변수로 선언해요. 04 화면의 분식집 프로그램에서 써요.

🔍 한 줄씩 따라가기 · 약수 개수를 합하는 프로그램

10까지의 약수 개수와 20까지의 약수 개수를 합하는 프로그램이에요. n, tot, i는 지역 변수, 9행의 tot은 전역 변수예요. 이름이 같은 두 tot이 각각 어떻게 바뀌는지 봐요. 단계가 많으니 「⏭ 함수 실행을 한 번에」도 써 보세요.

04

함께 해결하기 · 분식집 메뉴 주문

교과서 143·145쪽 · 함수와 중첩 제어 구조, 딕셔너리, global, 코랩 실습(폭탄 맵·분식집), 개념 정리하기

쉽게 말하면메뉴판 보기, 주문하기, 결제하기를 각각 함수로 만들어 두고, 무한 루프 안에서 손님이 고른 번호에 따라 알맞은 함수를 호출해요. 주문 금액 total은 여러 함수가 함께 쓰므로 전역 변수예요.

📋 문제 이해와 분석 · 알고리즘 설계

분식집 메뉴 주문 프로그램을 실행하면 메뉴 보기, 주문하기, 결제하기, 이용 종료 등이 나타나요.

  1. 프로그램을 실행하면 손님이 선택할 동작이 나온다.
  2. 메뉴판 보기를 실행하면 딕셔너리로 저장된 메뉴판이 출력된 후 다시 선택 화면이 나온다.
  3. 주문하기를 실행하면 주문받을 메뉴 이름이 입력되고 총액에 선택한 메뉴 가격이 추가된다.
  4. 반복해서 주문을 받고, 사용자가 주문 끝(n)을 입력하면 다시 선택 화면이 나온다.

📏 기준

  • 딕셔너리로 저장된 메뉴판을 출력합니다.
  • 메뉴를 입력받고 메뉴에 해당하는 금액을 누적한 다음, 총금액을 계산합니다.
  • 결제하기 위해 총 주문 금액을 출력합니다.

메뉴판 딕셔너리: 떡볶이 5000, 라면 3000, 순대 4000, 콜라 1500

무한 루프는 while 다음의 조건에 True를 써서 만들고, 원하는 상황이 되면 break로 빠져나온다. 반복 횟수를 정하지 않고 반복하고 싶을 때 쓴다.
split() 메소드는 문자열을 구분자(생략하면 공백)를 기준으로 잘라 리스트로 만들고, map(함수, 반복 가능 객체)는 각 요소에 함수를 적용한다. x, y = map(int, a.split())처럼 함께 쓴다.
사용자 정의 함수는 def로 정의하고 함수명(인수)으로 호출한다. 매개 변수로 값을 받고 return으로 반환값을 돌려준다. 지역 변수는 함수 안에서만, 전역 변수는 모든 영역에서 쓴다.
