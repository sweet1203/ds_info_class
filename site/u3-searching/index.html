01

탐색 알고리즘과 데이터 구조

교과서 108~109쪽 · 탐색 알고리즘, 선형 데이터 구조와 비선형 데이터 구조

쉽게 말하면데이터가 한 줄로 차례대로 이어져 있으면 선형 데이터 구조, 한 요소가 여러 요소와 이어져 있으면 비선형 데이터 구조예요. 데이터가 어떤 모양으로 저장되어 있는지에 따라 알맞은 탐색 방법이 달라져요.

🔎 탐색 알고리즘이란?

탐색 알고리즘은 주어진 자료에서 특정 요소를 효율적으로 찾기 위한 알고리즘으로, 특정 값, 순회 결과, 최단 경로 등을 찾는 데 쓰여요. 검색 엔진, 데이터베이스, 전자 상거래, 추천 시스템 등 다양한 시스템에서 핵심적으로 활용돼요.

⏱️

시간에 민감한 작업

경로를 이탈한 자동차의 내비게이션은 새 경로를 빠르게 찾아야 해요.

⚙️

효율성

잘 설계된 탐색 알고리즘은 대규모 데이터에서 특정 정보를 빠르고 정확하게 찾아요.

🧱 데이터 구조 · 선형과 비선형

데이터 구조(data structure)는 데이터의 요소 사이에 존재하는 논리적 관계로 구분되며, 데이터의 구성, 접근 방법, 연결 및 처리 방법을 포함해요. 탐색 알고리즘에 쓰는 데이터 구조는 형태에 따라 두 가지로 나뉘어요.

데이터 구조
선형 데이터 구조요소 간 관계가 순서대로 나열되는 1:1 구조 → 리스트 같은 형태에 저장
비선형 데이터 구조한 요소가 여러 요소와 연결되어 계층이나 관계를 표현(1:n, n:n) → 그래프 같은 형태에 저장

카드를 눌러 각 데이터 구조의 특징을 확인해요.

  • 선형 데이터 구조는 각 요소가 순차적으로 인접해서 연결되므로 비선형 데이터 구조에 비해 구현하기 쉬워요. 배열은 특정 요소에 한 번에 직접 접근할 수 있지만, 비선형 데이터 구조는 특정 노드에 한 번에 직접 접근할 수 없어요.
  • 선형 데이터 구조에서는 순차 탐색·이진 탐색, 비선형 데이터 구조에서는 깊이 우선 탐색·너비 우선 탐색 알고리즘을 주로 사용해요.

🔬 스스로 해결하기 · 탐색에 알맞은 데이터 구조 (109쪽, 새 상황으로)

보유 데이터와 탐색 목적을 읽고, 알맞은 데이터 구조를 골라요. 「요소가 한 줄로 이어질까, 여러 요소와 얽혀 있을까?」를 먼저 생각해요.

02

순차 탐색

교과서 110쪽 · 순차 탐색의 수행 과정, 수행 시간, 최선과 최악의 경우

쉽게 말하면리스트의 첫 번째 요소부터 하나씩 차례대로 찾는 값과 비교해요. 간단하고 정렬되어 있지 않아도 쓸 수 있지만, 데이터가 많아질수록 오래 걸려요.

👉 순차 탐색의 수행 과정

선형 데이터 구조에서 특정 요소를 찾을 때 일반적으로 쓰는 알고리즘은 순차 탐색과 이진 탐색이에요. 순차 탐색은 리스트의 첫 번째 요소부터 순차적으로 원하는 요소를 찾는 간단한 탐색 알고리즘이에요. 첫 번째 요소부터 마지막 요소까지 차례로 찾는 값과 비교해요.

0부터 순서를 세는 이유: 파이썬, C 언어 같은 많은 프로그래밍 언어의 배열 인덱스가 0에서 시작하기 때문이에요.

▶️ 체험 · 순차 탐색 한 단계씩 실행하기

처음에는 교과서 110쪽의 리스트가 들어 있어요. 찾는 값을 고르고 다음 요소 검사 ▶를 눌러요. 최선의 경우와 최악의 경우, 그리고 리스트에 없는 값도 찾아보며 비교 횟수를 기록해요.

⏱️ 수행 시간

크기가 n인 리스트에서 특정 요소를 순차 탐색하는 경우의 수행 시간은 O(n)으로, 리스트의 크기가 커질수록 원하는 요소를 찾는 데 걸리는 시간이 선형적으로 늘어나는 단점이 있어요. 단, 리스트는 정렬되어 있지 않아도 상관없어요.

최선의 경우

리스트의 첫 번째 값을 찾는 경우에는 1번의 비교가 이루어지고 탐색이 끝나요.

최악의 경우

리스트의 마지막 요소 또는 리스트에 존재하지 않는 값을 찾는 경우에는 n번의 비교가 이루어지고 탐색이 끝나요.

03

이진 탐색

교과서 111쪽 · 이진 탐색의 수행 과정, mid 선택 방법, 수행 시간

쉽게 말하면정렬된 리스트의 가운데 값부터 확인해요. 찾는 값이 더 작으면 왼쪽 절반, 크면 오른쪽 절반만 남기고 나머지는 지워요. 한 번 비교할 때마다 찾을 범위가 절반으로 줄어요.

✂️ 이진 탐색의 수행 과정

이진 탐색은 정렬된 데이터에서 특정 값을 효율적으로 찾기 위한 알고리즘이에요. 리스트의 중간값을 확인하고, 찾는 값이 중간값보다 작으면 왼쪽 절반을, 크면 오른쪽 절반을 대상으로 다시 탐색하는 과정을 반복해요.

  1. 첫 번째 요소를 low, 마지막 요소를 high로 정해요.
  2. mid 선택 방법 low와 high의 인덱스를 더한 뒤 2로 나눈 몫을 mid로 정해요.
  3. 찾는 값이 mid의 값보다 크면 low를 mid + 1로, 작으면 high를 mid − 1로 바꾸어 범위를 줄여요. 같으면 mid의 위치를 돌려줘요.

▶️ 체험 · 이진 탐색 한 단계씩 실행하기

처음에는 교과서 111쪽의 리스트가 들어 있어요. 회색 ×는 탐색에서 제외된 영역이에요. 아래 메시지를 교과서의 단계와 맞춰 봐요.

📏 체험 · 리스트가 커지면 비교 횟수는?

크기가 n인 정렬된 리스트에서 이진 탐색을 하면 데이터셋의 크기가 커질수록 순차 탐색보다 요소를 찾는 데 걸리는 시간이 훨씬 적어요. 리스트의 요소 개수를 고르면, 컴퓨터가 최악의 경우(리스트에 없는 가장 큰 값을 찾는 경우)를 직접 실행해 비교 횟수를 세요.

이진 탐색은 정렬된 리스트에서 순차 탐색보다 성능이 높은 탐색 알고리즘이에요.

04

순차 탐색과 이진 탐색 비교 · 실생활 사례

교과서 112~114쪽 · 함께 해결하기, 실생활 속 탐색, 지식 키우기

쉽게 말하면순차 탐색은 한 항목씩 검사하고, 이진 탐색은 탐색 범위를 절반씩 줄여 나가요. 데이터가 클수록 이진 탐색이 훨씬 효율적이지만, 이진 탐색은 정렬된 데이터에서만 쓸 수 있어요.

🏁 함께 해결하기 · 이름 리스트에서 두 탐색 겨루기 (112쪽과 같은 방법, 새 이름)

가나다순으로 정렬된 이름 12개의 리스트예요. 찾을 이름을 누르고 한 번씩 비교 ▶를 누르면 두 탐색이 동시에 한 번씩 비교해요. 서로 다른 이름 3개를 찾아 비교 횟수를 기록해요(앞쪽, 가운데, 뒤쪽 이름을 골고루).

🌏 실생활 속 탐색 활용 사례 (113쪽)

순차 탐색은 정렬 여부와 관계없이 쓸 수 있다는 장점이 있지만 데이터가 많아질수록 비효율적일 수 있어요. 이진 탐색은 정렬된 데이터에서 매우 빠른 탐색을 제공하지만 정렬이 먼저 되어 있어야 한다는 단점이 있어요.

📚

도서관에서 책 찾기 · 순차 탐색

책들이 제목이나 저자 이름순으로 정렬되어 있지 않다면, 원하는 책을 찾기 위해 처음 책꽂이부터 한 권씩 확인해야 해요.

📖

사전에서 단어 찾기 · 이진 탐색

사전의 중간을 펼쳐 찾는 단어가 그 쪽보다 앞인지 뒤인지 판단하고, 절반 범위로 줄여 가며 단어를 찾아요.

함께 해결하기 순차 탐색과 이진 탐색이 쓰이는 실생활 사례를 하나씩 찾아 적어요. 위의 두 사례가 아닌 나만의 사례로 찾아보세요.

🔭 선택 또는 시간이 남을 때 · 지식 키우기 비선형 데이터 구조의 그래프 탐색 (114쪽)

그래프 탐색 알고리즘의 대표적인 방법으로 깊이 우선 탐색(DFS)과 너비 우선 탐색(BFS)이 있어요. 아래 새 그래프에서 A부터 두 방법으로 방문해 보세요(이웃이 여럿이면 알파벳 순서로 골라요).

  • 깊이 우선 탐색 시작 정점에서 인접한 정점 하나를 골라 가능한 깊게 탐색하고, 더 갈 곳이 없으면 직전 정점으로 돌아가(백트래킹) 같은 방법으로 탐색해요. 미로가 갈라질 때마다 한쪽을 골라 깊숙이 들어가는 미로 탐색에 쓸 수 있어요.
  • 너비 우선 탐색 다음 레벨로 가기 전에 연결된 인접 정점을 모두 방문해요. 방문할 정점을 추적하려고 선형 데이터 구조인 큐를 이용해요. 웹 페이지의 링크를 차례로 모으는 웹 크롤러에 활용돼요.

함께 해결하기 · 알고리즘 정리

교과서 115~117쪽 · 데이터 정렬·탐색하기, 개념 정리하기, 보충 ○× (맞춤 활동·심화는 선택)

쉽게 말하면정렬된 리스트에서 순차 탐색과 이진 탐색의 비교 횟수를 직접 세어 확인하고, 빈칸과 ○×로 개념을 정리해요. 접혀 있는 활동은 시간이 남을 때나 숙제로 해요.

🔢 함께 해결하기 · 데이터 정렬·탐색하기 (115쪽과 같은 방법, 새 리스트)

공책에 직접 해 보고 칸에 숫자를 적은 뒤 확인을 눌러요. 2번(탐색) 표는 필수, 1번(정렬) 표는 되는 데까지 해요. 버블 정렬·삽입 정렬의 비교·교환 횟수는 정렬 알고리즘에서 배운 방법(교과서 103~104쪽) 그대로 세요.

🧠 개념 정리하기 (새 상황 문장으로)

빈칸(?)을 먼저 머릿속으로 채운 다음, 눌러서 확인해요.

  1. 분실물 보관함에 물건이 몇 개 없고 아무렇게나 놓여 있다면, 하나씩 차례로 확인하는 이 알맞다.
  2. 번호순으로 꽂힌 시험지 묶음에서 가운데를 펼쳐 보고 앞뒤 절반을 골라 나가는 방법은 이다.
  3. 학생 수가 수천 명으로 늘면 명단 맨 앞부터 한 명씩 확인하는 은 시간이 오래 걸린다.

핵심 문장 · 처음 생각과 비교 · 학업 계획 점검 · 마무리 퀴즈 · 질문폼

탐색 알고리즘은 주어진 자료에서 특정 요소를 효율적으로 찾는 알고리즘이다. 선형 데이터 구조(배열, 리스트, 스택, 큐)에서는 순차 탐색·이진 탐색을, 비선형 데이터 구조(그래프, 트리)에서는 깊이 우선·너비 우선 탐색을 주로 쓴다.
순차 탐색은 첫 번째 요소부터 차례로 비교하며 정렬되지 않은 데이터에도 쓸 수 있지만, 수행 시간이 O(n)이라 데이터가 많아질수록 비효율적이다.
이진 탐색은 정렬된 데이터에서 중간값과 비교해 탐색 범위를 절반씩 줄여 나가므로 데이터가 클수록 훨씬 효율적이다. 단, 정렬된 데이터에서만 수행할 수 있다.
