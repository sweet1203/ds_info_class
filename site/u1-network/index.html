‘LOGIN’을 보내려다 ‘LO’에서 멈춘 첫 통신
1969년, 최초의 컴퓨터 통신 테스트에서 ‘LOGIN’이라는 단어를 보내려고 했지만 겨우 ‘L’과 ‘O’ 두 글자를 보내는 데 그쳤어요. 이것이 인터넷의 시초예요. 그 뒤 통신 기술이 끊임없이 발전해서, 지금은 다른 곳에 있는 친구와 가상 공간에서 함께 게임을 하고 여러 명이 동시에 영상 회의도 해요.

오늘은 컴퓨터들이 무엇으로 연결되고, 서로를 어떤 주소로 구분하며, 데이터가 어떤 길로 전송되는지 살펴봐요. 마지막에는 내 기기의 네트워크 구성을 직접 확인해요.

🎒 나의 학습 준비 · 2030 학교 (10~11쪽)

네트워크로 연결된 컴퓨팅 시스템은 다양한 사물에 쓰이면서 사물 인터넷 시스템으로 발전하고 있어요. 2021년 기준 전 세계 사물 인터넷 시스템 수는 100억 개에 달했고, 2025년 이후에는 인터넷에 연결되는 기기가 약 500억 개 이상이 될 것으로 예상해요. 교과서 그림 속 2030 학교에는 강당의 자동 실내 환경 시스템, 교실의 자동 출석 확인 시스템, 도서관의 열람실 현황 시스템, 급식실의 자동 급식 확인 시스템이 있어요.

우리 학교에 가장 먼저 생기면 좋겠는 시스템은? 이 단원 끝의 프로젝트 「미래의 학교 공간을 설계해 볼까?」로 이어져요.

01

네트워크란 무엇일까?

교과서 13쪽 · 16쪽 · 네트워크, IP 주소, 도메인 이름

쉽게 말하면택배가 집 주소를 보고 찾아오듯, 네트워크에서도 기기마다 고유한 주소(IP 주소)가 있어야 데이터를 주고받을 수 있어요. 숫자 주소는 외우기 어려우니 사람은 이름(도메인 이름)을 쓰고, DNS 서버가 이름을 숫자 주소로 바꿔 줘요.

🕸️ 네트워크

초기 컴퓨터는 다른 컴퓨터와 연결되지 않고 독립적으로 쓰였지만, 컴퓨터와 전기 통신 기술이 결합하면서 여러 컴퓨터가 연결되는 컴퓨터 네트워크가 만들어졌어요. 네트워크는 컴퓨터나 다양한 디지털 장치들이 유선 또는 무선 중계기인 라우터와 스위치를 통해 연결되어, 각각 고유의 네트워크 주소로 서로를 구분하고 데이터를 송수신하는 통신망이에요.

🌐

라우터(router)

서로 다른 네트워크를 연결하고, 인터넷 경로상에 가장 효율적인 길을 알려 주는 장치

🔀

스위치(switch)

네트워크 안에서 컴퓨터 장치들을 연결하고, 해당 장치와 패킷을 주고받는 장치

🔢 IP 주소

IP 주소는 통신할 때 송신자와 수신자를 구분하려고 컴퓨터에 부여하는 고유의 주소예요. (프로토콜은 데이터를 주고받으려고 약속한 통신 규약이고, IP는 출발과 도착 주소로 목적지에 데이터를 전송하는 프로토콜이에요. 이때 쓰는 주소가 IP 주소예요.)

1928비트 · 0~255.1688비트 · 0~255.18비트 · 0~255.1308비트 · 0~255

IPv4

32비트 주소 체계. 8비트씩 4개 영역으로 나누고, 그 사이를 마침표(.)로 구분해 십진수로 나타내요. 한 영역은 0~255예요.

예) 192.168.1.130

IPv6

128비트 주소 체계. 16비트씩 8개 영역으로 나누고, 그 사이를 콜론(:)으로 구분해 16진수로 나타내요.

예) 2001:0DB8:0000:0000:0000:0000:1428:57AB

IP 주소로 IPv4를 많이 써 왔지만, 컴퓨팅 시스템이 늘어나 IPv4 주소가 부족해지자 주소 길이를 128비트로 늘려 더 많은 IP 주소를 줄 수 있는 IPv6를 도입했어요.

🏷️ 도메인 이름과 DNS 서버

전화를 걸 때 친구 이름을 고르면 자동으로 전화번호로 연결되지요. 이처럼 인터넷 서비스를 쓸 때는 IP 주소 대신 도메인 이름만 입력해요. DNS 서버가 자동으로 도메인 이름을 IP 주소로 바꿔 주기 때문에 복잡한 IP 주소를 기억하지 않아도 돼요.

💻 컴퓨터도메인 이름 → DNS 서버가 변환 → 지정된 IP 주소 110.165.22.169로 연결

🎯 이 주소는 무엇일까?

주소를 보고 알맞은 종류를 골라요. IPv4는 영역 수와 숫자 범위를 꼭 세어 봐요.

우리 교실은 어떤 네트워크에 속할까?

교과서 14~15쪽 · 서브넷, 유무선 네트워크, 네트워크 종류

쉽게 말하면교실의 컴퓨터·노트북·프린터는 스위치에 모이고, 스위치는 라우터를 거쳐 다른 네트워크와 이어져요. 교실 하나는 큰 네트워크를 잘게 나눈 서브넷이에요. 연결 방법은 선(유선)과 전파(무선)가 있고, 각각 장단점이 달라요.

서브넷(subnet)

IP 주소에서 네트워크 영역을 부분적으로 나눈 부분망(부분 네트워크). 교실은 서브넷에 속하고, 접속 환경에 따라 유선 네트워크와 무선 네트워크로 나뉘어요.

궁금해요! 우리 집 공유기도 라우터일까?

초창기 라우터는 규모가 큰 네트워크 장치였지만, 기술이 발전해 지금의 유무선 공유기인 소형(가정용) 라우터가 나왔어요. 라우팅 기능 없이 무선 공유만 하고 싶다면 유선을 무선으로 바꿔 주는 AP(Access Point)를 쓸 수 있어요.

🔌 유무선 네트워크

초기에는 유선 매체를 주로 썼지만 점점 무선 매체가 늘었어요. 최근에는 사용자 환경에 맞춰 유선과 무선을 결합한 형태가 널리 보급되어 네트워크 효율을 더욱 높이고 있어요.

특징장점단점
유선물리적 통신 매체인 UTP 케이블 또는 광섬유 케이블로 통신· 신뢰도가 높다
· 속도가 빠르다		· 이동이 어렵다
· 모든 컴퓨터를 선으로 직접 연결해야 하므로 회선이 복잡하다
무선같은 무선 주파수를 사용하여 통신· 이동이 자유롭다
· 물리적 연결이 필요 없다
· 많은 사용자가 동시에 이용할 수 있다		· 보안이 취약하다
· 신호 감쇄가 심하다
· 유선에 비해 속도가 느릴 수 있다
· 전송 범위를 벗어나면 연결이 어렵다

유선 매체: UTP 케이블, 광섬유 케이블 · 무선 매체: NFC, RFID, 와이파이, 블루투스

🗺️ 범위에 따른 네트워크 종류

서브넷은 가정이나 학교의 각 반 같은 소규모 네트워크예요. LAN은 가장 많이 쓰이는 서브넷으로, 여러 LAN이 모여 도시 안 네트워크인 MAN을, MAN이 모여 WAN을 이뤄요. 그래서 인터넷에 접속한다는 것은 도시의 범위(MAN)를 넘어 WAN에 접속한다는 뜻이에요.

WAN Wide Area Network · 수십 km 이상, 도시를 벗어난 범위
MAN Metropolitan Area Network · 수 km~수십 km, 도시 안
LAN Local Area Network · 수 m~수 km, 교실이나 회사 건물 안
PAN Personal Area Network · 수 m 정도 (무선 키보드·마우스, 블루투스, 에어드랍)

🎯 유선일까, 무선일까?

특징·장점·단점이나 매체를 보고 유선과 무선 중 어디에 해당하는지 골라요.

03

데이터는 어떻게 전송될까?

교과서 15쪽 · 네트워크 전송 구성도, 패킷

쉽게 말하면큰 사진을 통째로 보내지 않고 작은 조각(패킷)으로 나눠, 조각마다 받는 사람 주소를 붙여 보내요. 조각들은 길이 붐비면 서로 다른 길로 가기도 하고, 도착하면 주소를 떼고 다시 합쳐요.

✈️ 서울에서 보스턴까지 사진 보내기 (그림 Ⅰ-2 · 패킷 전송 예시)

서울의 A가 보스턴 하버드 대학교의 B에게 사진을 보내요. 다음 →을 눌러 한 단계씩 따라가 보세요.

📦 패킷(packet)

네트워크로 전송하기 쉽도록 데이터를 적당한 크기로 자른 최소 전송 단위예요. 데이터는 패킷 단위로 작게 나뉘어 통신 매체의 용량 제한과 네트워크의 혼잡도에 따라 패킷마다 다른 경로로 전송돼요. 각 패킷에는 수신자의 주소와 여러 데이터가 담겨 있고, 서로 다른 경로로 도착한 패킷들은 수신자가 주소를 뺀 데이터를 조합해 원래 데이터로 다시 만들어 읽어요.

04

네트워크 환경은 어떻게 설정할까?

교과서 16~17쪽 · IP 주소, 서브넷 마스크, 게이트웨이, DNS 서버, DHCP

쉽게 말하면네트워크에 들어가려면 기기마다 IP 주소와 DNS 서버 주소 같은 설정값이 필요해요. 하나하나 직접 입력하지 않아도, DHCP(동적 호스트 구성 프로토콜)가 기기가 요청할 때마다 자동으로 나눠 줘요.

🛂 게이트웨이

다른 나라를 여행할 때 출입국 관리소를 지나듯, 내가 속한 네트워크에서 다른 네트워크로 가려면 게이트웨이라는 통신 중계기를 거쳐야 해요. 보통은 라우터가 게이트웨이 기능을 포함하고 있어서, 게이트웨이 주소는 라우터의 주소가 돼요.

🤖 DHCP

각 컴퓨팅 시스템은 IP 주소를 미리 정해 두지 않아요. DHCP 서버가 네트워크에 필요한 IP 주소를 모두 가지고 있다가, 컴퓨팅 시스템이 IP 주소를 요구할 때마다 자동으로 할당해요.

🧪 DHCP 서버가 되어 보기

기기를 우리 반 네트워크에 연결해 보세요. 자동(DHCP)과 직접 입력을 바꿔 가며, 어느 쪽이 편하고 안전한지 비교해 봐요.

⚙️ 운영체제별 설정 화면 (그림 Ⅰ-3~Ⅰ-6 · 화면 설명)

🔒 지금은 읽기만 해요. 학교 컴퓨터에서 편집·수동 입력 버튼은 누르지 않아요.

윈도

설정 → <네트워크 및 인터넷> → 연결된 네트워크의 ‘속성’ → <IP 할당>과 <DNS 서버 할당>이 ‘자동(DHCP)’인지 봐요. 필요하면 편집 버튼으로 수동 입력도 할 수 있어요.

맥 OS

시스템 설정 → 연결된 네트워크 → <세부 사항> → <TCP/IP> 항목의 IPv4 구성이 ‘DHCP 사용’인지 봐요. 필요하면 수동 항목을 골라 직접 입력할 수 있어요.

안드로이드

연결된 Wi-Fi 옆의 설정(⚙) 버튼 → 아래쪽 IP 설정이 ‘DHCP’인지 봐요.

iOS

연결된 Wi-Fi 옆의 정보(ⓘ) 버튼 → <IP 구성>과 <DNS 구성>이 ‘자동’이면 DHCP를 쓰는 거예요.

궁금해요! DHCP는 왜 쓸까? 같은 IP 주소를 쓰려는 두 사용자 사이의 충돌을 막아 주고, 네트워크 범위 안에서 높은 이동성을 보장하며, IP 주소 등을 수동으로 입력하는 번거로움이 없어 네트워크를 효율적으로 관리할 수 있어요.

함께 해결하기 · 내 컴퓨터의 네트워크 구성

교과서 17쪽 · 조사 · 실습

쉽게 말하면지금 쓰는 노트북이나 휴대폰이 어떤 네트워크에, 어떤 주소로 연결되어 있는지 직접 찾아 적어 보는 시간이에요. 앞에서 배운 IP 주소·서브넷 마스크·게이트웨이·DNS 서버가 실제로 어떻게 보이는지 확인해요.
🔒 설정은 바꾸지 않고 「확인만」 해요. 설정 화면의 ‘편집’, ‘수동’ 같은 버튼은 누르지 않아요. 학교 컴퓨터는 관리자 권한이 막혀 있어 화면이 안 열릴 수 있고, 값을 잘못 바꾸면 인터넷이 끊길 수 있어요. 열리지 않는 단계는 건너뛰고, 휴대폰으로 확인해도 괜찮아요.

1️⃣ 내 기기의 네트워크 환경 찾기 (교과서 2번)

확인할 기기를 고르면 찾아가는 길이 나와요. 안 보이는 칸은 비워 둬요. 윈도 설정 화면에는 서브넷 마스크나 게이트웨이가 보이지 않을 수 있어요.

2️⃣ 연결이 잘 되는지 확인하기 (교과서 1번 · 윈도 컴퓨터)

  1. 키보드의 윈도 키를 눌러요.
  2. cmd를 입력해 명령 프롬프트 창을 열어요.

    학교 컴퓨터에서 열리지 않으면 이 단계는 건너뛰어요.

  3. ping IP 주소 또는 ping 도메인 이름을 입력해요.

    · 1️⃣에서 찾은 게이트웨이 주소로 ping을 보내면, 내 기기와 라우터 사이, 곧 같은 네트워크 안의 연결이 되는지 확인할 수 있어요.
    · 선생님이 알려 주는 도메인 이름으로 보내면 인터넷 너머까지 닿는지 볼 수 있어요.
    · 응답이 몇 번 돌아왔는지, 시간이 얼마나 걸렸는지 봐요.

    학교 네트워크는 ping을 막아 두기도 해요. 그러면 인터넷이 되는데도 「요청 시간이 만료되었습니다」(요청 시간 초과)가 나올 수 있어요.

📝 주요 개념 정리하기

빈칸에 들어갈 말을 먼저 떠올린 뒤 눌러서 확인하세요. 한 번 더 누르면 다시 가려져요.

  1. 옆 학교로 가는 길이 여러 갈래일 때, 그 가운데 가장 효율적인 길을 알려 주며 서로 다른 네트워크를 이어 주는 장치는 다.
  2. 주소 창에 학교 누리집 이름을 치면 DNS 서버가 그 이름에 연결된 숫자 주소를 찾아 준다. 이때 내가 친 이름은 , DNS 서버가 찾아 준 숫자 주소는 다.
  3. 2학년 3반 교실의 컴퓨터들은 IP 주소의 앞부분(네트워크 주소)이 서로 같다. 이렇게 큰 네트워크를 부분적으로 나눈 한 구역을 이라고 한다.
  4. 교실에 새 노트북을 켜기만 해도 IP 주소와 DNS 서버 주소가 저절로 정해지는 것은 덕분이다.

핵심 문장 · 마무리 퀴즈 · 생각 정리 질문폼

네트워크는 여러 디지털 장치가 라우터와 스위치로 연결되어 고유의 주소(IP 주소)로 서로를 구분하고 데이터를 주고받는 통신망이다. 사람은 도메인 이름을 쓰고, DNS 서버가 IP 주소로 바꿔 준다.
교실은 서브넷에 속하며 유선(신뢰도·속도)과 무선(이동성·동시 이용)이 섞여 쓰인다. LAN이 모여 MAN, MAN이 모여 WAN을 이루고, 데이터는 패킷으로 나뉘어 여러 경로로 전송된 뒤 다시 합쳐진다.
네트워크 환경 설정에는 IP 주소·서브넷 마스크·게이트웨이·DNS 서버가 필요하고, DHCP가 이를 자동으로 할당해 충돌을 막고 관리를 편하게 한다.
