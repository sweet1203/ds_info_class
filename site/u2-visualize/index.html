같은 칼로리 데이터를 본 두 친구
칼로리 데이터를 앞에 두고 한 친구는 성별에 따라 키가 어떻게 다른지를, 다른 친구는 운동 시간과 소모한 열량을 함께 살펴봤어요. 두 친구가 들려주는 이야기는 서로 달랐어요. 같은 데이터에서 왜 서로 다른 것을 보게 되었을까요?

오늘은 데이터를 그래픽으로 표현하는 방법을 알아보고, 오렌지3로 칼로리 데이터와 윤동주의 시를 직접 시각화해요. 그다음 빅데이터 단원을 정리해요.

  3. 정형 데이터의 시각화
  4. 비정형 데이터 · 워드 클라우드 (필수 실습 ②)
  5. 빅데이터 정리
  6. 마무리 · 질문폼

01

데이터 시각화는 무엇이고 어떤 방법이 있을까?

교과서 76쪽

쉽게 말하면숫자가 잔뜩 적힌 표는 한눈에 들어오지 않아요. 숫자를 그림(그래픽)으로 바꾸면 의미가 바로 보이고, 표에서는 몰랐던 숨은 정보도 찾을 수 있어요. 다만 어떤 그림으로 바꾸느냐에 따라 보이는 것이 달라요.

📌 데이터 시각화

수치나 통계 데이터를 그래픽으로 표현하여 분석 결과를 직관적으로 이해하기 쉽게 만드는 기술

일상생활에서 생기는 수많은 데이터는 그 자체만으로는 전체를 파악하기 어려운 경우가 많아요. 시각화하면 그 의미를 쉽게 파악할 수 있고 숨어 있는 정보도 쉽게 찾을 수 있어요. 그래서 시각화는 데이터 분석 분야에서 매우 중요한 역할을 해요.

박스 플롯

데이터의 특징을 파악할 수 있는 통계 분포와 이상치를 시각화

히스토그램 · 분포도

수치형 변수를 구간으로 나누어 각 구간에 속하는 데이터의 분포를 시각화

산점도

수치형인 두 개의 변수 간의 관계를 시각화

차트

막대그래프, 선그래프, 원그래프와 같이 데이터의 수치, 비율 등을 시각화

🧪 그래프 고르기 실험실 (연습용 가상 데이터)

미션을 하나 고르고, 아래 버튼으로 같은 데이터를 여러 그래프로 바꿔 보세요. 메시지가 가장 잘 보이는 그래프를 찾으면 「이 그래프로 전할래요」를 눌러요. 미션 다섯 개 중 두 개 이상 해 봐요(시간이 되면 더).

🔎 선택 · 시각화 체험: 검색어 두 개 비교하기 (교과서 76쪽 스스로 해결하기)
  1. 선생님이 알려 주는 검색어 트렌드 사이트(온라인 데이터랩)에 들어가요.
  2. 관심 있는 두 개의 키워드를 검색어에 입력해요. 예: 「줄넘기」와 「마스크」처럼 계절에 따라 달라질 것 같은 낱말
  3. 기간을 최근 4년으로 정하고 두 그래프를 비교해요. 언제 오르고 언제 내리나요?
02

데이터를 시각화하는 방법으로 무엇이 있을까?

교과서 77~78쪽 · 필수 실습 ① 칼로리 데이터

쉽게 말하면두 파일을 합치고(Merge Data) 나이를 세 구간으로 나눈(Discretize) 칼로리 데이터를 써요. 지난 시간에 만들었으면 열기만 하고, 아니면 아래 「나」 순서로 5분 안에 만들어요. 오늘은 여기에 Visualize 카테고리의 위젯을 붙여서 박스 플롯과 산점도로 그려 봐요.

🍊 준비: 칼로리 데이터 흐름 만들기

가. 「칼로리 전처리」 파일을 저장해 두었다면

  1. 오렌지3에서 File → Open으로 지난 시간에 저장한 「칼로리 전처리」 워크플로(.ows)를 열어요.
  2. 아래 흐름도의 회색 위젯(calories · exercise · Merge Data · Discretize)이 있으면 준비 끝이에요.

나. 파일이 없거나 지난 시간 칼로리 실습을 하지 않았다면 (5분)

  1. 내려받은 calories.csv와 exercise.csv를 File 위젯 2개로 각각 불러오고, F2 키로 이름을 calories · exercise로 바꿔요.
  2. Transform 카테고리의 Merge Data에 두 File 위젯을 연결해요(calories → Data, exercise → Extra Data). Merge Data를 더블 클릭해 짝을 User_ID ↔ User_ID로 바꿔요(처음에는 Row index로 맞춰져 있어요).
  3. Discretize를 Merge Data에 연결하고, Age를 고른 뒤 Natural binning, desired bins를 3으로 정해요.

03

정형 데이터의 시각화는 어떻게 할까?

교과서 79쪽

쉽게 말하면칼로리 데이터처럼 행과 열이 정해진 표로 정리된 데이터가 정형 데이터예요. 숫자뿐 아니라 이름·날짜·위도와 경도 같은 정보도 들어 있어서, 정보의 특성에 맞게 그래프나 지도로 시각화해요.

📋 정형 데이터

일정한 형식을 갖춘 데이터로 수치, 문자, 날짜, 지리 정보 등을 포함해요.
수치키, 열량, 운동 시간
문자성별, 학교명, 주소

정보의 특성에 맞게 시각화하는 것도 데이터 분석의 중요한 부분이에요. 예를 들어 위도·경도는 오렌지3의 Geo Map 위젯으로 지도 위의 점이 되고, 날짜는 시간의 흐름으로 보여 줄 수 있어요.

먼저 확인: 오렌지3 위젯 목록에 Geo와 Time series 카테고리가 보여야 해요. 보이지 않으면 추가 기능(Options → Add-ons…)을 설치하고 오렌지3를 다시 시작해야 하므로, 선생님께 먼저 여쭤봐요. 지도 바탕 그림은 인터넷으로 불러와요.
  1. 선생님이 알려 주는 폴더에서 전국 초중등학교 위치 표준 데이터(.csv)를 내려받아 File 위젯으로 불러와요. 위도와 경도가 numeric으로 되어 있는지 확인해요.
  2. File에 Scatter Plot을 연결해 점들이 이루는 모양을 봐요.
  3. Geo 카테고리의 Geo Map을 연결하고 아래 표처럼 정해 우리나라 지도 위의 학교급별 위치를 봐요.
  4. Time series 카테고리의 Time Slice를 File에 연결하고, Time Slice에 Geo Map을 하나 더 연결해요(설정은 위 Geo Map과 같게: 위도 · 경도 · 학교급구분). Custom step size를 1 year로 정하고 ▶ 재생 버튼을 눌러 시간의 흐름에 따라 세워진 학교를 봐요.

텍스트에서 단어가 나온 횟수(빈도수)를 글자 크기로 나타내요. 글자가 클수록 빈도수가 높은 단어예요. 주요 키워드를 알려 주고, 불용어(분석에 필요 없는 말)를 빼기 쉽고, 시각적 표현으로 이해를 도와요.

🧪 필수 실습 ② 윤동주의 시를 워드 클라우드로

  1. Text Mining 카테고리의 Corpus 위젯을 불러와요.
  2. Corpus에서 내려받은 윤동주 시.csv를 불러오고, 언어(Language)를 Korean으로 정해요.
  3. Corpus에 Corpus Viewer를 연결해 시 데이터를 살펴봐요.
  4. Corpus에 Preprocess Text를 연결해요. 정렬하거나 불필요한 문자를 지우는 데이터 전처리를 하는 위젯이에요.
  5. Preprocess Text에 Word Cloud를 연결해 시각화해요.

Text Mining 카테고리가 보이지 않으면 추가 기능 Text가 설치되지 않은 거예요. 선생님께 알려 주세요.

위젯설정
Corpus파일: 윤동주 시.csv · Language: Korean · Used text features: content

은하 이미지

  1. 선생님이 알려 주는 폴더에서 은하 이미지 폴더(안에 은하 종류별 폴더 3개)를 내려받아요.
  2. Image Analytics의 Import Images로 은하 이미지 폴더를 정해요.
  3. Image Viewer를 연결해 이미지 데이터를 그대로 확인해요.

FIFA 2023 데이터

  1. File로 선생님이 알려 주는 FIFA 2023 데이터(.csv)를 불러와요.
  2. Visualize의 Distributions를 연결하고 변수를 선수 가치(Value(£))로 정해요.
  3. Distributions에 Image Viewer를 연결하고, 선수 가치가 1억 파운드 이상인 막대를 눌러 골라요. 몇 명인지 아래쪽 숫자로 확인해요.
  4. Image Viewer에서 이미지 속성을 Photo로 정해요. 선수 사진은 인터넷으로 불러와요.

    보충 · 데이터 분석과 시각화의 관계

    데이터 분석은 복잡한 데이터를 수집·가공·분석해 의미 있는 정보를 끌어내는 과정이고, 시각화는 데이터를 차트·그래프·지도 같은 시각적 요소로 표현하는 것이에요. 두 가지는 어떤 관계일까요?

    심화 · 사회적·윤리적 가치를 생각해야 하는 시각화

    내 경험을 떠올려, 사회적·윤리적 가치를 고려해야 하는 빅데이터 시각화 사례를 찾아 친구와 의견을 나눠 봐요.

    마무리

    핵심 문장 · 학업 계획 점검 · 마무리 퀴즈 · 생각 정리 질문폼

    데이터 시각화는 숫자를 그래픽으로 바꿔 의미와 숨은 정보를 쉽게 보게 해 준다. 박스 플롯 · 히스토그램(분포도) · 산점도 · 차트(막대 · 선 · 원) 가운데 전하려는 메시지에 맞는 방법을 골라야 한다.
    같은 칼로리 데이터도 박스 플롯으로는 성별에 따른 통곗값을, 산점도와 회귀선으로는 운동 시간과 열량 소모의 관계를 볼 수 있다. 어떤 방법으로 보느냐에 따라 해석이 달라질 수 있다.
    정형 데이터는 수치 · 문자 · 날짜 · 지리 정보의 특성에 맞게 그래프나 지도로, 비정형 데이터는 이미지를 그대로 모아 보거나 텍스트를 워드 클라우드로 시각화한다.
