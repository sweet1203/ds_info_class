쓰기 메모 7칸 + 투표 1 + 칩 3개. 퀴즈 13문항(정답 위치 ①5 ②4 ③4). 질문폼 1번 ← 01 사례 카드·03 분류, 2번 ← 02 투표·근거 메모, 3번 ← 04 분야 조사·대처 메모.

**50분 흐름** — 도입(3분) 가족의 아침 이야기, 내 하루의 사물 인터넷 적기 → 01(8분) 세 가지 변화 카드를 읽고 사례 카드 뒤집기 → **02(11분 무렵 시작, 8분)** 장단점 비교, 투표, 근거 메모 → **03(19분 무렵 시작, 9분)** 스마트 시티·스마트팜, 분류 게임 → **04(28분 무렵 시작, 13분)** 모둠별 분야 고르기, 변화·영향·대처 메모, 빈칸·성취도 → 마무리(8분) 핵심 질문 답, 퀴즈, 질문폼. 질문폼 근거 활동은 모두 30분 안에 시작.

**줄인 것** — 31·32쪽 그림은 옮기지 않고 사례 문장만 카드·격자로 새로 정리. 33쪽 함께 해결하기의 「조사」는 수업 중 인터넷 검색 대신 모둠 토의와 생각할 거리 안내로 시작하게 함(검색은 선생님 재량). 스마트 시티 8가지 서비스는 분류 게임에 4가지만 사용.

**확인할 점**
- 교과서는 단점을 「극복할 기술 개발이 계속 이루어져야 한다」고만 하고 구체적 기술 이름을 들지 않는다. 교과서에 없는 기술 용어(암호화·인증 등)는 가르치지 않고, 학생이 스스로 방법을 제안하는 메모 칸으로 처리했다. 1단원 14쪽 「무선 매체는 보안이 취약하다」만 연결해 둠.
- 31쪽 「스마트폰 앱: 버스 도착 시간 확인」(개인)과 32쪽 「버스 도착 알림 서비스」(스마트 시티)가 같은 소재로 겹쳐 개인/사회 분류가 애매하다. 분류 게임에서는 이 사례를 빼고, 카드와 격자에서만 각각 보여 줌.
- 30쪽 학습 목표는 「변화를 평가」, 33쪽 성취도 평가는 「변화를 예측」으로 동사가 다르다. 화면에는 둘 다 그대로 둠(학습 목표 = 시작 화면, 성취도 평가 = 04).
- 장점은 교과서가 따로 목록을 만들지 않았다. 30쪽 본문 문장(편리함, 문제 해결, 안전한 주거, 의료 서비스, 맞춤형 콘텐츠)에서 뽑아 정리함.
- 04의 「우리가 갖추어야 할 태도」 칩 가운데 「개인 정보를 지키며 사용하기」는 33쪽 문장이 아니라 31쪽 단점(신체 정보 센서 노출 → 개인 정보 유출·사생활 침해)에서 이끌어 낸 선택지로, 1차 검토에서 유지하기로 함.

**검토 반영(1차)** — 개념 빈칸 2개를 새 문장 틀로 바꿈. 퀴즈 5-1 오답 「도시와 농촌의 경계가 뚜렷해짐」을 「농촌의 작업 효율이 낮아짐」으로(4-2 해설이 지우던 단서 해소). 04 분야 생각거리를 분야마다 2줄로 늘림. 환경은 32쪽 스마트 환경 모니터링·수질·폐기물과 26쪽 가스·토양 수분 센서, 교육은 26쪽 인체 감지·조도·온습도 센서와 41쪽 선택 활동의 스마트 교실 예·30쪽 맞춤형 콘텐츠, 예술은 26쪽 비콘·30쪽 맞춤형 콘텐츠·31쪽 스마트 안경으로, 교과서에 없는 사례는 사실처럼 쓰지 않고 질문으로만 둠. 사례 카드 뒷면 글(스마트 냉장고·스마트 팔찌)을 줄였고, 1366·1280px에서 14장 모두 넘침 없음을 확인함.

**검토 반영(2차)** — 퀴즈 1-2·1-3 줄기에서 정답 낱말(냉장고·신발)을 뺌. 퀴즈 3-1 오답 「농장의 생육 환경을 자동으로 제어한다」와 해설의 스마트팜 구절이 3-3의 단서가 되어 오답을 「사람이 직접 도시 곳곳을 돌며 점검한다」로 바꾸고 해설에서 뺌. 퀴즈 5-1 오답을 짧은→긴 순서로. 분류 카드 「농장의 온습도…」를 「작물이 자라는 비닐하우스의 온습도…」로, 자동 급수 카드에 작물·물과 비료를 줄 시기를 넣음. 교육 분야 생각거리에서 쪽 표기(41쪽)를 뺌.
