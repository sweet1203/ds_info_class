퀴즈 16문항(정답 위치 ①5 ②6 ③5).

**선생님 운영 메모** — 01에서 시간이 밀리면 분류 게임만 하고 01 퀴즈는 마무리 화면 앞에서 풀게 해요(결과표에 화면별로 남음). 05는 ①·② 흐름을 25분 무렵 시작하는 것이 목표라, 02·03 미션이 길어지는 모둠은 미션 A·스키테일을 건너뛰어도 돼요. 06은 2번과 개념 빈칸을 먼저 해요. 질문폼(info-u2-encryption) 1번 ← 02·03 카이사르·전치 미션(`caesarKey`·`caesarLimit`·`transDone`·`scyKey`·`transLimit`), 2번 ← 04 해시 실험실(`hashTry`·`hashWhy`), 3번 ← 05 키 흐름·비교 표(`keyFlow`·`cmp…`).

**성취도 평가 맞추기** — 59쪽(치환형) → 02 끝, 60쪽(전치형) → 03 끝, 61쪽(단방향) → 04 끝, 62쪽(대칭 이유·안전성)·63쪽(비대칭 중요성·필요성) → 05 끝에 「✅ 성취도 평가」 칩. 64쪽 학업 성취도 점검 3기준은 06에서 보충/심화 고르기로 이어짐.

**50분 흐름** — 도입(2분) 지난 시간·처음 생각 → 01(4분) 원리 그림·용어, 분류 게임 6장 → **02(6분 무렵 시작, 6분)** 원판 익히기 → 미션 A·B → **03(12분 무렵 시작, 7분)** 예제 1 불러오기로 원리 확인 → 미션 해독 → 스키테일 굵기 찾기 → **04(19분 무렵 시작, 6분)** 고친 메시지의 해시값 비교·기록, 비밀번호 흉내 → **05(25분 무렵 시작, 9분)** 꼭 할 흐름 ①·② 따라가기(각 2~3분), 비교 표, ③ 전자 서명은 선택 → 06(9분) 「시간이 되는 만큼」: 2번(암호화하고 압축하기)과 개념 빈칸 먼저, 지식·가치 메모와 선택 활동은 남는 만큼 → 마무리(6분) 핵심 질문·퀴즈·질문폼. 질문폼 근거 체험(02~05)은 모두 25분 무렵까지 시작.

**줄인 것** — 58쪽·63쪽 만화는 줄글·키 흐름 체험으로 대신. 59쪽 스스로 해결하기의 교과서 암호문(1·2번)과 60쪽 스스로 해결하기의 암호문(HYUN … CHU, 스키테일 한글 띠), 61쪽 해시 예시 문장은 쓰지 않고 새 문장으로 바꿈(공개 저장소에 교과서 답이 드러나지 않게). 61쪽 외부 해시 실습 웹 사이트는 주소를 쓰지 않고 페이지 안 SHA-256 계산으로 대신(결과는 같은 SHA-256, 교과서 예 「이 글은 원본입니다.」로 넣으면 교과서와 같은 값이 나오는 것을 개발 중 확인). 62쪽 OTP·보안 카드 그림은 설명 글로만. 62쪽 한컴오피스 실습은 학교 노트북 설치 여부를 몰라 「선택」으로 접어 둠. 64쪽 맞춤 활동 2번은 같은 구조의 새 문제로, 65쪽 보충 활동의 교과서 예(버디의 규칙)는 옮기지 않음. 63쪽 개념 정리하기는 새 상황 문장 빈칸으로.

**선생님 준비물** — 없음(외부 사이트·파일 없이 화면 안에서 모두 체험). 한컴오피스 실습(선택)을 하려면 학교 노트북에 한컴오피스가 있는지 확인.

**확인할 점**
- 63쪽 개념 정리하기 첫 문장 「**암호문을** 변환하는 과정을 ___, 해독하는 과정을 ___」 → 58쪽 정의대로라면 「**평문을 암호문으로** 변환하는 과정을 (암호화)」여야 함. 화면의 빈칸 문장은 새로 써서 해당 없음.
- 63쪽 그림 <기밀성 유지> 말풍선 「A의 공개키로 암호화된 것은 A의 **비밀키**로만 풀 수 있어」 → 62쪽에서 「비밀키」는 대칭 암호화의 공유 키 이름이므로, 비대칭에서는 「**개인키**」가 맞음. 화면에는 개인키로 씀.
- 63쪽 「송신자는 개인키(또는 공개키)로 암호화를 하고, 수신자는 개인키와 쌍을 이루는 공개키(또는 개인키)로 복호화」 — 문장이 헷갈리기 쉬워 화면에는 「한쪽이 개인키(또는 공개키)로 암호화하면 다른 쪽은 쌍을 이루는 공개키(또는 개인키)로 복호화」로 풀어 쓰고, 키 흐름 체험에서 기밀성 유지(받는 사람의 공개키 → 받는 사람의 개인키)와 전자 서명(보내는 사람의 개인키 → 보내는 사람의 공개키)을 나누어 보여 줌.
- 58쪽 암호화가 두 뜻으로 쓰임: 「정보를 읽기 어려운 형태로 바꾸거나 반대로 다시 읽을 수 있게 해독하는 기술」(넓은 뜻)과 「평문을 암호문으로 변환하는 과정」(좁은 뜻). 화면에는 두 문장을 모두 교과서대로 두고, 그림·퀴즈는 좁은 뜻(평문 → 암호문)으로 씀.
- 61쪽 단방향 암호화 사례로 든 QR코드 전자 출입 명부는 「서버가 사용자의 정보를 포함한 암호문으로 QR코드를 생성」한다고 설명해 서버가 다시 읽는(복호화하는) 것처럼 보임. 단방향의 「복호화 불가능」과 맞지 않아 보이지만 교과서 서술대로 두었고, 체험·퀴즈에는 쓰지 않음.
- 62쪽 대칭 특징 「암호화 속도가 빠르다」 vs 63쪽 비교 표의 「인증 속도가 빠름」, 63쪽 비대칭 「처리 속도가 느리지만」 vs 표의 「해독 시간이 오래 걸림」 — 표현이 섞여 있음. 화면 표에는 대칭 장점 「구현이 쉬움, 속도가 빠름」, 비대칭 단점 「해독 시간이 오래 걸림」(교과서 표 그대로).
- 63쪽 비교 표 「활용」 비대칭 칸은 공동 인증서만 있으나 본문 사례에 전자 서명도 있어 「전자 서명, 공동 인증서」로 씀.
- 60쪽 예제 1(본문 예제)은 세 글자 묶음을 원래 빈칸 자리에 맞춰 다시 쓴 것. 체험도 빈칸은 제자리에 두고 글자만 재배치함. 마지막 묶음이 키보다 짧으면 묶음 길이보다 큰 키 숫자를 건너뛰는 방식으로 구현했고, 60쪽 스스로 해결하기 1번과 64쪽 맞춤 활동 2번의 교과서 값과 계산이 맞음을 확인함.
- 60쪽 스키테일 스스로 해결하기 2번 띠는 체험과 같은 방식(세로로 채우고 가로로 읽기)으로 풀림을 확인함(답은 적지 않음). 체험의 새 띠는 교과서 띠와 굵기가 다르게 만듦.
- 63쪽 옆 설명 「개인키는 … **항상** 사용자가 소유해야」 — 극단어가 있어 화면에는 「늘 본인이 가지고」로 씀(퀴즈 보기에는 쓰지 않음).
- 59쪽 카이사르 암호 궁금해요 「알파벳에 숫자를 배정하고 숫자 순서대로 알파벳을 정렬하여 암호화하는 방식」은 뜻이 모호해 화면에는 넣지 않고 「암호화와 복호화가 간단하다」만 씀. 카이사르 암호의 한계(키가 25가지뿐이라 하나씩 넣어 보면 풀림)는 교과서가 학생에게 생각해 보게 한 내용이라, 체험(미션 B)과 퀴즈 2-2로 확인하게 함.
