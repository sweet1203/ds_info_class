생각해 볼까요? 사물 인터넷은 어떻게 시작되었을까?
1980년대 초, 카네기 멜런 대학교의 교수와 학생들은 멀리 있는 콜라 자판기까지 갔다가 콜라가 다 떨어졌거나 시원하지 않아 헛걸음을 하곤 했어요. 그래서 인터넷과 연동해 콜라의 재고와 온도를 확인할 수 있는 자판기를 만들었어요. 이것이 최초의 사물 인터넷이었어요.
「사물 인터넷」이라는 말은 1999년 생활용품 회사에서 재고 관리를 연구하던 케빈 애슈턴이 만들었어요. 모든 물건에 센서를 붙여 서로 소통하게 하자는 생각이었지요.

재고 관리에서 시작한 사물 인터넷은 이제 수많은 전자 기기와 물건에 쓰여요. 오늘은 사물 인터넷 시스템이 무엇으로 이루어져 있고, 어떤 순서로 움직이는지 직접 나누고 맞춰 보며 알아봐요.

01

사물 인터넷이란 무엇일까?

교과서 25쪽 · 사물 인터넷의 뜻과 하이패스

쉽게 말하면물건에 센서(느끼는 부품)와 통신 기능(말하는 부품)을 달아 주면, 물건끼리 정보를 주고받으며 사람이 일일이 시키지 않아도 알아서 일할 수 있어요. 이렇게 물건이 원래 하던 일보다 더 많은 일을 하게 만드는 기술이 사물 인터넷이에요.

🌐 사물 인터넷(IoT: Internet of Things)

사물에 다양한 센서와 통신 기능을 장착하여 사물 간에 정보 교류가 가능하게 만든 것으로, 각각의 사물이 제공하던 것 이상의 새로운 가치를 제공하는 기술
📦

사물이란?

네트워크에 연결될 수 있는 모든 것이에요. 자동차, 집, 가전제품, 스마트폰은 물론 입고 있는 옷이나 신발도 네트워크에 연결되어 있으면 사물 인터넷 시스템을 이루는 사물이 돼요.

🔄

스스로 작동

인터넷에 연결된 사물들은 사람이 직접 명령을 내리지 않아도 서로 정보를 주고받으며 스스로 작동할 수 있어요.

🏠

대표 사례

스마트 홈 서비스, 자율주행 자동차, 그리고 아래의 하이패스 통행료 처리 시스템이 대표적인 예예요.

🚗 하이패스는 어떻게 통행료를 낼까? (그림 Ⅰ-13 · 단계를 넘겨 보세요)

생각해 보기 이 네 단계 동안 운전자가 직접 버튼을 누르거나 명령을 내린 곳이 있었나요?

없어요. 차량 단말기와 톨게이트 단말기가 서로 정보를 주고받으며 스스로 작동해, 달리는 차 안에서 통행료가 자동으로 결제돼요. 이것이 사물 인터넷 시스템의 모습이에요.

02

사물 인터넷 시스템은 무엇으로 구성되어 있을까?

교과서 26~27쪽 · 디바이스 · 네트워크 · 플랫폼 · 서비스

쉽게 말하면사물 인터넷 시스템은 네 부분이 한 팀이에요. 디바이스가 데이터를 만들고, 네트워크가 그 데이터를 실어 나르고, 플랫폼이 모아서 저장·분석하고, 서비스가 그 결과를 사용자에게 쓸모 있게 전해 줘요. 앞 글자를 따서 DNPC라고 기억해요.
D디바이스데이터를 생성
→
N네트워크디바이스와 플랫폼을 연결
→
P플랫폼데이터를 저장·분석
→
C서비스결과를 사용자에게 제공

서비스는 C 또는 S로 나타내요(Contents/Service).

🏠 스마트 홈 속 이것은 D · N · P · C 중 무엇일까?

카드에 적힌 장치나 기술이 사물 인터넷 시스템에서 어떤 역할을 하는지 보고 골라요. 위의 설명을 다시 봐도 괜찮아요.

03

사물 인터넷 시스템의 동작 원리는 어떻게 될까?

교과서 28쪽 · 스마트 화분으로 보는 DNPC

쉽게 말하면센서가 모으고(데이터 수집) → 네트워크가 보내고(데이터 전달) → 클라우드가 따져 보고(데이터 처리 및 분석) → 스마트 기기로 알려 줘요(서비스 제공). 사용자가 명령을 내리면 이번에는 거꾸로 사물 쪽으로 전달돼 사물이 움직여요.

⚙️ 동작 원리

  • 데이터 수집

    다양한 센서나 디바이스를 통해 데이터를 수집해요.

  • 데이터 전달

    수집한 데이터를 유무선 통신 기술을 통해 클라우드로 전송해요.

  • 데이터 처리 및 분석

    클라우드에서 데이터를 저장하고, 전송된 정보를 분석하는 데이터 처리 과정을 거쳐 유용한 정보를 생산해요.

  • 서비스 제공

    생산된 정보는 다시 스마트 기기나 센서로 전달되어 사용자에게 서비스를 제공해요.

🪴 순서 맞추기: 사물 인터넷 시스템은 어떤 순서로 움직일까?

아래 카드 중에서 먼저 일어나는 일부터 차례로 눌러요. 첫 번째는 교과서의 스마트 화분, 두 번째는 같은 원리를 다른 장치에 적용해 보는 문제예요.

📝 개념 정리하기

빈칸에 들어갈 말을 먼저 떠올린 뒤 눌러서 확인하세요.

  1. 하이패스처럼 사람이 명령하지 않아도 사물들이 서로 정보를 주고받으며 스스로 작동하게 해 주는 기술이 이다.
  2. 스마트 홈에서 기기들을 무선으로 이어 주는 와이파이는 , 거실에서 사람의 움직임을 감지하는 인체 감지 센서는 , 집 밖에서 스마트폰으로 전등을 끄게 해 주는 원격 제어는 , 기기들의 데이터를 저장하고 분석하는 클라우드는 에 해당한다.
  3. 스마트 화분에서 흙의 수분을 재는 일은 , 잰 값을 네트워크로 보내는 일은 , 클라우드가 물이 부족한지 판단하는 일은 , 스마트폰에 물 줄 시기를 알려 주는 일은 단계에 해당한다.

마무리

핵심 문장 · 마무리 퀴즈 · 생각 정리 질문폼

사물 인터넷은 사물에 센서와 통신 기능을 장착해 사물 간에 정보를 주고받게 하여, 사물이 하던 것 이상의 새로운 가치를 제공하는 기술이다. 연결된 사물은 사람이 직접 명령하지 않아도 스스로 작동할 수 있다.
사물 인터넷 시스템은 데이터를 생성하는 디바이스(D), 연결하는 네트워크(N), 저장·분석하는 플랫폼(P), 결과를 제공하는 서비스(C)로 구성된다.
사물 인터넷 시스템은 데이터 수집 → 데이터 전달 → 데이터 처리 및 분석 → 서비스 제공의 과정으로 동작하며, 사용자의 명령은 다시 사물로 전달되어 사물을 움직인다.
