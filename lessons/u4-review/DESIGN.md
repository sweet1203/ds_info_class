# u4-review 설계표 — 협력적 창의·융합 프로젝트 · Ⅳ단원 정리 (교과서 200~205쪽)

u1~u3-review와 같은 틀(프로젝트 → 평가 → 진로 → 단원 정리, 동료 평가 · 역량 Check는 접기)로 만들었다. 이 프로젝트는 교과서에 **오렌지3 모델 학습 · 평가**까지 들어 있어서, 앞선 단원 정리처럼 「계획 + 발표 준비」가 아니라 **문제 발견 · 계획 → 실제 모델 학습 · 평가 → 성찰**까지 50분 안에 한다. 데이터 수집(에어코리아 · 기상자료개방포털에서 우리 동네 자료 내려받기)은 시간이 많이 들어 교과서 워크플로가 쓰는 `서울시 데이터(최종).csv`(선생님 폴더)로 대신하고, 우리 동네 데이터는 다음 시간이나 과제로 둔다. 모둠 활동이지만 메모는 각자 화면에 적는다(질문폼은 개인).

질문폼(info-u4-review) 1번 ← 01 `sdgPickName` `storyProblem` `storyIdea` `relData`(8분 무렵), 2번 ← 02 `typePickName` `algoPickName` `algoWhy`(10분 무렵), 3번 ← 02 `pmRes` + 성찰 `reflectImpact` `reflectEffort`(26분 무렵). 성찰하기를 교과서처럼 모델 평가 바로 뒤(같은 202쪽)에 두어 30분 안에 닿게 했다.

## 50분 흐름 (시작 화면 「50분 계획」과 같음)
모둠 정하기(2분, 오렌지3 실행 · 파일 받기) → 01 문제 발견 · 계획(6분, ~8분) 힌트 카드 보고 피해 · 연관 데이터 메모, 속성 표 훑기, 스토리(수집 방법은 접어 둠) → **02 모델 학습 · 평가 · 성찰(18분, ~26분)** 유형 · 알고리즘 고르기 2분 → File Role · Impute · Data Sampler · Linear Regression · Predictions 연결 10분 → 결과 메모 2분 → 성찰 3분 · 퀴즈 1분(질문폼 3번 근거가 26분 무렵에 닿음) → 03 평가하기(4분, ~30분) 프로젝트 카드 보며 자기 평가 · 역량(응용하기 · 동료 평가는 선생님 운영) → 04 진로(4분, ~34분) 카드 3장 · 퀴즈(진로 카드 메모는 선택) → 05 단원 정리(6분, ~40분) 분류 게임 6장 · 퀴즈 → 마무리(10분) 핵심 질문 답, 퀴즈, 질문폼.

## 줄인 것
- 200~201쪽 ➊ · ➋ 데이터 수집(사이트에서 우리 동네 4년 치 내려받아 합치기)은 50분 안에 어려워, 사이트 이름과 메뉴 · 자료 종류만 안내하고 교과서 워크플로와 같은 `서울시 데이터(최종).csv`로 실습함. 사이트 주소는 화면에 쓰지 않음.
- 200쪽 수행 계획서 QR · 모둠원 역할 표는 시작 화면의 모둠명 · 역할 메모로 대신함(역할 이름은 190쪽 모둠원 역할을 힌트로 씀).
- 203쪽 응용하기(센서로 측정한 공기질 데이터로 예측)는 준비물(MICS-6814 · ESP32)이 필요해 03에 접어 둠. QR 실습 영상은 「선생님이 보여 주는 영상」으로.
- 203쪽 평가하기의 자기 평가 · 동료 평가 표는 자기 평가 칩(잘한 것 고르기)과 동료 평가 메모(선택)로 바꿈. 평가 기준 문장은 접힌 표에 그대로 둠.
- 205쪽 단원 정리 14문항(○×, 단어 고르기, 빈칸, 선 긋기)은 형성평가 문항이라 옮기지 않음. 같은 개념(지능 에이전트, 인간의 역할, 로지스틱 회귀의 S자 곡선과 이진 분류, k-최근접 이웃, 선형 회귀, k-평균, 앙상블)을 **새 상황 문장**(로봇 청소기, 자율 주행 버스, 합격 확률, 과일 · 전학생 · 배달 주소 · 손님 · 날씨 예측 모델 등)으로 분류 게임과 퀴즈에 넣음. 정답(239쪽)은 넣지 않음.
- 202쪽 「예」로 채워진 평가 지표 결과와 203쪽 예측 결과 수치는 화면과 이 문서에 옮기지 않음(학생이 자기 결과를 적음).

## 선생님 준비물
- 선생님이 알려 주는 폴더: `서울시 데이터(최종).csv`(교과서 자료 200쪽). 저장소에는 넣지 않음.
- (선택) 응용하기: MICS-6814 센서, ESP32, 센서 측정값과 오늘의 기상 데이터를 합친 테스트 파일. 교과서 워크플로에는 Test Data(File) → Predictions (1) 흐름이 들어 있음.

## 확인할 점
- 202쪽 ➌ 「15% 훈련 데이터인 Remaining Data」 — Data Sampler에서 85%가 훈련 데이터(Data Sample)이고 남은 15%(Remaining Data)는 **테스트 데이터**임. 화면에는 「85%는 훈련 데이터, 나머지 15%는 테스트 데이터」로 바로잡음.
- 202쪽 ➊ 「예측하려는 속성이 아닌 PM10은 Skip」 — 교과서 설명 그대로 둠. 워크플로 파일에서는 날짜 · 요일도 feature로 들어가 있어 화면에 「날짜와 요일을 포함한 나머지 속성은 모두 feature」로 씀.
- 202쪽 ➋ Impute의 「결측치를 제거」는 워크플로 파일에서 「Remove instances with unknown values」로 설정되어 있음(확인함). 화면 설정 표도 같게 씀.
- `서울시 데이터(최종).csv`는 UTF-8이 아닌 한글 인코딩(CP949)으로 저장되어 있음. 오렌지3에서 한글 속성 이름이 깨지면 선생님이 UTF-8로 다시 저장해 나눠 주면 됨(막혔을 때에 「선생님께 알려요」로 적음). 데이터는 1,461일, PM2.5 등 일부 속성에 결측치가 있음을 확인함.
- 로컬에서 같은 설정(PM10 제외, 결측치 행 제거, 85% 무작위 학습)으로 선형 회귀를 여러 번 해 보니 R2가 교과서 값과 비슷한 범위로 나옴(분할에 따라 조금씩 다름 → 화면에 「모둠마다 값이 조금 달라도 정상」).
- 05 용어 카드는 205쪽 단원 정리에 나온 용어로만 씀. 지능 에이전트의 특성 목록은 다른 차시(u4-agent) 화면과 맞추지 않았으므로, 그쪽 용어와 다르면 05 카드 문장을 맞춰야 함.
- 205쪽 역량 Check의 12개 역량은 u2-review와 같은 목록(교과서와 같음)을 씀. 201쪽 「이 프로젝트로 길러진 역량」 4개(지식 정보 처리 · 창의적 사고 · 협력적 소통 · 공동체 역량)는 03 역량 칩으로.
- 204쪽 인터뷰 3문답은 요약해 다시 씀. 퀴즈 보기에 극단어가 들어가지 않게 함.
- 04 진로 퀴즈 4-2(주제별로 나누는 텍스트 프로젝트 → 분류)는 인터뷰 「텍스트 분류 알고리즘」을 기계학습 유형과 잇는 문항으로, 문제 줄기에는 「분류」 낱말을 넣지 않음.

## 검토 반영(1차)
- 시작 화면 「오늘의 질문」을 u1~u3-review처럼 **단원 핵심 질문 2개**(지능 에이전트 · 기계학습)로 바꾸고, 마무리는 「Ⅳ단원 핵심 질문에 답하기」(기계학습 질문, 오늘 만든 모델을 예로)로. MEMOLIST `keyQ` 이름표도 바꿈.
- 50분: 05 분류 게임 10장 → 6장(묶음마다 1장, 선형 회귀만 2장), 04 진로 카드 5장 → 3장 · 진로 카드 메모는 선택으로 접음, 01 ➊ · ➋ 수집 방법을 접음. 질문폼 3번 근거가 26분 무렵에 닿음.
- 퀴즈 단서: 6-1(PM2.5 항목, 2-1 해설이 답을 줌) → 85:15에서 평가에 쓰는 데이터(정답 ③), 6-2(선형 회귀, key3와 겹침) → 이 프로젝트의 SDGs 목표(정답 ②). key3 둘째 문장도 퀴즈 답을 주지 않게 평가 · 개선 문장으로 고침.
- 05 지능 에이전트 카드를 205쪽 단원 정리 문장 대신 예(배달 드론)로 풀어 씀. 퀴즈의 로봇 청소기 · 자율 주행 버스와 겹치지 않는 예를 씀.
- 퀴즈 4-1 보기를 짧은→긴 순서로, 접힌 선택 활동 용어 「이미지 임베딩」을 「데이터 시각화」로. 분포 ①3 ②4 ③3.
- 02 안내 「무작위라 값이 달라도 정상」 → 「Role 설정이나 Data Sampler 설정이 다르면 값이 조금 다를 수 있어요」(교과서 워크플로는 Replicable sampling).
