인공지능 기후 전문가가 되어 보자
기후 변화는 이제 모든 국가에 영향을 미치고 있어요. 국가 경제를 혼란에 빠뜨리고 오늘과 미래의 사람들, 공동체, 국가에 큰 손실을 입히고 있지요. 지속가능발전목표 13번 「기후 변화 대응」을 살펴보고, 우리 동네의 초미세 먼지 농도를 예측하는 인공지능을 모둠이 함께 만들어 봐요.

문제를 발견하고 → 필요한 데이터를 계획하고 → 오렌지3로 모델을 학습시켜 평가한 뒤, 인공지능이 사회에 미칠 영향을 성찰해요. 그다음 자연어 처리 엔지니어의 이야기를 읽고 Ⅳ단원 전체를 정리해요.

01

문제 발견하기 · 해결 방안 계획 세우기

교과서 200~201쪽 · 프로젝트 1~2단계

쉽게 말하면먼저 미세 먼지가 왜 문제인지, 미세 먼지를 예측하려면 어떤 데이터가 관련 있는지 생각해요. 그리고 모은 데이터로 무엇을 할지 스토리로 정리해요. 계획이 분명해야 다음 단계에서 알맞은 모델을 고를 수 있어요.

🔍 1. 문제 발견하기

PM-10 · PM-2.5

PM-10은 미세 먼지, PM-2.5는 초미세 먼지 농도를 뜻해요. 오늘 예측할 값은 PM-2.5예요.

공기질 데이터

오존, 이산화질소, 일산화탄소, 아황산가스처럼 공기 속 물질의 농도

기상 데이터

기온, 풍속, 풍향, 이슬점, 습도, 기압, 가시거리처럼 그날의 날씨

📥 2. 해결 방안 계획 세우기 · 데이터 수집

📥 우리 동네 데이터를 모으는 방법 보기 (선택 · 다음 시간이나 과제로)

➊ 우리 동네 공기질 데이터

에어코리아의 「통계 정보 → 최종 확정 측정 자료 조회」에서 우리 동네의 코로나 이전(2016~2019년) 일평균 데이터를 연도별로 내려받아 한 파일로 합쳐요. 요일 데이터를 추가하면 정확도가 올라가요.

➋ 우리 동네 기상 데이터

기상자료개방포털에서 평균 기온, 평균 풍속, 최다 풍향, 이슬점, 평균 상대 습도, 평균 현지 기압은 일 자료로, 가시거리는 시간 자료의 「시정」으로 내려받아 한 파일로 합쳐요.

우리 동네의 공기질 데이터(2016~2019년 일평균)와 기상 데이터를 모아 한 파일로 합치는 데는 시간이 걸려요. 오늘은 수업 시간 안에 모델까지 만들기 위해, 선생님이 서울의 공기질 · 기상 · 요일 데이터를 날짜별로 합쳐 둔 서울시 데이터(최종).csv를 써요. 우리 동네 데이터 모으기는 선생님 안내에 따라 다음 시간이나 과제로 해요.

교과서 202쪽 · 프로젝트 3~4단계와 성찰 · 오렌지3 실습

쉽게 말하면예측하고자 하는 값(PM2.5)이 어떤 형태인지 보고 기계학습 유형과 알고리즘을 골라요. 오렌지3에서 결측치를 지우고, 데이터의 85%로 학습시킨 뒤 나머지 15%로 평가해요. 결과를 보고 인공지능 기술이 사회에 미칠 영향을 성찰해요.

🪞 성찰하기

활동을 마치고 난 뒤, 인공지능 기술이 현재 또는 미래 사회에 미칠 영향과 우리가 노력해야 할 점을 써요.

🆘 막혔을 때 펼쳐 보기
  • Role을 어떻게 바꿔요? → File 위젯 창의 표에서 그 속성 줄의 Role 칸을 더블 클릭해 목록에서 골라요. 다 바꾼 뒤 Apply를 눌러야 반영돼요.
  • 한글 속성 이름이 깨져 보여요 → 선생님께 알려요. 같은 파일을 다른 인코딩으로 저장한 파일을 받을 수 있어요.
  • Predictions에 평가 지표가 없어요 → Show performance scores를 켜고, File에서 PM2.5가 target인지 확인해요.
  • Predictions의 줄 수가 너무 많아요 → 훈련 데이터가 들어간 거예요. Data Sampler와 이은 연결선을 더블 클릭해 Remaining Data로 바꿔요.
  • 오렌지3가 안 열려요 → 모둠 친구 화면을 함께 보며 결과를 메모하고, 성찰하기를 먼저 써요.

06

마무리

핵심 문장 · 마무리 퀴즈 · 생각 정리 질문폼

사회 문제를 인공지능으로 풀 때는 문제 발견 → 데이터 수집 계획 → 모델 학습 → 모델 평가 → 성찰 순서로 진행하고, 예측하려는 값의 형태에 맞는 유형과 알고리즘을 고른다.
만든 모델은 평가 지표(R2 · MAE)로 성능을 확인하고, 데이터나 속성을 바꿔 가며 더 나은 모델로 고쳐 나간다.
자연어 처리는 사람의 언어를 컴퓨터가 이해하고 처리하게 하는 기술이다. 인공지능은 여러 분야에 쓰이므로 관심사에 따라 다양한 진로로 이어진다.
