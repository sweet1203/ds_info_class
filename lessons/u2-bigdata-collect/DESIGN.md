쓰기 메모 10칸 + 칩 4개. 퀴즈 13문항(정답 위치 ①4 ②5 ③4). 질문폼 1번 ← 02 상황별 수집 방법 고르기·`wayWhy`, 2번 ← 03 「이렇게 수집해도 될까?」·`careFix`, 3번 ← 04 수집 계획(`planQ`~`planCare`).

**다음 차시와 잇기** — 04에서 `calories.csv`·`exercise.csv`를 「정보 데이터」 같은 폴더에 저장하게 하고, 두 파일에 무엇이 들었는지 한 줄씩만 소개했다. 내용은 「빅데이터 전처리」(u2-preprocess)에서 오렌지3로 연다.

**50분 흐름(검토 반영 후)** — 도입(6분) 칼로리 데이터 내려받기 3분(시작 화면) + 비만율 이야기·처음 생각 → 01(7분) 정의·3V, 분류 게임 → **02(13분 무렵 시작, 9분)** 네 방법 탭, 상황별 고르기 + 한 줄 메모 → **03(22분 무렵 시작, 5분)** 주의할 점, 장면 판단·메모 → **04(27분 무렵 시작, 12분)** 수집 계획 9분 + 성취도, 수집 과정 돌아보기·개념 정리 빈칸은 접어 둔 선택 → 마무리(8분). 질문폼 근거 활동(02·03·04)은 모두 30분 안에 시작.

**줄인 것** — 68쪽 그림 Ⅱ-6·Ⅱ-7(사이트 화면)과 69쪽 그림 Ⅱ-8(사진)은 옮기지 않고, 사이트는 이름만 적었다(주소 없음). 68쪽 캐글 회원 가입·로그인은 하지 않고 선생님 폴더에서 같은 파일을 받게 했다(교과서 경로는 한 줄 소개). 69쪽 생각해 보기(설문 조사 사이트로 직접 수집)는 수집 계획 아래 선택 안내 한 줄로만. 67쪽 은행·추천 서비스 사진은 글로만. 69쪽 개념 정리하기는 그대로 옮기지 않고 새 상황 빈칸 5개로(답 낱말만 같음).

**확인할 점**
- 67쪽 「페타바이트(PB, 1,024TB)」와 옆 날개의 「테라바이트 10¹²byte, 페타바이트 10¹⁵byte」가 서로 맞지 않는다(10¹⁵byte = 1,000TB, 1,024TB는 2진 단위). 화면에는 10¹²·10¹⁵ byte만 쓰고 1,024TB는 뺐다.
- 교과서 66~69쪽에는 「수집 시 윤리적 문제」가 따로 정리되어 있지 않다. 66쪽 도입 글(윤리적인 문제를 고려해야 올바른 결과), 66쪽 삽화 말풍선(개인 정보 유출 주의), 68쪽 공공 데이터 설명(개인 정보 보호·국가 안보와 질서, 신뢰성·법적 근거), 69쪽(목적에 알맞은 방법)을 모아 03 화면을 만들었다. 03 판단 카드의 「허락」「참여하겠다는 친구」는 개인 정보를 지키는 방법을 쉽게 풀어 쓴 것으로, 교과서에 따로 나온 용어는 아니다.
- 66쪽 비만율 그래프의 「소아청소년 비만율(6~18세) 10.2%→16.2%」는 본문에 설명이 없어 화면 그래프에서는 중고등학생 비만율(본문 수치)만 그렸다.
- 68쪽 스스로 해결하기는 캐글 회원 가입이 필요하다. 수업에서는 가입하지 않고 선생님 폴더를 쓰게 했다(선생님 결정 필요).
- 직접 수집 설명의 「여러 센서나 플랫폼을 활용하여」에서 플랫폼은 Ⅰ단원 IoT 플랫폼과 같은 낱말이지만 뜻을 따로 설명하지 않았다. 화면에서는 교과서 문장 그대로 둠.

**선생님 준비물** — 드라이브 「선생님이 알려 주는 폴더」에 `calories.csv`, `exercise.csv`(교과서 소스 코드 74쪽 폴더의 두 파일). 다음 차시용 `태양광 발전.xlsx`도 같은 폴더에 함께 두면 편하다.

**검토 반영(1차)**
- 칼로리 데이터 내려받기를 04에서 시작 화면(오늘 할 일 위)으로 옮김(u2-preprocess처럼). 04는 「나의 데이터 수집 계획」 중심으로 바꾸고, `collectSteps`와 개념 정리 빈칸은 「시간이 남으면」 접는 칸으로. 수집 계획(질문폼 3번 근거)이 27분 무렵 시작.
- 02 분류 게임 아래 한 줄 메모 `wayWhy` 추가(질문폼 1번 근거), MEMOLIST에 넣음.
- 퀴즈 2-1 해설을 「누구나 자유롭게 쓸 수 있도록 공개」까지만 써 3-1 답이 드러나지 않게 함. 3-1 보기를 「~범위」로 길이를 맞추고 정답을 가운데 길이로.
- 퀴즈 3-2를 교과서 근거 문항으로 바꿈(66쪽 「윤리적인 문제를 고려해서 수행해야 올바른 결과」). 03 화면의 익명·허락·출처 확인은 활동(판단 카드)에만 남김.
- 퀴즈 5-2(4-2 줄기와 겹침)를 4V·5V(가치·정확성) 문항으로 바꿈. 5-3 보기를 모두 웹 관련으로 바꾸고 정답에서 「웹 크롤러」를 뺌, 길이를 맞춤.
- 퀴즈 1-1 오답의 「숫자로만」을 「작은 숫자 데이터」로.
- careGame: 쉬운 「공영 자전거 통계」 카드를 그럴듯한 함정 카드(이름·주소·전화번호가 있지만 기관 정보인 공개 병원 데이터 → 괜찮아요)로 바꿈.
- 「반 친구 직접 수집」 반복을 줄임: 퀴즈 4-1을 가로등 밝기(센서)로, 개념 정리 5번을 횡단보도 사람 수 세기로.
- 직접 수집 탭의 카메라 예를 「여러 표정의 얼굴 사진」에서 「병든 식물 잎 사진」으로.
- 퀴즈 13문항, 정답 위치 ①4 ②5 ③4.

**검토 반영(2차)**
- 마무리 key3 첫 문장을 69쪽 개념 정리와 다른 어순으로 풀어 씀(3V를 다양성 → 속도 → 양 순서로).
- 02 민간 데이터 탭: 「오늘 「스스로 해결하기」에서 내려받는」 → 「시작 화면에서 내려받은」.
- 표지 「시작하기 →」 위에 「먼저 아래 「오늘 할 일 보기」에서 칼로리 데이터를 내려받은 뒤 시작해요」 한 줄.
- 설계표 04행에서 `fileCheckPick`을 빼고(0 시작으로 옮김) 04 내용을 현재 구성(수집 계획 · 성취도 · 접는 칸)에 맞춤.
- 운영 메모: 마무리 질문폼 3번(수집 계획)을 수업 안에 다 못 쓴 학생은 수업 뒤 메모 모아 보기를 보며 이어서 쓴다.
