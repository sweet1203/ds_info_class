# u1-iot-design-2 설계표 — 사물 인터넷 시스템 설계 ② 스마트 조명 만들기 · 사물 인터넷 정리 (교과서 38~41쪽, 37쪽 실습 포함)

피코 H 1인 1키트 실습. **핀 배치(선생님 결정)**: 지난 시간 회로에서 **버튼만 빼고** 인체 감지 센서를 더한다. LED는 **GP14 그대로**(보드 핀 19), 센서 신호 **GP28**(보드 핀 34, 매뉴얼 5장과 같음), 여유 활동 부저는 버튼이 있던 **GP15**(보드 핀 20). 매뉴얼 5장(LED 15·부저 14)과 LED·부저 핀이 서로 바뀌어 있다. 피코 H에는 와이파이가 없으므로 38~39쪽 Blynk 실습은 **코드 읽기 · 동작 예측 · 화면 시뮬레이션**으로 바꾸고, 「버튼으로 켜기 vs 인터넷으로 켜기」 비교로 **통신망에 연결되어 정보를 주고받아야 사물 인터넷 시스템**(24쪽 정의)임을 짚는다.

**줄인 것** — 39쪽 Blynk 계정·템플릿·데이터스트림·장치 추가 실습은 순서만 한 줄로 소개(외부 계정 생성 없음). 38쪽 Ⓐ 코드 수정 영상·실습 영상(QR)은 넣지 않음. 매뉴얼 5장 실습(3) PIR 두 개·챌린지 미션은 넣지 않음. 40쪽 3컷 만화와 41쪽 선택 활동은 접어 두고 시간이 남을 때. 41쪽 보충·심화의 교과서 예시(스마트 귀걸이, 스마트 스터디 셔츠, 스마트 교실)는 예시 답안이므로 옮기지 않음.

**확인할 점**
- **키트 PIR 센서 실물 확인(선생님)**: 흔한 HC-SR501형은 기판 글자가 VCC · OUT · GND이고 가운데가 OUT(신호)이다. 교과서 35쪽 사진도 가운데가 Signal이다. 화면 그림은 이 순서로 그렸고, 「그림 순서·선 색이 아니라 기판 글자 기준」 안내를 크게 넣었다. 매뉴얼 그림(Fritzing)은 선 색이 실제 극성과 맞지 않으므로 학생에게 보여 주지 않는 것이 좋다. 키트 센서의 글자·전원 전압(5V VBUS 연결)이 맞는지 수업 전에 확인 필요.
- **유지 시간 가변 저항**: 출고 상태가 길게 맞춰져 있으면 한 번 켜진 LED가 몇 분씩 안 꺼질 수 있다. 수업 전에 가장 짧게 돌려 두기를 권함(화면 도움말에 「선생님이 미리 맞춰 두었을 수도 있어요」).
- **피코 H 펌웨어의 network 모듈**: 일반 Raspberry Pi Pico용 마이크로파이썬에는 network 모듈이 없을 것(와이파이 칩이 없음)으로 보이나 실물로 확인하지 않았다. 화면 예측 3번은 확실한 것(BlynkLib가 없어 1줄부터 오류)을 먼저 쓰고 network는 「쓸 수 없을 거예요」로 씀. 확인 필요.
- 교과서 37쪽 코드는 `Pin(13, Pin.IN)`(풀다운 없음)이고, 키트 매뉴얼은 `Pin.PULL_DOWN`을 쓴다. 피코에서는 매뉴얼대로 넣었다.
- 매뉴얼 5장 코드에는 `utime.sleep(0.2)`, 바로 아래 설명에는 `utime.sleep(0.02)`로 서로 다르다(매뉴얼 오류). 화면은 0.2초.
- PIR 센서 「전원 후 1분 가까이 안정 시간」은 교과서·매뉴얼에 없는 실습 팁(일반 PIR 모듈의 특성)이라 도움말에만 넣었다.
- 「피코 조명은 사물 인터넷 시스템일까?」 → 「아직 아니다」. 근거: 24쪽 정의(통신망에 연결되어 정보를 주고받는 시스템), 26쪽 디바이스 = 센서·액추에이터·**통신 모듈**·마이크로컨트롤러이므로 피코 조명은 D의 일부만 갖춤, 37쪽 「센서와 마이크로컨트롤러를 사용하여 사물 인터넷 장치를 개발할 수 있고」. 비교표·투표 설명·u1-review 해설을 모두 「D의 일부, 통신 모듈 없음」으로 맞춤.
- 38쪽 코드 4~6줄은 교과서 그림처럼 `'XXX'`로 둠(교과서 코드 파일의 한국어 안내 문구 대신). 학생 화면에 「읽기만 해요」로 안내.
- 「앱의 ON이 V2로 1을 보낸다」는 39쪽 결과 그림(ON → LED 켜짐)과 코드 23~26줄로 추론한 설명이다(교과서가 V2 값 0/1을 직접 쓰지는 않음).
- 마무리 퀴즈 셋째는 접힌 선택 활동(웨어러블) 대신 35쪽 인체 감지 센서 원리(적외선의 변화)로 바꿈.

**검토 반영(2차)**
- 01 핀 표 아래 5V 경고: 「VBUS(핀 40)는 5V예요. 이 선은 센서 VCC에만 연결하고 다른 GP 핀에 닿지 않게 해요. 선을 바꿔 꽂을 때는 USB를 뽑아요」.
- 부저(접힌 활동) 안내 맨 앞에 「먼저 지난 시간의 버튼과 3V3 선을 뺐는지 확인」. 3V3 선이 GP15에 남아 있으면 부저 출력 핀과 3V3이 바로 이어지기 때문.
- 시뮬레이션 부저 울림 시간을 코드와 같은 0.1초로 맞춤(화면 갱신 간격도 0.05초로 줄여 짧은 울림이 보이게). 이 문서의 부저 표기도 0.1초로 통일.
- 준비물에 「암-수 점퍼선 3개(PIR 연결용)」 추가. **키트에 암-수 점퍼선이 들어 있는지 확인 필요**(PIR 모듈 핀이 수 핀이라 브레드보드에 바로 꽂을 수 없음).
- 도움말에 「LED가 꺼진 직후 몇 초는 다시 감지하지 않아요」 추가(HC-SR501형의 감지 후 잠금 시간, 교과서·매뉴얼에는 없는 실습 팁).
