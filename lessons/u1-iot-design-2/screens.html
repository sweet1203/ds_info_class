01

인체 감지 센서로 켜지는 스마트 조명

교과서 35·37쪽 · 인체 감지 센서를 활용한 전등 켜기

쉽게 말하면지난 시간 회로에서 버튼만 빼고 인체 감지 센서를 더하면 돼요. LED는 그대로 GP14에 두어요. 코드도 버튼 자리에 센서가 들어갈 뿐이에요. 센서가 사람의 움직임을 감지하면 1, 없으면 0을 보내고, 마이크로컨트롤러는 그 값에 따라 LED를 켜고 꺼요.

🔧 회로 연결하기

부품 핀피코 연결교과서 ESP32
센서 VCC (전압)VBUS (보드 핀 40)VIN
센서 OUT (신호)GP28 (보드 핀 34)D13
센서 GND (접지)GND (보드 핀 28 등 아무 GND)GND
LED 긴 다리(+)저항(220Ω)을 거쳐 GP14 (보드 핀 19) · 그대로D2
LED 짧은 다리(−)GND (보드 핀 18) · 그대로GND
🔎 센서 기판에 적힌 글자(VCC · OUT · GND)를 보고 연결해요. 그림의 순서나 선 색이 아니라 글자가 기준이에요. 센서마다 핀 순서가 다를 수 있어요. 교과서는 같은 핀을 V · S · G로 적어요.

LED와 저항은 지난 시간 자리(GP14) 그대로 두고, 버튼과 버튼 선만 빼요.

⚠️ VBUS(핀 40)는 5V예요. 이 선은 센서 VCC에만 연결하고 다른 GP 핀에 닿지 않게 해요. 선을 바꿔 꽂을 때는 USB를 뽑아요.

🧪 실습 ① 사람이 움직이면 LED 켜기

from machine import Pin
import time
LED = Pin(14, Pin.OUT)
PIR = Pin(28, Pin.IN, Pin.PULL_DOWN)
while True:
    if PIR.value() == 1:
        LED.value(1)
    else:
        LED.value(0)
    time.sleep(0.2)
314번 핀을 LED의 출력으로 정해요. 지난 시간과 같아요.
428번 핀을 인체 감지 센서의 입력으로 정해요.
6센서 값이 1이면(움직임을 감지하면)
7LED 켜기
8·9움직임이 감지되지 않으면 LED 끄기
100.2초 쉬고 다시 확인해요.

교과서 37쪽 코드와 같은 순서예요. 주로 달라진 것은 핀 번호(ESP32 2번·13번 → 피코 14번·28번)이고, 그 밖에 4줄의 Pin.PULL_DOWN, 10줄의 쉬는 시간이에요.

센서 앞을 지나가 보세요. 사람이 지나간 뒤에도 감지 유지 시간 동안은 값이 1로 남아요.

실제 센서의 감지 유지 시간은 가변 저항으로 0.3초에서 5분까지 조절해요. 화면에서는 1~8초로 줄여서 보여 줘요.

  1. 버튼을 빼고 센서를 연결한 뒤, 코드를 입력해 실행해요.
  2. 종이컵으로 센서를 덮고 컵 안에 손만 넣었다 빼 봐요. 주변 친구들의 움직임에 반응하지 않게 하려는 거예요. LED가 언제 켜지고 언제 꺼지나요?
  3. 손을 뺀 뒤 LED가 꺼질 때까지 몇 초쯤 걸리는지 재 봐요.
🆘 센서가 이상하게 동작할 때 (눌러서 펼치기)
  • 전원을 넣자마자 제멋대로 켜졌다 꺼져요 → 센서는 전원을 넣은 뒤 1분 가까이 안정되는 시간이 필요해요. 잠시 기다려요.
  • 한 번 켜지면 한참 안 꺼져요 → 감지 유지 시간 가변 저항이 길게 맞춰져 있을 수 있어요. 가장 짧게(최소로) 돌려 두어요. 선생님이 미리 맞춰 두었을 수도 있어요.
  • LED가 꺼진 직후에는 손을 넣어도 반응이 없어요 → 센서는 꺼진 직후 몇 초 동안 다시 감지하지 않아요. 잠깐 기다렸다가 다시 해 봐요.
  • 아무도 없는데 자꾸 켜져요 → 주변 친구들의 움직임을 감지한 거예요. 종이컵으로 센서를 덮고 손만 넣어 봐요.
  • 가까이 가도 반응이 없어요 → 기판 글자를 다시 봐요. VCC가 VBUS(보드 핀 40), OUT이 GP28(보드 핀 34)인지, 코드의 숫자가 28인지 확인해요.
  • LED만 안 켜져요 → LED가 GP14(보드 핀 19)에 그대로 있는지, 3줄의 숫자가 14인지 확인해요.
➕ 여유가 있으면: 부저 더하기 (눌러서 펼치기)

먼저 지난 시간의 버튼과 3V3 선을 뺐는지 확인해요. 사람이 처음 감지되는 순간 부저가 「삑」 한 번 울리게 해 봐요. 부저도 결과를 내보내는 출력 장치예요. 버튼이 있던 GP15 자리를 써요.

부품피코 연결
부저 빨간 선(+)GP15 (보드 핀 20)
부저 검은 선(−)GND
from machine import Pin
import time
LED = Pin(14, Pin.OUT)
PIR = Pin(28, Pin.IN, Pin.PULL_DOWN)
BUZ = Pin(15, Pin.OUT)
while True:
    if PIR.value() == 1:
        LED.value(1)
        BUZ.value(1)
        time.sleep(0.1)
        BUZ.value(0)
        while PIR.value() == 1:
            time.sleep(0.2)
    else:
        LED.value(0)
    time.sleep(0.2)

색칠한 줄(5줄, 9~13줄)이 새로 넣는 줄이에요. 9~11줄에서 0.1초 동안 「삑」 울리고, 12~13줄은 센서 값이 0으로 돌아갈 때까지 기다려요. 그래서 사람이 계속 있어도 부저는 처음 한 번만 울려요.

02

스마트폰 앱으로 켜기: 코드 읽고 예측하기

교과서 38~39쪽 · 사물 인터넷 시스템 설계와 구현

쉽게 말하면교과서에서는 와이파이가 있는 ESP32를 인터넷에 연결하고, Blynk라는 사물 인터넷 플랫폼과 스마트폰 앱을 이용해 멀리서 LED를 켜요. 우리 피코 H에는 와이파이가 없으니, 오늘은 이 코드를 읽고 동작을 예측해 봐요.

🗺️ 사물 인터넷 시스템 설계 (그림 Ⅰ-14)

DESP32디바이스
N네트워크
PBlynk플랫폼
N네트워크
CBlynk 앱서비스

ESP32에 장치 프로그램을 넣고 Blynk 앱으로 접속하면 전 세계 어디서든 통신과 제어가 가능해요. 플랫폼 쪽은 계정 만들기 → 템플릿 만들기 → 데이터스트림(Virtual Pin) 만들기 → 장치 추가 순서로 준비해요.

📖 교과서의 장치 프로그램 읽기 (묶음을 눌러 보세요)

import BlynkLib
import network
from machine import Pin
WIFI_SSID = 'XXX'
WIFI_PASS = 'XXXXXX'
BLYNK_AUTH = 'XXXXXXXXX'
wifi = network.WLAN(network.STA_IF)
if not wifi.isconnected():
    print('Connecting to WiFi...')
    wifi.active(True)
    wifi.connect(WIFI_SSID, WIFI_PASS)
    while not wifi.isconnected():
        pass
print('IP:', wifi.ifconfig()[0])
blynk = BlynkLib.Blynk(BLYNK_AUTH)
ledPin = Pin(2, Pin.OUT)
@blynk.on('connected')
def blynk_connected(ping):
    print('Blynk ready. Ping:', ping, 'ms')
@blynk.on('disconnected')
def blynk_disconnected():
    print('Blynk disconnected')
@blynk.on('V2')
def v2_write_handler(value):
    v2_pin_value = int(value[0])
    ledPin.value(v2_pin_value)
while True:
    blynk.run()

읽기만 해요. 직접 입력하지 않아요. 4~6줄의 XXX에는 와이파이 이름·비밀번호, Blynk 인증 키를 넣어요.

🔮 동작 예측하기

코드를 보고 먼저 내 예측을 적은 다음, 「확인」을 펼쳐 비교해요.

  1. 앱에서 ON을 고르면 25줄의 v2_pin_value에는 어떤 값이 들어가고, LED는 어떻게 될까?
    확인앱의 ON은 데이터스트림 V2에 1을 보내요. 그래서 v2_pin_value는 1이 되고, 26줄에서 ledPin.value(1)이 되어 LED가 켜져요. OFF면 0이 들어가 꺼져요.
  2. 5줄의 와이파이 비밀번호를 잘못 넣고 실행하면 어떻게 될까?
    확인12~13줄은 「연결되지 않은 동안 계속 기다리기」예요. 연결이 안 되니 아래 줄로 넘어가지 못하고, Blynk와도 연결되지 않아 앱으로 LED를 켤 수 없어요.
  3. 이 코드를 우리 피코 H에 그대로 넣으면 어떻게 될까?
    확인1줄 import BlynkLib부터 오류가 나요. 우리 피코에는 Blynk 라이브러리가 설치되어 있지 않거든요. 설치하더라도 피코 H에는 와이파이 기능이 없어서 2·7줄의 와이파이(network) 부분도 쓸 수 없을 거예요. 핀 번호만 바꿔서는 해결되지 않고, 네트워크에 연결할 수 있는 보드가 있어야 해요.
03

버튼으로 켜기 vs 인터넷으로 켜기

교과서 24·26~27·37~39쪽 · 무엇이 있어야 사물 인터넷 시스템일까?

쉽게 말하면센서와 마이크로컨트롤러로 만든 조명은 사물 인터넷 장치를 만드는 첫걸음이에요. 네트워크에 연결되어 정보를 주고받아야 비로소 사물 인터넷 시스템이 돼요.

📌 사물 인터넷 시스템이란? (24쪽)

센서와 통신 기능을 내장한 각종 사물들이 인터넷을 비롯한 통신망에 연결되어 정보를 주고받는 시스템

D 디바이스

센서, 액추에이터, 통신 모듈과 이것을 제어하는 마이크로컨트롤러 등이 포함된 장치

N 네트워크

유무선 통신으로 사물들을 연결해 데이터를 전송하는 매개체

P 플랫폼

사용자와 사물 사이에서 데이터를 저장·관리·분석하는 중계자

C 서비스

분석한 결과를 사용자에게 맞춤형으로 제공

🗳️ 오늘 만든 피코 스마트 조명은 사물 인터넷 시스템일까?

교과서의 정의로 보면 아직 아니에요. 디바이스(D)에 들어가는 것 가운데 센서·출력 장치·마이크로컨트롤러는 있지만 통신 모듈이 없어서, 통신망에 연결되어 정보를 주고받지 못해요. 교과서도 「센서와 마이크로컨트롤러를 사용하여 사물 인터넷 장치를 개발할 수 있다」고 말해요. 통신 기능을 갖추고 네트워크(N)로 플랫폼(P)과 서비스(C)에 이어질 때 사물 인터넷 시스템이 돼요.
04

사물 인터넷 시스템 정리

교과서 40~41쪽 · 우리의 일상 속 사물 인터넷 시스템

쉽게 말하면지금까지 배운 사물 인터넷 시스템의 개념 · 구성 · 동작 과정을 내 말로 정리하는 시간이에요. 주변에서 쓰는 시스템 하나를 골라 동작 과정을 설계해 봐요.

핵심 문장 · 마무리 퀴즈 · 생각 정리 질문폼

인체 감지 센서(입력)의 값이 1이면 LED(출력)를 켜고 0이면 끄도록 if 문으로 제어하면 스마트 조명이 된다. 교과서 ESP32 코드와 주로 달라진 것은 핀 번호다.
교과서의 앱 조명은 디바이스(ESP32) — 네트워크 — 플랫폼(Blynk) — 네트워크 — 서비스(앱)로 이어져, 멀리서도 LED를 켜고 끌 수 있다.
센서와 통신 기능을 가진 사물이 통신망에 연결되어 정보를 주고받아야 사물 인터넷 시스템이다. 동작 과정은 데이터 수집 → 전달 → 처리 및 분석 → 서비스 제공이다.
