**질문폼(info-u3-variables) 근거** — 1번 ← 01 코드 읽고 예측하기 ①(`trCoin`·`varWhy`), 2번 ← 02 자료형 고르기(`typeHard`), 3번 ← 03 코드 읽고 예측하기 ③(`trAdd`·`addWhy`)과 시작 화면 처음 생각(`planVar`). 세 활동 모두 27분 무렵까지 끝남. 코랩 실습은 질문폼 근거로 쓰지 않음(늦어지는 학생이 있어도 질문폼을 쓸 수 있게).

**50분 흐름** — 도입(3분) 중단원 도입은 훑기만, 투표 하나, 처음 생각 한 줄 → **01(3~11분)** 메모리 그림·대입 연산자 설명, 예측하기 ①(2분), 메모, 변수 이름 분류 7장 → **02(11~18분)** 표 Ⅲ-1은 선생님과 함께 훑고 자료형 고르기 8장, 메모 → **03(18~27분)** 교과서 예제 3개는 결과만 확인, 예측하기 ②③(4분), 메모, 스스로 해결하기 예측 → **04(27~43분)** 코랩 열기·로그인·사본 저장(3~4분), 예제 실행 → 변수 연산 직접 입력 → 함께 해결하기 1·3 → 메모·개념 정리(2번은 먼저 끝낸 학생이 선택) → 마무리(43~50분) 처음 생각과 비교, 퀴즈, 질문폼. 더 해 보기(선택)는 먼저 끝낸 학생용.

**코랩 노트북(`assets/variables_types.ipynb`)** — 교과서 120~121쪽 코드(`작업자료/교과서코드_3단원/120쪽`, `121쪽`)를 바탕으로 만듦. 출력은 비운 채 저장. 로컬 python3로 모든 칸을 차례로 실행해 확인함(함께 해결하기 1번 빈칸은 시험할 때만 값을 넣어 실행, 3번의 마지막 TypeError는 의도한 오류).
- ① 예제 따라 하기: 120쪽 예제 3개 그대로.
- ② 스스로 해결하기(변수 연산): 코드는 문제로 마크다운에 보여 주고, 실행 칸은 비워 두어 학생이 직접 입력(실행 결과는 넣지 않음).
- ③ 함께 해결하기: 1번은 교과서처럼 이름·나이만 채우고 나머지 4줄은 `# 취미 =`처럼 비워 둠(정답 코드 없음), 확인용 print 2줄은 따로 칸. 2·3번은 교과서가 주는 문제 코드 그대로(결과를 예측한 뒤 실행). 3번의 `a, b, c = …`(한 번에 여러 변수에 대입)는 교과서에 설명이 없어 마크다운에 한 줄 풀어 씀.
- ④ 더 해 보기(선택): 나를 소개하는 변수(개인 정보 쓰지 않기 안내), 규칙에 어긋난 변수 이름을 직접 써서 오류 보기.

**줄인 것** — 118쪽 사진과 전문가 그림은 글(투표 보기)로만. 119쪽 QR(통합 개발 환경)·120쪽 QR(연산자)의 내용은 넣지 않음. 연산자는 대입 연산자(119쪽 옆 설명)와 교과서 코드에 나오는 + - * /만 짧게 다룸(비교 연산자·% 연산자·복합 대입 연산자는 u3-selection 132~135쪽에서). 컨테이너형은 표와 괄호 모양까지만(리스트·딕셔너리는 다차원 데이터 차시에서). 터틀은 153쪽 선택 활동(보충)의 사각형 코드를 0 화면에 접어 둠(코랩에서는 그림판이 열리지 않아 IDLE 권장 안내). 03 체험 ③은 함께 해결하기 3번과 같은 원리를 **다른 값(20과 '20')**으로 보여 줌(교과서 문항의 실행 결과는 화면에 없음). 개념 정리하기는 교과서 문장을 옮기지 않고 새 상황 문장 빈칸으로.

**확인할 점**
- 119쪽 표 Ⅲ-1과 127쪽에서 딕셔너리는 「순서가 없다」고 함. 파이썬 3.7부터는 딕셔너리가 넣은 순서를 기억해 그 순서대로 출력됨. 교과서의 뜻은 「인덱스(순서 번호)로 값을 찾지 않고 키로 찾는다」로 보임. 이 화면에는 표를 교과서 그대로 두고, 다차원 데이터 차시에서 「인덱스가 아니라 키로 찾는다」로 풀어 씀.
- 120쪽 Tip은 「문자형은 좌우만 일치시키면…」, 표 Ⅲ-1은 「문자열형(str)」. 다음 차시와 용어를 맞추려고 화면에는 「문자열」로 씀.
- `작업자료/교과서코드_3단원/121쪽/121_함께_해결하기_1번.py`의 키 값이 교과서 121쪽 표의 값과 다름(정답 코드라 노트북에는 넣지 않았고, 노트북 표는 교과서 값 그대로).
- 118쪽 「컴퓨터로 대표되는 프로그래밍」은 문장이 어색해 화면에서는 「컴퓨터가 일을 하게 하려면 프로그래밍으로 명령을 내려야」로 풀어 씀.
- 03 체험의 TypeError 메시지(`unsupported operand type(s) for +: 'int' and 'str'`)는 파이썬 3.14로 확인함. 코랩(3.12 계열)도 같은 문장.

- 03 TypeError 메시지는 파이썬 3.14로 확인함.
- 121쪽 함께 해결하기 2번 `area = 2 * pi * radius`: 변수 이름은 area(넓이)인데 식은 **원의 둘레**(2πr)를 구하는 식임(원의 넓이는 πr²). 활동 목적(실수형이 되는 까닭)에는 영향이 없어 코드는 교과서 그대로 두고, 노트북 3-2 마크다운에 「이 식은 원의 둘레를 구하는 식」이라고 한 줄 밝힘.
