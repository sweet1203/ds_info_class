퀴즈 12문항(정답 위치 ①4 ②4 ③4). 질문폼(info-u5-info-protection) 1번 ← 0 확진자 안내문 고르기(`openPick`·`openWhy`)·02 「지킬까, 나눌까?」, 2번 ← 02 함께 해결하기(`pickInfo`·`protectVal`·`shareVal`), 3번 ← 03 오남용 사례·법적 장치(`misuseLaw`), 04 실천 점검(`myPlan`). 05의 접어 둔 2·3번은 퀴즈·질문폼이 묻지 않음.

중단원 핵심 질문(222쪽 「정보를 보호하고 정보 보안을 유지하기 위한 실천 방안은 무엇일까?」)의 답은 233쪽 학업 계획 점검에 맞춰 다음 차시(u5-info-security) 마무리에서 적게 하고, 이 차시 마무리에서는 223쪽 소단원 질문에 답하게 함.

**50분 흐름** — 도입(4분) 확진자 안내문 고르기 → 공개 방침 보기, 학습 계획 → 01(5분, 4~9분) 정의·Ⅴ-6 탭, 분류 6장, 퀴즈 → **02(9분, 9~18분)** 생각의 변화·장점·기준 3분, 분류 6장 1분, 함께 해결하기 메모와 짝 토의 4분, 성취도 평가·퀴즈 1분 → **03(5분, 18~23분)** 오남용 사례, 법 카드 훑어보기, 분류 5장, `misuseLaw` 한 줄 → **04(6분, 23~29분)** 세 가지 실천 방법 2분, 실천 점검·`myPlan` 3분(27분 무렵 끝), 분류 6장·퀴즈 1분 → 05(9분, 29~38분) 기사 읽고 개인 정보 찾기 4분, 성취도 평가·개념 정리 2분, 접어 둔 2·3번은 남는 시간 또는 과제 → 마무리(6분, 38~44분) 소단원 질문 답·퀴즈·질문폼, 여유 6분. 질문폼 근거 활동(0·02·03·04)은 모두 27분 무렵까지 끝남.

**선생님 준비물** — 05의 「선생님이 알려 주는 사이트」(한국인터넷진흥원의 정보 보호 법령 안내)를 칠판이나 학급 게시판으로 알려 주기. 그 밖의 외부 사이트·파일 없음.

**줄인 것** — 222쪽 확진자 개인 정보 유출·방침 그림은 안내문 항목만 본떠 장소·시간이 다른 새 예시 표로 그림. 223쪽 그림 Ⅴ-6은 탭, 224쪽 그림 Ⅴ-7은 흐름 상자, 225쪽 그림 Ⅴ-8은 글 카드로 바꿈(교과서 그림 파일은 쓰지 않음). 226쪽 설정 화면 캡처는 「설정 → 애플리케이션 / 설정 → 개인 정보 보호 및 보안」 경로 글로만. 227쪽 기사(실제 사건)는 옮기지 않고 같은 구조(서버 해킹 → 학생 정보 유출 → 수사 의뢰)의 가상 기사로 바꿈. 227쪽 개념 정리하기는 새 상황 문장 빈칸으로. 함께 해결하기·스스로 해결하기에는 예시 답을 넣지 않고 생각할 실마리 질문만 둠.

**확인할 점**
- 과정안(plan_Ⅴ-2) 2-1의 학습 목표가 2-2의 것(「정보 보안의 필요성을 설명할 수 있다 / 정보 보안 기술을 활용하여 디지털 윤리를 실천할 수 있다」)으로, 성취기준도 [12정05-03](진로 설계)으로 들어가 있음 → 교과서 223쪽 학습 목표를 씀. 과정안 정리 단계의 「228쪽 개념 정리하기」도 실제로는 227쪽.
- 226쪽 생각해 보기 「내 스마트폰의 개인 암호를 설정하거나 변경해 보자」 → 수업 중 실제 기기 설정을 바꾸게 하지 않는다는 제작 지침에 따라 「어디서 설정하는지만 떠올리고, 실제 암호는 어디에도 적지 않기」로 바꿈.
- 227쪽 스스로 해결하기 2번(법령 찾아 위반 내용 적기)은 법 조문을 화면에 만들어 넣지 않으려고 「관련 있다고 생각하는 법 고르기 + 소홀히 한 점 메모」로 하고, 조문 확인은 선생님이 알려 주는 사이트에서 하게 함. 법 고르기 칩에는 정답 표시가 없음(선생님이 수업에서 정리).
- 225쪽 법령 이름은 교과서 표기(「개인 정보 보호법」처럼 띄어 씀)를 따름. 실제 법령 이름은 「개인정보 보호법」처럼 붙여 쓰는 것이 있어, 학생이 사이트에서 찾을 때 띄어쓰기가 다를 수 있음.
- 224쪽 공유해야 할 정보에 「컴퓨터 바이러스 정보, 해킹 정보」가 있음 → 피해를 막기 위해 수법과 대처법을 알리는 정보로 풀어 「가짜 택배 문자 수법과 대처 방법」 카드로 씀.
- 223쪽 그림 Ⅴ-6의 「정보에 대한 책임 소재의 불분명」(개인·국가)과 「정보에 대한 책임 소재 불분명」(기업) 표기가 조금 다름 → 교과서대로 둠.
- md 변환본 227쪽 끝의 「정보 보안 / 주요 용어」는 228쪽 머리말(2-2 주요 용어)이 넘어온 것.

**검토 반영(1차)**
- 분량 줄임: 01 `leakNext` 메모 삭제, 02 분류 8→6장, 04 실천 점검·`myPlan`을 분류 게임 앞으로, 05의 2·3번을 「시간 되면」으로 접음(메모 모아 보기는 쓴 것만), 퀴즈 16→12문항(4-3·5-1·5-2·6-3 삭제, 05 화면 퀴즈 없음).
- 교과서 뼈대와 겹침: 퀴즈 2-1을 예산 공개 사례형, 2-3을 상황형(태풍 대피 안내/친구의 진료 기록/가족의 카드 번호)으로, 개념 정리 빈칸을 한 장면 문장으로 바꾸고 순서도 바꿈.
- 퀴즈 단서·오답: 3-2를 휴대폰 부정 이용 상황형으로(줄기 낱말과 정답 맞물림 없앰), 4-1·4-2 오답을 그럴듯하게 바꾸고 4-1 정답의 부정형·최장 해소.
- 질문폼 3번 근거로 03에 `misuseLaw` 한 줄 메모 추가.
