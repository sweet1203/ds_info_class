퀴즈 11문항(정답 위치 ①4 ②4 ③3).

**질문폼(info-u3-algorithm-efficiency)** — 1번 ← 01 두 알고리즘 비교 기록(`raceRec`), 2번 ← 02 어떤 O 표기법일까 분류·막대 비교, 3번 ← 03 하노이 탑 기록(`hanoiRec`)·모델링 괄호·규칙(`hanoiRule`).

**50분 흐름** — 도입(3분) 이야기·예상 고르기, `planFast` → 01(10분) 정의 카드 훑기, 짝짓기 슬라이더, n을 3가지 이상 바꿔 실행(질문폼 1번 근거, 13분 무렵 끝) → 02(8분) 내 기록 그래프로 O(n)·O(1) 확인, 네 가지 표기 막대, 분류 6장(질문폼 2번 근거, 21분 무렵 끝) → **03(21분 무렵 시작, 17분)** 원반 1·2·3개 직접 옮기기(현재 상태 확인) → 모델링 괄호 → 원반 4·5개 도전하며 표 채우기, 규칙·예측 메모(질문폼 3번 근거, 30분 무렵까지 원반 3~4개 기록) → 마무리(9분) 처음 생각과 비교, 퀴즈, 질문폼. 원반 5·6개와 자동 실행은 시간이 남는 학생용.

**줄인 것** — 99쪽 알고리즘 1 그림(1+2=3, 3+3=6 … 기억)은 「두 알고리즘 비교」 체험의 n·s 값 변화로 대신함. 99쪽 연산 횟수 표는 학생이 실행해 직접 만드는 기록 표로 바꿈. 100쪽 정비례·상수 그래프는 학생 기록으로 다시 그림. 100쪽 지식 키우기 표(n = 10, 100)는 n 슬라이더 막대로 바꿈(값은 계산으로 표시). 101쪽 성능 분석 표의 이동 횟수(교과서에 인쇄된 값)는 미리 보여 주지 않고 학생 기록으로 채움. 101쪽 개념 정리하기(문제 상태·추상화·문제 분해·모델링 용어)는 내용상 앞 화면 용어라서 u3-decompose-model의 04 화면에 새 문장 빈칸으로 넣음. 하노이 탑 모델링 괄호의 답은 공개 저장소에 넣지 않으려고 확인 기능을 두지 않음.

**선생님 준비물** — 없음. 하노이 탑 기록은 이 기기에만 저장되고, 요약(`hanoiRec`)은 메모처럼 진도 현황판으로 전송됨.

**확인할 점**
- 99쪽 알고리즘 1 그림은 「1+2=3」부터 시작해 덧셈이 9번 그려져 있지만, 단계 ❶(합 s = 0, 숫자 n = 1)과 본문 「n이 10이면 덧셈을 10번 수행」은 0 + 1부터 세어 10번임. 화면은 본문·표(연산 횟수 = n)를 따름.
- 99쪽 알고리즘 1 ❹ 「n이 10보다 작거나 같을 때」, 알고리즘 2 ❶ 「숫자(n) = 10」은 1부터 10까지의 예이므로, 화면에서는 n을 바꿔 실행하려고 「끝 수」로 일반화해 적음.
- 100쪽 지식 키우기 표의 값(n = 10, 100일 때 네 표기)은 계산이 맞음을 확인함.
- 100쪽 그래프는 모양만 보여 주는 그림이라 O(n) 직선이 O(n²)보다 처음에 위에 그려져 있음. 화면 그래프는 실제 값(n 0~10)으로 그려 O(n)이 O(n²)보다 처음부터 아래에 있음(n이 1보다 클 때 n² > n).
- 101쪽 성능 분석 표의 값과 일반식은 계산이 맞음을 확인함(화면에는 넣지 않음).
- 「컴퓨터로 옮겨 보기」(자동 실행)는 이동 횟수를 화면에 보여 주므로, 학생이 직접 기록한 원반 수에서만 열리게 했음(아직 안 해 본 원반 수의 횟수는 드러나지 않음).

**결정이 필요한 것** — 하노이 탑에서 학생 기록이 가장 적은 횟수보다 많으면 「더 적은 횟수로도 옮길 수 있어요」라고만 알려 줌(숫자는 알려 주지 않음). 이 안내도 빼기를 원하시면 알려 주세요.

**검토 반영(1차)**
- 하노이 탑 「컴퓨터로 옮겨 보기」: 원반 수 3가지 기록 조건 대신, 지금 고른 원반 수를 직접 옮겨 기록한 경우에만 그 원반 수를 자동 재생하도록 바꿈.
- 분류 해설(악수)을 「대략 n의 제곱에 비례」로.
- 01 체험에서 알고리즘 1의 현재 값을 「n = …」 대신 「지금 더한 숫자 = …」로 표시(끝 수 n과 헷갈리지 않게).
- 01 체험에 「기록 지우기」 버튼 추가(표·그래프·`raceRec` 함께 지움).
- 퀴즈: 3-2 줄기에 「2배씩」 단서가 있던 것을 「내가 기록한 하노이 탑 이동 횟수가 늘어나는 모양」으로 바꾸고 단서는 해설로 옮김. 1-1 해설에서 수행 시간 설명을 빼 4-1(수행 시간과 기억 공간)의 단서를 없앰.
