# u1-iot-design-1 설계표 — 사물 인터넷 시스템 설계 ① 장치 고르기와 연결 (교과서 34~37쪽)

교과서는 ESP32 + Thonny + 마이크로파이썬으로 실습한다. 우리 학교는 **라즈베리파이 피코 H(와이파이 없음) 스타터 키트, 1인 1키트 개인 실습**으로 바꾼다(선생님 확정). 핀 번호는 키트 매뉴얼 3장(온보드 LED 25번)·4장(빨간 LED 14번, 버튼 15번)을 그대로 따른다.

퀴즈 13문항(정답 위치 ①4 ②4 ③5). 질문폼(info-u1-iot-design-1) 1번 ← 01 분류·05 스마트 선풍기·`fanWhy`, 2번 ← 03 실습 ② 또는 깜박이기 시뮬레이션·`ledMemo`, 3번 ← 04 버튼 시뮬레이션(실물은 선택)·`btnMemo`. 2·3번 문항은 「실물 또는 화면 시뮬레이션」으로 써서 하드웨어가 늦은 학생도 답할 수 있게 함.

**50분 흐름** — 도입(3분) 빈 교실 이야기·준비물 확인 → 01(6분) 입출력 설계·분류 게임 → **02(9분 무렵 시작, 14분)** Thonny 첫 연결(인터프리터 고르기, 케이블·포트 문제 해결 포함)·온보드 LED → **03(23분 무렵 시작, 10분)** 회로 꾸미기·깜박이기, 시뮬레이션으로 시간 바꾸기 → 04(33분 무렵 시작, 5분) 버튼 시뮬레이션은 모두, 실물은 실습 ②를 마친 학생만 → 05(4분) 선풍기·빈칸 → 마무리(8분) 퀴즈·질문폼. Thonny 첫 연결이 오래 걸리는 것을 고려해 02를 14분으로 잡았다. 질문폼 2번 근거(03)는 23~33분에 닿으므로, 하드웨어가 늦은 학생은 03 시뮬레이션으로 먼저 메모를 쓰게 한다.

**교과서 ESP32 코드와 피코 코드의 차이**
| | 교과서(ESP32) | 우리(피코 H) |
|---|---|---|
| 36쪽 LED 깜박이기 | `Pin(2, Pin.OUT)` (외장 LED 모듈 S → D2) | `Pin(14, Pin.OUT)` (GP14 = 보드 핀 19, 저항 220Ω 따로) |
| 온보드 LED | – | `Pin(25, Pin.OUT)` (피코 H 온보드 LED, 매뉴얼 3장) |
| 버튼 | 교과서에 없음 | `Pin(15, Pin.IN, Pin.PULL_DOWN)` (GP15 = 보드 핀 20, 대각선 다리 3V3 = 보드 핀 36) |
| 시간 모듈 | `import time` | 매뉴얼은 `import utime`이지만 교과서와 같게 `import time`으로 씀(피코 마이크로파이썬에서 둘 다 동작) |
| 와이파이 | ESP32에 있음 | 피코 H에 없음 → design-2에서 다룸 |
- 버튼 코드는 매뉴얼 4장(누르면 2초 켜짐) 대신 교과서 37쪽 인체 감지 센서 코드와 같은 if/else 모양으로 바꿨다(다음 시간에 버튼 자리만 센서로 바꾸면 되도록). 반복마다 `time.sleep(0.1)`을 넣음.
- GND는 매뉴얼 그림처럼 핀 38→전원 레일을 써도 되지만, 그림을 단순하게 하려고 LED 바로 옆 GND(보드 핀 18)로 그렸다(화면에 「GND 핀은 여러 개라 가까운 것을 써도 돼요」).

**줄인 것** — 36쪽 「지식 키우기」 Thonny·마이크로파이썬 설치는 학교 PC 상황에 따라 「선생님 안내에 따라」로만 안내(설치 사이트 주소는 화면에 넣지 않음). 교과서 QR 결과 영상은 화면 시뮬레이션으로 대신함. 매뉴얼 4장 실습(3) LED 신호등·챌린지 미션은 넣지 않음. 교과서 35쪽 ESP32 회로 연결표는 다음 시간(design-2) 핀 대응표에 한 열로 넣음. 37쪽 인체 감지 센서 실습은 design-2로 넘김(차시 계획: 34~37쪽 중 장치 고르기·연결까지).

**확인할 점**
- 35쪽 인체 감지 센서 적외선 파장은 PDF 원문에 「약 10μm」로 바르게 되어 있다(텍스트 추출본에서 μ가 깨져 「10mm」로 보였던 것). 교과서 오류 아님. 화면은 파장 숫자 없이 「적외선의 변화를 이용」으로 씀.
- 34쪽 LED 설명은 PDF 원문도 「전류가 흐르는 때」(오탈자, 「흐를 때」가 자연스러움). 화면은 바로잡아 씀.
- **저항 값**: 키트 매뉴얼 4장 회로 그림의 저항 색 띠가 빨강-빨강-갈색(220Ω)이다. 매뉴얼 준비물 사진(파란 5띠 저항)은 띠를 읽을 수 없고 본문에도 값이 없다. 화면에는 220Ω으로 적었으니 **키트 실물 저항 값 확인 필요**(다르면 준비물·회로표·회로 그림 글자 세 곳을 바꾸면 됨).
- 분류 게임 세 번째 묶음은 「마이크로컨트롤러」로 유지(선생님 확정). 교과서 35쪽 「입출력 장치는 마이크로컨트롤러에 연결하여 제어할 수 있다」.
- 버튼 코드는 매뉴얼 4장(누르면 2초 켜짐) 대신 교과서 37쪽과 같은 if/else 모양으로 유지(선생님 확정).
- 핀 배치: design-2는 LED를 GP14 그대로 두고 버튼만 빼며, 부저를 GP15에 꽂는다(선생님 결정). 매뉴얼 5장(LED 15·부저 14)과 다르다.
- `Pin.PULL_DOWN`은 교과서에 없는 말이라 개념으로 가르치지 않고 「누르지 않았을 때 값이 0으로 안정되게 하는 설정」 한 줄로만 설명.
- 매뉴얼 3장은 처음 연결할 때 BOOTSEL을 누르라고 하지만, 이는 마이크로파이썬을 처음 설치할 때만 필요하다. 화면에는 「처음 설치할 때만」으로 씀.
- 37쪽 「함께 해결하기」 스마트 선풍기의 입력 장치(온도 측정)는 교과서 26쪽에 「온습도 센서」로 나온다. 화면에서는 고르기만 하고 정답을 보여 주지 않음(모둠 토의용).
- 3V3 경고: 버튼을 5V(핀 39 VSYS·40 VBUS)에 연결하면 GP15에 3.3V보다 높은 전압이 들어가 보드가 상할 수 있고, 핀 37(3V3_EN)은 전원 끄기용 핀이라 화면에 「꽂지 않아요」 경고를 넣음.

**검토 반영(2차)**
- 이 차시는 2차 검토에서 고칠 것 없음. 핀 배치 결정(design-2는 LED GP14 그대로·버튼 빼기·부저 GP15)과 이어지는지 다시 확인함.
