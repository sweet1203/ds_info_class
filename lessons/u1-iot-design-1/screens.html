💡

LED

전원을 연결하여 전류가 흐를 때 빛을 내는 반도체 소자예요. 극성이 있어서 방향을 맞춰 꽂아야 해요.

• 긴 다리가 +극, 짧은 다리가 −극이에요. +쪽을 VCC(전압)에, −쪽을 GND(접지)에 연결해요.
• 과도한 전류가 흐르면 쉽게 망가지므로 저항을 함께 써서 전류를 제한해요. 저항이 내장된 LED는 저항을 따로 연결하지 않아도 돼요.

어디에 쓰일까? 신호등, 자동차 헤드라이트, 스마트 가로등, 전광판
🚶

인체 감지 센서

적외선을 통해 사람의 움직임을 감지하는 입력 센서예요. 사람 몸(표면 온도 20~35℃)에서 나오는 적외선의 변화를 이용해요. 우리 키트에서는 PIR 센서라고 불러요.

• 가변 저항 두 개로 조절해요. 하나는 감도(최대 7m 거리까지 감지), 다른 하나는 감지 유지 시간(0.3초~5분)이에요.

02

피코와 Thonny 준비

교과서 26·36쪽 · 마이크로컨트롤러와 마이크로파이썬

쉽게 말하면피코에게 명령하려면 두 가지가 필요해요. 내 컴퓨터에서 코드를 쓰는 프로그램 Thonny, 그리고 피코 안에서 파이썬을 알아듣게 해 주는 마이크로파이썬이에요.
🧠

마이크로컨트롤러

소형 CPU와 입출력 모듈을 하나의 칩으로 구성하여 사용자가 원하는 기능을 수행하는 작은 컴퓨터예요. 라즈베리파이 피코, ESP32, 아두이노가 모두 마이크로컨트롤러예요.

🐍

마이크로파이썬

하드웨어를 제어하는 기능을 제공하는 파이썬용 펌웨어예요. 마이크로컨트롤러마다 구성이 달라서 보드에 맞는 마이크로파이썬을 설치해야 해요.

⚖️ 교과서의 ESP32와 우리의 피코 H

코드의 모양은 거의 같아요. 장치를 연결한 핀 번호만 우리 보드에 맞게 바꿔요. 와이파이가 없다는 점은 다음 시간에 다시 이야기해요.

🛠️ 준비하기 (선생님 안내에 따라)

  1. Thonny 열기

    학교 컴퓨터에는 이미 설치되어 있을 수 있어요. 없으면 선생님 안내에 따라 설치해요.

  2. 피코를 USB 케이블로 컴퓨터에 연결하기

    처음 마이크로파이썬을 설치할 때만 보드의 BOOTSEL 버튼을 누른 채로 연결해요. 이미 설치되어 있다면 그냥 꽂아요.

  3. Thonny 오른쪽 아래에서 인터프리터 고르기

    「MicroPython (Raspberry Pi Pico)」를 골라요. 마이크로파이썬이 없다고 나오면 선생님 안내에 따라 「Install MicroPython」으로 설치해요.

  4. 아래쪽 셸(Shell)에 >>>가 보이면 준비 끝

    셸에 print('hello')를 입력하고 Enter를 눌러 보세요.

🧪 실습 ① 피코 보드 위 LED(온보드 LED) 켜기

피코에는 보드 자체에 작은 LED가 하나 있어요. 회로를 꾸미지 않고도 바로 켜 볼 수 있어요. 아래 코드를 직접 입력해요.

from machine import Pin
led = Pin(25, Pin.OUT)
led.value(1)
1하드웨어를 다루는 machine 모듈에서 Pin을 준비해요.
225번 핀(온보드 LED)을 출력(Pin.OUT)으로 정해 led라는 이름을 붙여요.
3값을 1로 정해 LED를 켜요. 0이면 꺼져요.
  1. 코드를 입력하고 초록색 ▶ 실행을 눌러요. 저장할 곳을 물으면 선생님 안내대로 골라요.
  2. 보드 위 LED가 켜졌는지 확인해요.
  3. 3줄의 1을 0으로 바꿔 다시 실행해요.
🆘 막혔을 때 확인할 것 (눌러서 펼치기)
  • 「장치를 찾을 수 없어요」, 셸에 >>>가 안 보여요 → 오른쪽 아래 인터프리터(포트)를 다시 골라요. 목록에 피코가 없으면 케이블을 뺐다가 다시 꽂아요.
  • 케이블을 꽂아도 반응이 없어요 → 충전만 되는 케이블일 수 있어요. 다른 케이블로 바꿔 봐요.
  • 「Backend is busy」 같은 말이 나와요 → 빨간 ■ 정지를 누른 뒤 다시 실행해요.
  • 오류 메시지가 나와요 → 마지막 줄의 줄 번호를 보고 그 줄을 확인해요. 대소문자(Pin, OUT), 괄호, 쉼표, 따옴표를 하나씩 비교해요.
  • 보드에 마이크로파이썬이 없대요 → 선생님께 알려요. 함께 설치해요.
03

LED 켜고 끄기

교과서 34·36쪽 · 출력 장치를 핀에 연결하고 제어하기

쉽게 말하면LED를 피코의 한 핀에 연결하고, 그 핀의 값을 1로 하면 켜지고 0으로 하면 꺼져요. 사이에 기다리는 시간을 넣고 계속 반복하면 LED가 깜박여요.

🔧 회로 연결하기

부품피코 연결
LED 긴 다리(+)저항(220Ω)을 거쳐 GP14 (보드 핀 19)
LED 짧은 다리(−)GND (보드 핀 18)
번호가 두 가지예요. 코드에 쓰는 번호는 GP 번호(GP14 → 14)예요. 보드 가장자리 순서대로 센 보드 핀 번호(19)와 달라요. GND 핀은 여러 개라 가까운 것을 써도 돼요.

피코는 브레드보드 가운데 홈에 걸쳐 꽂고, 선은 쓰려는 핀과 같은 세로줄 구멍에 꽂아요. 브레드보드는 세로 다섯 구멍이 한 줄로 이어져 있어서 부품 다리도 같은 줄에 꽂아야 연결돼요.

🧪 실습 ② LED를 1초마다 켜고 끄기

from machine import Pin
import time
LED = Pin(14, Pin.OUT)
while True:
    LED.value(1)
    time.sleep(1)
    LED.value(0)
    time.sleep(1)

5~8줄 앞은 네 칸 들여쓰기해요. Thonny는 while True: 다음 줄을 자동으로 들여 써 줘요.

2시간을 기다리는 데 쓰는 time 모듈을 준비해요.
314번 핀(GP14)을 LED의 출력으로 정해요.
4아래 들여 쓴 줄들을 끝없이 반복해요.
5·7값 1(HIGH)이면 켜기, 0(LOW)이면 끄기
6·8괄호 안의 초만큼 기다리기

교과서 36쪽 코드와 같아요. 교과서는 ESP32의 2번 핀, 우리는 피코의 14번 핀을 써요.

▶ 실행하기 전에 화면에서 먼저 돌려 보기

LED.value = 0
기다리는 시간
▶ 실행을 누르면 위 코드가 한 줄씩 실행되는 모습을 보여 줘요.
  1. 회로를 꾸미고, 코드를 입력해 실행해요. LED가 1초마다 켜졌다 꺼지나요?
  2. 6·8줄의 1을 다른 수로 바꾸기 전에 결과를 먼저 예측하고 실행해요.
  3. 멈출 때는 Thonny의 ■ 정지를 눌러요.
🆘 LED가 켜지지 않을 때 (눌러서 펼치기)
  • 다리 방향 → 긴 다리(+)가 저항 쪽, 짧은 다리(−)가 GND 쪽인지 확인해요. 반대로 꽂으면 켜지지 않아요.
  • 같은 줄 → 저항 끝과 LED 긴 다리가 브레드보드의 같은 세로줄에 있는지 봐요. 가운데 홈을 건너면 이어지지 않아요.
  • 핀 번호 → 선을 꽂은 곳이 GP14(보드 핀 19)인지, 코드의 숫자가 14인지 맞춰 봐요.
  • 코드는 도는데 반응이 없어요 → 온보드 LED 코드(25번)로 보드가 살아 있는지 먼저 확인해요.
04

버튼으로 LED 켜기

교과서 37쪽 코드 구조로 · 입력에 따라 출력 바꾸기

이 화면은 이렇게 해요. 아래 화면 시뮬레이션은 모두 해 봐요. 실물 버튼 회로는 실습 ②(LED 깜박이기)를 마친 사람만 이어서 해요.
쉽게 말하면버튼은 누르면 1, 떼면 0을 보내는 입력 장치예요. 마이크로컨트롤러가 if 문으로 입력값을 확인해서 LED를 켜거나 꺼요. 다음 시간에 버튼 자리에 인체 감지 센서를 넣으면 스마트 조명이 돼요.

🔧 회로에 버튼 더하기

부품피코 연결
LED그대로 (GP14 · GND)
버튼 다리 하나GP15 (보드 핀 20)
그 대각선 쪽 다리3V3 (보드 핀 36)

버튼은 브레드보드 가운데 홈에 걸쳐 꽂아요. 다리가 네 개인데, 대각선으로 마주 보는 두 다리를 쓰면 방향과 상관없이 연결돼요. 버튼을 누르면 GP15와 3V3이 이어지면서 GP15의 값이 1이 돼요.

⚠️ 버튼 선은 3V3(보드 핀 36)에만 꽂아요. 핀 39·40(5V)과 핀 37(3V3_EN)에는 꽂지 않아요.

🧪 실습 ③ 버튼을 누르는 동안 LED 켜기 (실물은 실습 ②를 마친 사람)

from machine import Pin
import time
LED = Pin(14, Pin.OUT)
BTN = Pin(15, Pin.IN, Pin.PULL_DOWN)
while True:
    if BTN.value() == 1:
        LED.value(1)
    else:
        LED.value(0)
    time.sleep(0.1)
415번 핀을 버튼의 입력(Pin.IN)으로 정해요. Pin.PULL_DOWN은 버튼을 누르지 않았을 때 값이 0으로 안정되게 하는 설정이에요.
6버튼의 값이 1이면(누르고 있으면)
7LED 켜기
8·9그렇지 않으면 LED 끄기
100.1초 쉬고 다시 확인해요.

▶ 화면 시뮬레이션 (모두)

BTN.value() = 0LED.value = 0
왼쪽 버튼을 누르고 있으면 코드의 어느 줄이 실행되는지 위 코드 상자에 표시돼요.
  1. 모두 · 시뮬레이션 버튼을 눌렀다 떼며 6~9줄 중 어느 줄이 실행되는지 확인해요.
  2. 모두 · 7줄과 9줄의 1과 0을 서로 바꾸면 어떻게 될지 예측해 메모해요.
  3. 실물(실습 ②를 마친 사람) · 버튼을 꽂고 코드를 입력해 실행하고, 예측이 맞는지 확인해요.
🆘 버튼을 눌러도 반응이 없을 때 (눌러서 펼치기)
  • 버튼 다리 → 대각선 두 다리에 선을 연결했는지 봐요. 가운데 홈에 걸쳐 있어야 해요.
  • 3V3 자리 → 보드 핀 36(3V3)인지 확인해요. ⚠️ 핀 39·40(5V)과 37(3V3_EN)에는 꽂지 않아요.
  • 철자 → Pin.IN, Pin.PULL_DOWN의 대문자와 밑줄을 확인해요.
  • LED가 계속 켜져 있어요 → 4줄에 Pin.PULL_DOWN이 빠졌는지 봐요.

🌀 함께 해결하기: 스마트 선풍기

온도가 내려가면 선풍기(모터)가 자동으로 꺼지는 스마트 선풍기에 필요한 장치를 구성해 봐요. 교과서 26쪽 센서와 모터 설명을 참고해요.

📝 개념 정리하기 (빈칸을 눌러 확인)

  1. 복도에 사람이 지나가면 불이 켜지게 하려고, 몸에서 나오는 적외선의 변화로 움직임을 알아채는 를 천장에 달았다.
  2. 이 복도 조명에서 움직임 값을 받아들이는 센서는 , 불을 켜고 끄는 LED는 이다.
  3. 센서 값을 받아 판단하고 LED에 명령을 보내는 피코 같은 작은 컴퓨터를 라고 한다.
  4. 새로 산 피코에서 파이썬 코드를 실행하려면 먼저 보드에 맞는 을 설치해야 한다.
