퀴즈 11문항(정답 위치 ①4 ②4 ③3). 질문폼(info-u4-human-ai) 1번 ← 01 시기 분류·`roleChange`, 2번 ← 02 자전거 대여소 분류·`bikeWhy`, 03 기사·`goodPts`, 3번 ← 03 토의 `badPts`. 선택 활동(Frozen Lake·로봇 고양이)은 퀴즈·질문폼이 묻지 않음.

**코랩 노트북** `assets/frozenlake_agent.ipynb` — ① 라이브러리 설치(`gymnasium[toy-text]`) ② 불러오기 ③ 환경 만들기(지도 출력) ④ 무작위로 움직이는 에이전트 애니메이션(교과서 예제, 200걸음) ⑤ **스스로 해결하기**: 4번 코드를 복사해 그림 그리는 줄을 지우고 반복 횟수를 늘려 「100판에 몇 번꼴로 도착하는지」 어림하기(빈 셀 + 말로 된 힌트, 정답 코드 없음) ⑥ 관찰 정리(마크다운 — 무작위 에이전트에게 없는 단계도 적기) ⑦ **더 해 보기(선택)**: 「코드를 다 이해하지 않아도 된다」 안내, 점수표로 경험에서 배우는 에이전트 5000판 연습 → 칸별 행동 화살표 → 배운 에이전트 100판 결과(무작위 쪽 값은 계산하지 않고 5번에서 어림한 값과 견주기) → 배운 에이전트 애니메이션. 출력은 비움.
로컬에 gymnasium·pygame이 없어, 같은 규칙(4×4 지도, 미끄러지면 원하는 방향 또는 양옆으로 1/3씩, 100걸음 제한)의 흉내 환경으로 코드 셀을 모두 실행해 오류 없음을 확인함(설치 셀 제외). 그때 배운 에이전트는 100판 중 69~74번 도착(서너 판에 한 판꼴 실패), 5번 힌트대로 4번 코드를 고친 것도 오류 없이 돌아감(3000걸음에 385판 중 3번 도착). 실제 코랩 실행은 확인하지 못함.

**50분 흐름** — 도입(3분) 처음 생각 → 01(9분) 시기 버튼 3개, 분류 게임, `roleChange` → 02(8분) 세 측면 표·태양열 탭, 자전거 분류, `bikeWhy` → **03(20분 무렵 시작, 11분)** 기사 읽기 3분, 토의 1·2 메모(26분 무렵까지 `badPts`), 개념 정리·성취도 평가, 퀴즈. 사례 정리 표(검색 필요)는 접어 두고 시간 되면 → 04(10분) 맞춤 활동 1·3과 성취도 점검, 2번 개발 역할 표는 접어 두고 시간 되면. 선택 활동은 시간이 되는 만큼(코랩은 처음 열고 설치하는 데 2~3분 걸리므로 남는 시간이나 과제로, 브라우저의 직접 건너기로 대신할 수 있음) → 마무리(9분) 학업 계획 점검·퀴즈·질문폼.

**줄인 것** — 170~171쪽 연대표는 시기 버튼으로 하나씩 보기. 173쪽 기사는 원문을 옮기지 않고 요약, 출처 주소는 쓰지 않음. 173쪽 토의 1·2번과 174쪽 맞춤 활동의 「예」 답, 175쪽 보충·심화의 「예」 답은 옮기지 않음(다른 실마리 문장만 줌). 개념 정리하기 문장은 새 상황 문장으로. 175쪽 교과서 노트북의 xvfb·atari 설치 줄은 Frozen Lake 그림 그리기에 필요 없어 뺌.

**확인할 점**
- 과정안 1-2의 학습 목표가 「정보 과학 분야의 직업에 대해 설명할 수 있다 / 미래 사회의 변화를 반영하여 진로 선택을 할 수 있다」로 다른 단원 것이 들어가 있음 → 교과서 170쪽 학습 목표를 씀.
- 175쪽 교과서 노트북은 「#5.학습」이라는 제목 아래 `env.action_space.sample()`로 무작위 행동만 하므로 실제로는 학습이 일어나지 않음(교과서 본문은 「지능 에이전트가 학습하는 과정을 관찰해 보자」) → 노트북에서 「무작위로 움직이는 에이전트」로 이름을 바로잡고, 학습하는 모습은 「더 해 보기(선택)」의 점수표 에이전트로 보여 줌. 이 부분은 교과서에 없는 방법(강화학습의 한 방법)을 쉬운 말로만 풀어 쓴 것이라 선택으로 두고 퀴즈·질문폼에서 묻지 않음. 빼도 되는지 선생님 확인 필요.
- 175쪽 「Open AI Gym 게임」 → 지금은 gymnasium 라이브러리로 이어짐(교과서 노트북도 gymnasium을 씀). 화면에는 라이브러리 이름만 노트북 안에 씀.
- 171쪽 「데이터 기반 인공지능」 띠는 1980~1990년대와 2000년대 이후 두 칸에 걸쳐 있음(PDF 확인) → 두 시기 모두 데이터 기반으로 표시하고, 시기 이름은 「도약: 기계학습의 활용」, 「현재: 딥러닝 및 생성형 인공지능의 발전」을 따름.
- 173쪽 개념 정리하기 md는 빈칸 배치가 섞여 있음(주요 용어 6개 → 규칙 기반 1개, 미래에 중요시될 것 2개, 협력 영역 3개로 보고 새 문장을 만듦).
- 172쪽 표 Ⅳ-5 「발생 또는 절차상의 문제가 없는지 예측」은 뜻이 조금 어색하지만 교과서대로 둠.
- 172쪽 함께 해결하기 3번(협력 사례 찾기)은 인터넷 검색이 필요할 수 있어 「교과서, 뉴스, 선생님이 알려 주는 사이트」로 안내하고, 찾기 어려우면 02의 자전거 대여소 사례로 해도 되게 함.

**검토 반영(1차)** — 노트북 7번 비교 셀에서 무작위 에이전트 계산을 빼고 「5번에서 어림한 값과 견주기」로(5번 과제의 답이 드러나지 않게), 5번은 4번 코드를 조금 고치는 수준의 말로 된 힌트로 가볍게. 7번에 「코드를 다 이해하지 않아도 돼요」, 실패 빈도를 실제(서너 판에 한 판꼴)에 맞춤, 쓰지 않는 display import 삭제. 보충 메모(flP~flA)와 노트북 6번 안내를 「직접 건너 본 나(또는 잘 건너는 지능 에이전트)라면 + 무작위 에이전트에게 없는 단계도」로. 03 사례 정리 표·04 개발 역할 표를 「시간 되면」으로 접음. 퀴즈 1-1 오답에도 「규칙」을 넣고, 1-2 줄기를 「의사나 기술자의 지식을 규칙으로 넣어 그 사람처럼 답하게 만든 것」으로. 자전거 카드 「미처 떠올리지 못한」. 메모 모아 보기에서 접어 둔 표·보충·심화 메모는 쓴 묶음만 보이게. Frozen Lake 시도 횟수를 「한 번이라도 움직인 시도」로 세어 「처음 자리로」를 언제 눌러도 맞게. 쓰지 않는 클래스 정리.
