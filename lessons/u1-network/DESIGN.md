퀴즈 15문항(정답 위치 ①5 ②5 ③5). 질문폼(info-u1-network) 1번 ← 03 단계별 보기, 2번 ← 02 sorter·`wiredWireless`, 3번 ← 04 DHCP 체험·`dhcpNote`(05 내 기기 기록은 덧붙이기).

**50분 흐름** — 도입(4분) 단원 도입은 핵심 질문·2030 학교만 짚고 투표, 1969년 이야기, `planNet` → 01(7분) 주소 구조·도메인, 분류 게임 → 02(8분) 교실 구성도 따라가기, 유무선 표, 분류 게임, `wiredWireless` → 03(5분) 단계별 보기 → 04(8분) 표 Ⅰ-1, DHCP 체험(자동으로 5대 연결 → 주소 부족·반납 → 직접 입력으로 충돌 만들기), `dhcpNote` → **05(32분 무렵 시작, 10분)** 내 기기 확인·기록, ping, 빈칸 → 마무리(8분) 퀴즈·질문폼. 질문폼 근거 활동(02·03·04)은 32분 안에 모두 지나가고, 05의 내 기기 기록은 3번에 덧붙이는 자료.

**줄인 것** — 「알고 있나요?」(중학교 복습)와 이 단원의 핵심 역량 목록은 넣지 않음. 2030 학교 시스템은 카드 없이 한 문장과 투표로만. 생각해 볼까요?의 만화 대사는 줄글로만. 운영체제별 설정 화면(그림 Ⅰ-3~Ⅰ-6)은 그림 대신 경로 글로 설명. 교과서 개념 정리하기 문장은 그대로 옮기지 않고 새 문장 빈칸으로.

**확인할 점**
- 16쪽 옆 설명 IPv4 예 「255.168.1.130」은 표 Ⅰ-1의 「192.168.1.130」과 달라 오타로 보임 → 화면에서는 192.168.1.130을 씀.
- 16쪽 IPv6 예 「FDCB:BA78:0005:2340:BBFF:0000:ASDD:FFFF」의 「S」는 16진수 숫자가 아님 → 화면에서는 16진수만 쓴 다른 예(2001:0DB8:…)를 씀.
- 15쪽 WAN 범위 「수십 km의 … 도시를 벗어난 범위」 → 화면에서는 「수십 km 이상, 도시를 벗어난 범위」로 풀어 씀.
- 13쪽 도메인 예 www.ebs.co.kr(표 Ⅰ-1에서는 EBS.co.kr로 표기가 다름). 개념 설명용 교과서 예시라 구성 그림에만 그대로 두고 링크는 걸지 않음. 분류 게임의 도메인은 www.○○○.go.kr처럼 기관 이름을 가림.
- 14쪽 그림 Ⅰ-1(PDF 7쪽): A 학교는 노트북 무선(AP 경유)·컴퓨터·프린터 유선, B 학교는 노트북·컴퓨터 유선(스위치), 스마트폰·프린터 무선. 데이터 길은 A 노트북→AP→스위치→라우터→B 스위치→B 노트북으로 그림(1차 검토에서 B 노트북·프린터 연결 방식 바로잡음).
- 17쪽 함께 해결하기는 윈도 명령 프롬프트(ping)만 안내함. 학교 PC에서 cmd가 막힐 수 있어 「건너뛰어도 된다」로 안내하고, IP 주소 찾는 길은 운영체제별 설정 화면으로 안내. 윈도에서 명령 프롬프트가 열리면 `ipconfig`로도 볼 수 있다는 한 줄을 덧붙임(교과서에 없는 명령어 — 빼려면 lesson.js `DEVPATH` 윈도 항목의 회색 문장 삭제).
- 05의 IP 주소·게이트웨이 등 메모는 진도 현황판으로 전송됨. 교내망·가정 공유기의 사설 주소가 대부분이지만, 집에서 휴대폰 데이터로 접속하면 공인 주소가 적힐 수 있음.

**검토 반영(2차)** — 퀴즈 1-3 해설에서 「32비트」를 빼 마무리 6-3의 답이 드러나지 않게 함. 05 빈칸 1번을 게이트웨이와 헷갈리지 않게 라우터 고유 표현(여러 갈래 길 가운데 가장 효율적인 길)으로 바꿈. 02 구성도의 라우터 설명을 01 정의에 맞춰 「서로 다른 네트워크를 연결하고 효율적인 길을 알려 줘요」로 바꿈(교과서 그림의 말풍선 「근거리 내 여러 기기 간의 네트워크 연결을 도와준다」는 공유기 설명에 가까워 쓰지 않음). IP 확인기에서 마스크·게이트웨이 칸에 콜론을 넣으면 내부 코드(v6)가 보이던 것을 고치고, 게이트웨이 형식 오류도 안내함.
