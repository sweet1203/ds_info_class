# u1-review 설계표 — 협력적 창의·융합 프로젝트 · Ⅰ단원 정리 (교과서 42~45쪽)

50분 한 차시 안에서 모둠 설계 메모(문제 → 필요한 센서·장치 → 동작 과정 → 기대 효과)와 발표 준비까지, 진로 카드(44쪽), 단원 정리(45쪽) 퀴즈를 한다. 모둠 활동이지만 메모는 각자 화면에 적는다(질문폼은 개인).

| 화면 | 교과서 쪽 | 핵심 내용 | 체험·활동 | 퀴즈 | 메모 칸 |
|---|---|---|---|---|---|
| 0 시작 | 8·10·42쪽 | 프로젝트 「미래의 학교 공간을 설계해 볼까?」 소개, 모둠명·역할, 단원 핵심 질문 2개(8쪽: 네트워크 / 사물 인터넷 시스템), 50분 계획 | 모둠 정하기 | – | `team` `roles` |

| 06 마무리 | – | key3, 단원 핵심 질문 답, 마무리 퀴즈, 결과표, 질문폼, 메모 모아 보기 | – | 3 | `keyQ` |

퀴즈 10문항(정답 위치 ①4 ②3 ③3). 01·04는 프로젝트 활동 화면이라 퀴즈를 두지 않았다. 질문폼(info-u1-review) 1번 ← 01·02 설계 카드(`why` `dSensorPick`…`cHow`), 2번 ← 02 `flow` `effect` `caution`, 3번 ← 03 진로 카드 `career` `careerSkillPick`(진로를 발표 준비 앞으로 옮겨 23~28분에 닿게 함).

**50분 흐름** (화면 0 「50분 계획」과 같음) — 모둠 정하기(2분) → 01 문제 발견(7분, ~9분) → **02 시스템 설계(14분, ~23분)** D·N·P·C 고르기, 동작 과정·효과 적기, 설계 카드 완성 → **03 진로(5분, ~28분)** 인터뷰 카드·진로 카드 → 04 발표 준비(7분, ~35분) 1분 대본·자기 평가(실제 발표·동료 평가는 선생님 운영: 시간이 되는 모둠만 또는 다음 시간 앞부분) → 05 단원 정리(8분, ~43분) 분류 게임·퀴즈 → 마무리(7분) 질문폼.

**줄인 것** — 43쪽 「설계한 시스템의 작동 과정을 그림으로」는 화면의 설계 카드로 대신함(그림은 공책·발표 자료에 그려도 됨). 모든 모둠의 발표는 50분 안에 어렵기 때문에 발표 준비까지만 화면에 두고, 발표·동료 평가는 선생님 운영에 맡김. 45쪽 단원 정리 11문항은 형성평가 문항이므로 옮기지 않았다. 같은 개념(라우터, LAN, 게이트웨이, 스마트팜, D·N·P·C)을 **상황 문장**(옆 학교로 파일 보내기, 노트북 네트워크 설정 칸, 딸기 비닐하우스, 급식실 줄 알림, 교실 미세 먼지 측정기 등)으로 새로 써 퀴즈와 분류 게임에 넣음. 정답(238쪽)은 넣지 않음. 1차 검토에서 45쪽 문장과 겹친다고 지적된 퀴즈 4개·분류 2개를 상황 문장으로 바꿈.

**확인할 점**
- 42~43쪽의 예(도서관 빈자리, 압력 센서·와이파이·앱 프로그램·좌석 알림)는 교과서 예시 답안이라 화면에 옮기지 않았다. 대신 지난 시간 실습과 이어지는 「교실 뒤 사물함 쪽이 어둡다」를 입력 칸 안내 예로 씀.
- 43쪽 평가 기준 「문제의 초기 상태와 목표 상태를 파악하였는가?」는 이 단원에서 「초기 상태·목표 상태」를 따로 가르치지 않는다(정보 교과의 문제 해결 용어). 평가 기준이므로 문장은 그대로 두었다.
- 44쪽 인터뷰의 「항상 새로운 지식을 배우려는 열정」은 퀴즈 보기에서 극단어(항상)를 빼고 「새로운 지식을 배우려는 열정」으로 씀.
- 45쪽 2번 문장 「모든 사물 간에 인터넷 연결이 가능하게」(29쪽 개념 정리와 같음)는 25쪽 본문 「사물 간에 정보 교류가 가능하게」와 표현이 다르다. 화면은 25쪽 본문 표현을 따름.
- 단원 핵심 질문은 8쪽 단원 도입(네트워크·사물 인터넷 시스템 두 질문)을 따름(이름표도 「네트워크」로). 마무리 메모는 사물 인터넷 시스템 질문 하나만 받음.
- 마무리 퀴즈 첫 문항은 design-2 마무리 퀴즈(ESP32 → 디바이스)·분류 게임 첫 문장과 답이 겹치지 않도록 「서비스(C)」를 묻는 급식실 상황으로 바꿈. 피코 조명을 디바이스라고 한 해설은 지움(design-2 결정: D의 일부, 통신 모듈 없음).
- 분류 게임의 RFID 문장은 통신 기술이 주어가 되게 바꿈(「RFID 무선 통신이 … 결제 정보를 실어 나른다」).
- 교과서는 「스마트팜」(붙여 씀, 32쪽)과 「스마트 홈」·「스마트 시티」(띄어 씀)를 섞어 씀. 화면도 교과서대로 둠.

**검토 반영(2차)**
- 5번 묶음 둘째(LAN) 문항을 14쪽 문장 대신 상황 문장(학교 본관 건물 안 컴퓨터실·교무실을 유선과 와이파이로 묶은 네트워크)으로 바꿈.
