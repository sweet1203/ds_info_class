퀴즈 15문항(정답 위치 ①5 ②5 ③5).

**질문폼(info-u3-searching)** — 1번 ← 01 데이터 구조 분류, 2번 ← 02~04 시뮬레이터 기록(`seqRec`·`binRec`·`nameRec`), 3번 ← 04 실생활 사례(`realSeq`·`realBin`).

**시뮬레이터 확인** — 이진 탐색은 mid = (low + high)의 몫, 같으면 반환·크면 low = mid + 1·작으면 high = mid − 1. 교과서 예(5 찾기)는 교과서와 같은 3번 비교, 「리스트가 커지면?」 표는 교과서 111쪽 표와 같은 값. 이름 겨루기의 이진 탐색은 교과서 112쪽과 같은 방법(12명이므로 0번과 11번의 중간 → 5번부터). DFS·BFS 순서는 이웃을 알파벳 순서로 골라 node로 확인함. 115쪽 형식 확인 표의 정답은 화면 코드가 계산함(새 리스트라 교과서 답과 관계없음).

**50분 흐름(검토 반영 후)** — 도입(3분) 도입 질문·`planSearch` → **01(6분, 글 줄임)** 탐색 카드 훑기, 데이터 구조 카드 뒤집기, 분류 6장(질문폼 1번 근거, 9분 무렵 끝) → **02(5분)** 교과서 예로 끝까지, 최선·없는 값 각각 한 번 → **03(7분)** 교과서 예를 교과서 단계와 맞추기, 리스트 크기 표 → **04(7분)** 이름 3개 겨루기(질문폼 2번 근거), 실생활 사례 메모(질문폼 3번 근거, 28분 무렵 끝) → 05(9분) 확인 표, 빈칸, ○× → 마무리(8분). 116쪽 맞춤 활동은 선택·숙제, 그래프 탐색과 게임 설계는 시간이 남을 때.

**줄인 것** — 108쪽 내비게이션·검색 엔진 그림은 글로. 109쪽 데이터 구조 그림은 HTML 도표와 카드로, 그래프·트리 그림은 카드 글로(그래프 탐색 선택 활동에서 새 그래프 그림). 109쪽 스스로 해결하기 표의 4행(성적·지하철·도서·가계도)은 답이 드러나지 않게 쓰지 않고 새 상황 6개로. 110~111쪽 단계 그림은 시뮬레이터로. 112쪽 이름 리스트(교과서 이름)와 함께 해결하기 표의 이름 3개는 쓰지 않고 새 이름으로. 114쪽 그래프 그림·방문 순서는 새 그래프로. 115쪽 리스트·표는 새 리스트로(교과서 리스트 답은 넣지 않음). 115쪽 개념 정리하기·117쪽 보충 문장은 새 문장으로. 116~117쪽의 「예」로 채워진 답(서점 문제의 문제 분해와 모델링 칸, 가치·태도 칸, 심화 게임 예시 세부)은 옮기지 않음.

**선생님 준비물** — 없음. 05의 확인 표는 공책에 먼저 손으로 풀게 하면 좋음.

**확인할 점**
- 111쪽 다섯 번째 단계 설명 「찾는 값(5)이 mid값(4)보다 왼쪽에 있으므로 low를 mid − 1로 변경하여 오른쪽 범위를 탐색에서 제외」는 오류(PDF 직접 확인). 이때 mid값은 6이고, 바꾸는 것은 high(high = mid − 1)이어야 그림(low·high가 모두 4번)과 맞음. 화면은 「mid값(6)보다 왼쪽에 있으므로 high를 mid − 1로」로 바로잡음.
- 111쪽 수행 시간 표(100 → 7, 10,000 → 14, 1,000,000 → 20, 10,000,000 → 24)는 계산이 맞음을 확인함.
- 109쪽 차이점 두 번째 문장 「…비선형 데이터 구조는 한 개의 요소가 수많은 다른 요소에 연결될 수 있다. 따라서 비선형 데이터 구조에 비해 구현하기 쉽다」는 주어가 빠져 읽기 어려움(뜻은 「선형 데이터 구조가 비선형 데이터 구조에 비해 구현하기 쉽다」). 화면은 주어를 넣어 씀.
- 109쪽은 그래프를 「정점과 간선」, 옆 설명은 「노드와 간선」으로 씀. 카드에 「정점(노드)」으로 함께 적음.
- 114쪽 첫 문장 「가장 대표적인 가지 탐색 방법으로」는 「두 가지」가 빠진 것으로 보임(선택 활동이라 화면에는 문장을 옮기지 않음).
- 117쪽 보충 활동 ❷ 「삽입 정렬은 각 숫자를 적절한 위치에 '삽입'하는 방법」 등 교과서 ○× 문장은 쓰지 않고 새 문장으로 바꿈.

**검토 반영(1차)**
- 분량: 05의 116쪽 맞춤 활동(메모 7칸 + 학업 성취도 점검)을 「선택 또는 숙제」로 접고, 05에는 확인 표·빈칸·○×만 펼쳐 둠. 01의 탐색 카드 글과 선형·비선형 차이 설명을 줄이고 포털 검색 엔진 설명을 뺌. 질문폼 3번 근거(실생활 사례)가 28분 무렵에 끝나도록 50분 흐름을 다시 잡음.
- 05 확인 표: 리스트를 7개([41, 17, 8, 29, 56, 12, 35])로 늘리고 찾는 값을 12·41·56으로 바꿔 115쪽 교과서 답과 같은 숫자가 나오지 않게 함(값은 node로 다시 계산해 확인).
- 04 이름 겨루기를 12명으로 늘려 112쪽 함께 해결하기(10명)의 비교 횟수와 겹치지 않게 함(이름별 순차·이진 비교 수를 node로 확인).
- 01 데이터 구조 카드의 「심화」 표시를 교과서 109쪽 그림처럼 비선형(그래프·트리) 쪽으로 옮김.
- 117쪽 심화(게임 설계)에서 교과서 예시 내용(게임 종류, 규칙 세부)을 빼고 ➊~➍ 틀만 남김.
- 퀴즈: 3-1을 「이진 탐색을 바로 쓸 수 있는 상황」 고르기로 바꿈. 6-2는 정답이 가장 긴 보기가 되지 않게 보기를 바꿈. 3-2 정답 위치를 옮겨 분포를 ①5 ②5 ③5로 유지. 01 분류 카드에서 「번호순」「순서」처럼 선형을 바로 떠올리게 하는 낱말을 뺌.
