퀴즈 13문항(정답 위치 ①4 ②5 ③4). 보기 순서는 화면에서 학생마다 섞여 나옴.

**코드 읽고 예측하기(공통 추적기)** — 코드 상자(줄 번호·색), 입력값 칸, 변수 표, 실행 결과 상자, 「한 줄 실행 / 자동 실행 / 끝까지 / 처음부터」. 예측 모드에서는 실행될 줄을 먼저 눌러 고르고 확인한 뒤 한 줄씩 따라감. 숫자가 아닌 값을 넣으면 파이썬처럼 `ValueError`를 보여 줌. 조건 줄에서는 「`7 % 2`는 1 → `1 == 0` → False(거짓)」처럼 조건식 값을 풀어 보여 줌. if·elif 줄은 「실행되는 줄」로 세고, `else:` 줄은 흐름이 지나갈 때 강조만 하고 예측 채점에서는 빼서 골라도 안 골라도 맞음(화면 안내문에 밝힘). 확인 뒤 「✎ 다시 예측」으로 같은 입력값에서 다시 예측할 수 있음.

**선생님 운영 메모** — 01은 그림과 분류 게임만 하고 넘어가요(5분). 02·03의 추적기는 「입력값 바꾸기 → 예측 → 확인」을 입력값 두세 개로 반복하는 것이 핵심이에요. 02의 if문 형식·비교 연산자 표는 훑기만 해도 돼요. 질문폼 1번 ← 02 짝수·홀수 예측(`evenPick`·`evenWhy`), 2번 ← 03 선택 구조 형식(`formRes`·`formFix`), 3번 ← 04 예측 표(`shipPred`·`ship50`). 코랩은 04에서 처음 열기 때문에, 시작 화면에서 학교 계정 로그인을 미리 안내하면 좋아요.

**50분 흐름** — 도입(3분) 악보 질문·학습 목표, 처음 생각 한 줄 → 01(5분, 8분 무렵까지) 그림 Ⅲ-9, 분류 게임 6장 → **02(9분, 17분 무렵까지)** if문 형식 훑기, 버스 y/n 예측, 짝수·홀수 두 번 예측·메모(질문폼 1번 근거) → **03(7분, 24분 무렵까지)** 형식·순서도, 양수·음수·0 예측, 형식 판단 4개·메모(질문폼 2번 근거) → **04(19분, 43분 무렵까지)** 화면 맨 위 문제 상황·예측 표 4칸·메모(28분 무렵까지, 질문폼 3번 근거) → 복합 대입 연산자 훑기 → 코랩 열기·로그인(3분) → 예제 셀 실행해 보고 값 바꾸기(2분, 코드가 들어 있음) → 2-1 빈칸·2-2 수정 직접 입력(9분) → 마무리(7분) 처음 생각과 비교, 퀴즈, 질문폼. 시간이 밀리면 예제 셀은 1-3만 실행하고 2로 넘어가요. 「3. 더 해 보기」는 선택.

**줄인 것** — 132쪽 김치 부침개는 카드 한 장으로(순서 바꾸기 활동 없음). 134쪽 스스로 해결하기는 교과서의 「명령1·명령2」 형식 6개를 그대로 쓰지 않고, 같은 판단을 하는 새 기온 코드 4개로 바꿈(공개 저장소에 교과서 정답이 드러나지 않게). 135쪽 함께 해결하기는 교과서 지면처럼 빈칸·수정 활동으로 두고, 완성 코드(1번 빈칸의 답, 2번 수정 코드)는 화면·노트북 어디에도 넣지 않음. 135쪽 말풍선이 권하는 입력값(정기 회원 n · 55000 / 40000)은 예측 표와 노트북 시험 입력으로 씀. 개념 정리하기(145쪽)는 소단원 끝 차시(u3-function)에서 다룸.

**코랩 노트북(`assets/selection.ipynb`)** — 출력은 비운 상태로 저장. 로컬 python3로 모든 코드 셀을 실행해 확인함: 1-1(y·n), 1-2(짝수·홀수), 1-3(양수·음수·0)은 input()에 값을 넣어 실행, 2-1은 빈칸을 채운 시험 코드로 (y·30000)(n·30000), 2-2는 수정한 시험 코드로 경계값을 포함한 4가지 입력, 3-1은 경계값 6개로 확인(시험 코드는 저장소에 넣지 않음). 빈 셀(2-2, 3-1, 3-2)은 주석만 있어 실행해도 오류 없음.

**확인할 점**
- 135쪽 2번 실행 결과 「총금액은 60000원입니다.」 — 코드가 `print('총금액은', total,'원입니다.')`라 쉼표로 구분한 값 사이에 공백이 들어가 실제 출력은 「총금액은 60000 원입니다.」. 화면 예측 표와 노트북은 실제 파이썬 출력대로 보여 줌. 수업 중 「책과 띄어쓰기가 다르다」는 질문이 나오면 print()의 sep 기본값(137쪽 sep 옵션)으로 설명 가능.
- 교과서 코드 파일 `135_함께_해결하기_2번.py`는 지면과 문장이 다름(「50000원 이상으로 …」, 「배송 3000원이 …」). `135_함께_해결하기_1번.py`도 마지막 줄이 「총 금액은」. 화면·노트북은 교과서 지면 문장을 따름.
- 133쪽 if문 실행 결과에서 입력 프롬프트가 「하차하시겠습니까?(y/n) y」처럼 띄어 보이지만, 코드의 프롬프트 끝에 공백이 없어 실제로는 「(y/n)y」로 붙어 나옴. 화면 추적기는 실제 출력대로.
- 134쪽 순서도는 「명령 1~3」이 오른쪽으로 갈라졌다가 모두 아래로 모이는 모양을 그대로 다시 그림.
- 파이썬 추적(sys.settrace)은 `else:` 줄에서 멈추지 않지만, 흐름이 else로 넘어가는 것을 보여 주려고 추적기에서는 `else:`도 한 단계로 보여 줌(총괄 결정으로 유지). 예측 채점에서는 `else:` 줄을 골라도 안 골라도 맞음으로 처리함. 137쪽 실행 순서 표(다음 차시)에는 else가 없어 영향 없음.

**검토 반영(1차)**

- 노트북 예제 셀에는 코드가 들어 있으므로 화면·노트북 첫 셀·「1. 교과서 예제 실행해 보기」 문구를 「실행해 보고 값을 바꿔 보기」로 통일하고, 직접 입력은 「2. 함께 해결하기」에서 하도록 밝힘. 50분 흐름의 시간도 맞춤.
- 질문폼 3번 근거가 30분 안에 닿도록: 03 선택 구조 형식 판단을 6개 → 4개(맞음 2·틀림 2)로 줄이고, 04의 문제 상황과 예측 표를 한 카드로 묶어 화면 맨 위로 올림(복합 대입 연산자 표는 그 아래).
