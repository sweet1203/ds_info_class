객체와 클래스는 무엇일까?

교과서 146~147쪽 · 객체지향 프로그래밍, 객체, 인스턴스, 클래스

쉽게 말하면객체는 속성(상태를 나타내는 데이터)과 메소드(행동을 나타내는 함수)를 한 단위로 묶은 것이에요. 클래스는 객체를 만드는 설계도예요. 붕어빵 틀(클래스) 하나로 붕어빵(객체)을 여러 개 만들 수 있어요.

🧱 객체

객체(object)는 속성과 메소드를 한 개의 단위로 묶어 표현한 것이에요. 속성은 객체의 상태를 나타내는 데이터이고, 메소드는 객체의 행동을 나타내는 함수예요. 객체가 메모리에 할당되어 실체화된 것을 인스턴스라고 해요.

🧑 person객체
속성 이름 · 나이 · 성별 · 직업
메소드 걷기 · 먹기 · 자기 · 일하기

함수는 특정한 기능을 하는 코드 덩어리를 하나로 묶은 것이고, 클래스 안에서 구현한 함수는 메소드라고 따로 불러요.

📐 클래스

객체를 생성하기 위한 설계도를 클래스(class)라고 해요. 객체를 만들려면 먼저 클래스를 정의해야 해요. 예를 들어 「사람」 클래스를 정의하면 「윤기」, 「별이」 같은 구체적인 사람 객체를 만들 수 있어요.

클래스는 같은 종류의 객체(인스턴스)를 여러 개 만들 수 있어요. 자동차 설계도 하나로 컨버터블, 세단, SUV, 픽업트럭을 만드는 것처럼요.

클래스 정의 및 객체 생성은 어떻게 할까?
교과서 148쪽 · class 키워드, 객체 생성, 생성자 __init__()

  
쉽게 말하면class 키워드로 클래스를 정의하고, 객체 변수 = 클래스 이름()으로 객체를 만들어요(인스턴스화). 만든 객체에 . 연산자를 붙이면 속성값에 접근할 수 있어요. 생성자 __init__()을 쓰면 객체를 만들면서 속성도 함께 저장해요.

  

    

      
✍️ 클래스와 객체 생성 형식


class 클래스 이름:
    속성 내용
    def 메소드명():
        메소드 내용

객체 변수 = 클래스 이름()

      
클래스 이름은 일반적으로 대문자로 시작해요(예: Book). 클래스로부터 객체를 생성하면, 클래스에 정의된 속성과 메소드를 가진 인스턴스가 생겨요.

    

    

      
🏷️ 식별자의 명명 규칙 · self

      
    
        
  • 카멜 표기법: 여러 단어로 된 이름에서 각 단어의 첫 글자를 대문자로 (예: userName)
    • 
        
  • 스네이크 표기법: 모두 소문자로 쓰고 단어 사이를 밑줄(_)로 연결 (예: user_name)
    • 
      

      
클래스 안에서 정의하는 메소드의 첫 번째 매개 변수는 self예요. self는 그 메소드가 호출된 객체 자체를 가리키고, self로 객체의 속성과 다른 메소드에 접근해요. self를 빠뜨리면 오류가 나요.

  • 게임을 시작하면 참여할 플레이어 인원수를 입력받는다.
    • 
        
  • 플레이어마다 0~9 사이의 랜덤한 숫자 3개가 중복 없이 배정된다.
    • 
        
  • 각 플레이어는 자기 순서에 숫자를 추측하고 피드백을 받는다.
    • 
        
  • 숫자를 모두 맞힌 플레이어가 있으면 이름을 출력하고 게임을 끝낸다.

보충 · 터틀 그래픽스

        
파이썬의 터틀(turtle) 그래픽스 모듈로 간단한 그림을 그려요. 아래 코드는 사각형을 그려요. 코드를 바꿔 원하는 모양을 그려 보세요. 터틀은 웹 환경인 코랩보다 설치형 환경인 파이썬 IDLE에서 하기를 권해요.


import turtle          # turtle 모듈 불러오기
t = turtle.Turtle()    # turtle 객체 생성
for i in range(4):
    t.forward(100)     # 앞으로 100픽셀 이동
    t.right(90)        # 오른쪽으로 90도 회전
turtle.done()          # 그림판 유지

        
기본 명령어: forward() 전진 · backward() 후진 · right() 우회전 · left() 좌회전 · circle() 원 그리기

객체는 속성(데이터)과 메소드(행동)를 한 단위로 묶은 것이고, 클래스는 객체를 만드는 설계도다. 클래스로 만들어 메모리에 실체화된 객체를 인스턴스라고 한다.

    
class로 클래스를 정의하고 객체 변수 = 클래스 이름()으로 객체를 만든다. 생성자 __init__()은 객체가 생성될 때 자동으로 호출되어 속성을 저장하고, 메소드는 self로 그 객체의 속성을 활용한다.

    
객체지향 프로그래밍은 코드의 재사용성, 유지 보수성, 확장성을 높여 규모가 크고 복잡한 소프트웨어 프로젝트에서 장점이 크다. 숫자 야구 게임은 Player 객체와 Game 객체가 서로 주고받으며 동작한다.
