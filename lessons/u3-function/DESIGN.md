**선생님 운영 메모** — 01 곱셈 문제는 「일부러 한 번 틀리고, 한 번 맞히기」만 해요. 02의 실험실은 입력 서너 개(「6 8」, 「1 2 3」, 「a b」)로 단계별 변화를 보는 것이 핵심이고, 폭탄 맵 체험에서 교과서 실행 예와 같은 좌표를 넣어 보고 바로 03으로 넘어가요(직접 작성은 04 코랩 2-1). 03 약수 프로그램은 단계가 85개라 「⏭ 함수 실행을 한 번에」와 「한 줄 실행」을 섞어 써요. 질문폼 1번 ← 01(`mulTry`·`loopWhy`), 2번 ← 02 실험실·폭탄 맵 체험(`bombLog`·`bombWhy`), 3번 ← 03 약수 프로그램(`sameName`).

**50분 흐름** — 도입(3분) → **01(6분, 9분 무렵까지)** 곱셈 문제 돌려 보기·메모(질문폼 1번 근거) → **02(8분, 17분 무렵까지)** 지식 키우기 훑기, 실험실, 폭탄 맵 체험·메모(질문폼 2번 근거) → **03(9분, 26분 무렵까지)** def 형식, 누적 합 따라가기, 지역/전역 표, 약수 프로그램·메모(질문폼 3번 근거) → 04(18분, 44분 무렵까지) 분식집 돌려 보기(3분) → 코랩 열기·로그인(3분), 예제 셀 실행해 보기(1분, 코드가 들어 있음, 1-1만), 2-1 폭탄 맵 빈칸 7곳(5분), 2-2 분식집 빈칸 3곳(4분) → 개념 정리 빈칸(2분) → 마무리(6분). 1-3·1-4는 03 화면의 추적기로 대신해요. 2-2를 다 못 하면 다음 시간 시작에 이어서 해요.

**줄인 것** — 143·145쪽 빈칸의 답(폭탄 맵의 반복·종료 조건·범위 조건·다시 입력받는 명령·맵 출력 반복 범위와 조건, 분식집의 두 함수 정의 줄과 메인 반복)은 화면·노트북 어디에도 넣지 않고 빈칸(`____`)과 힌트로만 둠. 화면 체험은 실행 결과와 처리 과정만 보여 줌(코드 아님). 145쪽 개념 정리하기는 교과서 문장을 옮기지 않고 새 상황 문장 5개 빈칸으로(답 낱말은 주요 용어 그대로). 143쪽 리스트 내포 Tip은 노트북 코드 첫 줄로만 만나고 화면에서 따로 설명하지 않음(교과서도 Tip으로만 다룸). 145쪽 QR 소스 코드 링크는 넣지 않음.

**코랩 노트북(`assets/function.ipynb`)** — 출력은 비운 상태로 저장. 로컬 python3로 모든 예제 셀을 실행해 확인함: 1-1(난수 씨앗 고정, 한 번 틀리고 한 번 맞힘), 1-2, 1-3(10 → 55), 1-4. 빈칸 셀은 시험용으로 채운 코드로 확인: 2-1은 교과서 실행 예와 같은 입력(2 0 / 6 8 / 4 3 / 5 5 / n)으로 교과서와 같은 맵, 2-2는 메뉴판 보기 → 주문 2개 → 결제 → 종료, 메뉴판에 없는 이름은 KeyError가 남을 확인. 3-2 평균 함수도 확인. 시험용 답 코드는 저장소에 넣지 않음.

**확인할 점**
- 145쪽 `show_menu()`의 `print()`가 for문 안(메뉴 줄과 같은 들여쓰기)에 있어 실제로는 메뉴 한 줄마다 빈 줄이 생기는데, 지면 실행 결과에는 빈 줄이 없음. 노트북 빈칸 코드와 화면 체험은 지면 코드대로(메뉴마다 빈 줄) 둠. 메뉴판 출력 뒤에 한 줄만 띄우려면 `print()`를 for문 밖으로 내어 써야 함 — 수업 중 질문이 나오면 설명.
- 145쪽 코드는 메뉴판에 없는 이름을 주문하면 `menu_pan[menu]`에서 KeyError로 멈춤. 화면 체험에서 「김밥」 버튼으로 보여 주고, 노트북 3-1(in 연산자로 고치기, 선택)로 연결.
- 145쪽 실행 결과의 메뉴판 머리줄은 「=====<메뉴판>====」(왼쪽 = 5개, 오른쪽 4개)인데 코드는 `print('====<메뉴판>====')`(양쪽 4개)라 실제 출력과 = 개수가 다름. 화면·노트북은 코드대로.
- 145쪽 개념 정리하기는 소단원(132~145쪽) 전체를 정리하는 활동이라 이 차시 04에 둠.
- 144쪽 「전역 변수는 함수 내부에서 값을 변경할 수 없다」는 global 선언이 없을 때의 이야기(같은 쪽 Tip의 global). 표는 지면대로, Tip을 바로 아래에 둠.
- 144쪽 「지역 변수와 전역 변수의 이름이 같아도 되나요?」 말풍선은 답이 지면에 없어 03 메모(`sameName`)로 학생이 추적기를 근거로 답하게 함.
- 추적기는 함수를 호출한 줄(7행, 10·11행)을 「호출할 때」와 「반환값을 받아 돌아왔을 때」 두 번 보여 줌(파이썬 실행 추적은 돌아올 때 그 줄을 다시 알리지 않지만, 반환값이 호출한 자리로 돌아오는 것을 보이려고). 1행 def는 정의만 하고 안쪽을 실행하지 않는 단계로 보여 줌.
- 교과서 코드 파일 `142_무한_루프.py`는 5행이 `'=?'`, `143_스스로_해결하기.py`는 맵 출력이 `'□'`·`'★'`(앞뒤 공백 없음)로 지면(`'= ?'`, `' □ '`, `' ★ '`)과 다름. 지면을 따름. `145_함께_해결하기.py`도 「이용종료」(지면 「이용 종료」)와 if 한 줄 쓰기 방식이 다름 — 지면을 따름.
- 143쪽 좌표는 `maps[x][y]`라 x가 행(위에서 몇째 줄), y가 열임. 지면 실행 예(2 0 → 셋째 줄 첫 칸)와 맞음. 화면 맵에 행·열 번호를 붙이고 안내문에 밝힘.
