퀴즈 11문항(정답 위치 ①4 ②4 ③3). 1차 검토 뒤 다른 유형의 정의를 알려 주는 오답과 정답만 긴 보기를 고침.

**선생님 운영 메모** — 질문폼(info-u4-ml-concept) 1번 ← 01 규칙 찾기(`mlRule`·`bugPred`), 2번 ← 02 스팸 필터(`spamRes`·`ruleProblem`), 3번 ← 03 유형 분류 게임과 까닭 메모(`typeWhy`). 03은 탭을 훑은 뒤 분류 게임·메모를 먼저 하고, 개념 정리 빈칸은 그다음에 해요. 02의 스팸 필터는 처음 8통을 다 맞히지 못해도 「새 이메일 4통 도착」을 눌러 넘어가게 해 주세요(핵심은 새 이메일에서 규칙이 깨지는 경험). 계획안의 「스팸 메일 분류 규칙을 토의해 만들고 문제점 발표」를 이 체험으로 대신했어요.

**50분 흐름** — 도입(4분) 생각해 볼까요·핵심 질문, `planML` 한 줄 → 01(4분 무렵 시작, 8분) 과정 카드 읽기, 규칙 찾기·예측·규칙 메모(질문폼 1번 근거, 12분 무렵 끝) → 02(12분 무렵 시작, 10분) 비교 카드 훑기, 스팸 필터 두 단계·문제 메모(질문폼 2번 근거, 19분 무렵), 스스로 해결하기 분류 6개·까닭 메모(22분 무렵 끝, 짝 발표는 선택) → 03(22분 무렵 시작, 10분) 탭 3개 훑기(3분), 유형 분류 게임·`typeWhy` 메모(질문폼 3번 근거, 29분 무렵 끝), 개념 정리 빈칸(3분) → 마무리(32분 무렵 시작, 18분) 처음 생각과 비교(5분), 퀴즈(3분), 질문폼(10분). 남는 시간에는 선생님이 강화 학습 체험 사이트를 함께 보여 줘도 좋아요.

**줄인 것** — 176쪽 인공지능 그림·자율주행 사진은 글 칩으로만. 177쪽 포유류·조류 그림은 세 단계 카드 글로, 체험은 곤충·거미 새 데이터로 바꿈. 178쪽 스스로 해결하기의 교과서 문제 4개는 옮기지 않고 새 문제 6개로 바꿈(답이 공개 저장소에 드러나지 않게). 179쪽 강아지·고양이 그림은 꽃(해바라기·튤립) 카드로 다시 그림. 179쪽 강화 학습 체험 사이트 주소는 화면에 쓰지 않고 「선생님이 알려 주는 사이트」로. 개념 정리하기는 교과서 문장을 옮기지 않고 새 상황 문장 빈칸으로.

**선생님 준비물** — 없음(브라우저 체험만). 강화 학습 체험(179쪽 옆 설명)을 쓰려면 교과서에 실린 사이트를 미리 열어 두세요.

**확인할 점**
- 계획안(plan_Ⅳ-2)의 2-1 정리 단계에 「169쪽 [개념 정리하기]」라고 적혀 있으나 이 소단원의 개념 정리하기는 179쪽에 있음. 도입 단계의 「162~163쪽 나의 학습 준비」「164쪽 생각해 볼까요?」도 Ⅳ-1 단원 도입 쪽수임 — 이 차시는 176쪽 생각해 볼까요?를 씀.
- 계획안 학습 목표는 「비교·설명」, 교과서 177쪽은 「비교·분석」 — 화면은 교과서대로 「비교·분석」.
- 178쪽 그림 Ⅳ-2에서 전통적인 프로그래밍 규칙 예는 「‘이벤트’, ‘우승’」, 기계학습이 찾는 단어는 「‘당첨’, ‘무료’, ‘이벤트’, ‘우승’」 — 그대로 옮김.
- 179쪽 지도학습 설명은 「분류」 예시만 보여 줌. 회귀는 다음 차시(180쪽~)에서 다루므로 이 차시 분류 게임에도 「자전거 대여 수 예측」(회귀형 지도학습) 하나만 넣고 회귀라는 낱말은 쓰지 않음.
- 체험 데이터의 곤충·거미 특징(곤충 다리 6개·더듬이·몸 3마디, 거미 다리 8개·더듬이 없음·몸 2마디)은 일반적인 생물 지식이며, 몸 색깔은 일부러 규칙에 쓸 수 없게(두 무리에 같은 색이 섞이게) 만듦.
- 스팸 필터는 제목에 적은 단어가 들어 있는지만 봄(대소문자 무시). 「무.료」처럼 글자 사이에 기호를 넣은 스팸과 「무료 급식」 같은 정상 메일을 일부러 넣어, 어떤 단어 규칙도 쉽게 모두 맞히기 어렵게 함.
