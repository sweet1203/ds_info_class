# u5-review 설계표 — 협력적 창의·융합 프로젝트 · Ⅴ단원 정리 (교과서 234~237쪽)

u1~u4-review와 같은 틀(프로젝트 → 평가 → 진로 → 단원 정리, 동료 평가 · 역량 Check는 접기)로 만들었다. 이 프로젝트의 결과물은 **카드 뉴스**인데, 도구로 그림 · 폰트까지 넣어 완성하고 실제로 배포해 반응을 모으는 일은 50분 안에 어렵다. 그래서 오늘은 **문제 발견 · 해결 방안 → 카드 뉴스 초안(5장의 장면 순서와 글, 화면에서 바로 미리 보기) → 배포 계획 · 결과 예측**까지 하고, 도구로 완성하기와 실제 배포는 「다음 시간 · 집에서」로 접어 두었다. 제작 도구는 「선생님이 알려 주는 도구」로만 적었다. 모둠 활동이지만 메모는 각자 화면에 적는다(질문폼은 개인).

퀴즈 10문항(정답 위치 ①3 ②4 ③3). 02 · 03은 프로젝트 활동 화면이라 퀴즈를 두지 않았다(u1~u4-review와 같음). 01은 개인 정보 자기 결정권이라는 개념이 처음 나오는 화면이라 2문항을 두었다.

질문폼(info-u5-review) 1번 ← 01 `caseNote` `caseRight` `rightPickName`(10분 무렵), 2번 ← 01 `solution` + 02 `cn2`~`cn4`(필수 장면, 22분 무렵), 3번 ← 03 `distWhere` `distReact` `distCare`(배포 계획 표가 03 맨 위, 25분 무렵).

## 50분 흐름 (시작 화면 「50분 계획」과 같음)
모둠 정하기(2분) → 01 문제 발견 · 계획(8분, ~10분) 자기 결정권 카드 훑기 1분 → 사례 속 개인 정보 찾기 3분 → 우리 모둠 사례 · 지켜지지 못한 것 2분(다른 사례 찾기는 접어 둔 선택) → 해결 방안 1분 · 퀴즈 1분 → **02 카드 뉴스 초안(12분, ~22분)** 요령 1분 → 제목 · 2~4장 글 8분(1 · 5장은 시간이 되면) → 출처 · 점검 3분 → 03 배포 계획 · 평가(4분, ~26분) 배포 계획 표 3분(질문폼 3번 근거, ~25분) → 자기 평가 1분(역량 · 동료 평가는 접어 둔 선택) → 04 진로(4분, ~30분) 카드 4장 · 퀴즈 → 05 단원 정리(7분, ~37분) 분류 게임 7장 · 퀴즈 → 마무리(13분) 핵심 질문 답, 퀴즈, 질문폼.

## 줄인 것
- 235쪽 3단계 카드 뉴스 제작: 오늘은 화면에서 5장 초안(장면 순서와 글)까지만. 그림 · 폰트를 넣어 완성하는 일은 「선생님이 알려 주는 도구」로 다음 시간이나 집에서(02에 접어 둠). 결과물 파일은 저장소에 넣지 않음.
- 235쪽 4단계: 배포 계획을 세우고 결과를 예측하는 데까지. 실제 게시와 반응 정리는 완성 뒤에(화면에 안내).
- 234쪽 수행 계획서 QR · 모둠원 역할 표는 시작 화면의 모둠명 · 역할 메모로 대신함. 이 프로젝트에는 교과서가 역할 이름을 주지 않아서 역할 예(사례 찾기 · 글 쓰기 · 디자인 · 배포 계획)를 새로 적음.
- 234쪽 1단계 · 2단계의 「예」와 235쪽 반응 정리 방법의 「예」는 예시 답안이라 옮기지 않음. 대신 새로 지은 가상 사례(체육 대회 사진 · 이름표 · 반 티셔츠의 학교 이름 · 설명란의 전화번호 · 학원 앞에 있는 시간 → 낯선 문자)를 체험으로 쓰고, 해결 방안은 답 대신 생각할 질문 카드 3장만 둠. 반응 정리 방법 입력칸 예시는 다른 예(보기 전 · 후 같은 질문 설문)로 씀.
- 235쪽 평가하기의 자기 평가 · 동료 평가 표는 자기 평가 칩과 동료 평가 메모(선택)로 바꿈. 평가 기준 문장은 접힌 표에 그대로 둠.
- 237쪽 단원 정리 11문항(○×, 단어 고르기, 빈칸, 선 긋기)은 형성평가 문항이라 옮기지 않음. 같은 개념(웨어러블, 메타버스, 데이터 엔지니어, 악성 코드, 해킹, 보호할 정보와 공유할 정보, 정보 공급자와 정보 사용자, 개인 정보 보호법)을 **새 상황 문장**(길을 알려 주는 안경, 맥박을 재는 반지, 온라인 속 학교 축제, 주문 기록이 다니는 통로, 저절로 퍼지는 메일 파일, 사진을 잠그는 설치 파일, 관리자 비밀번호를 알아내 접속, 동아리 부장의 연락처 관리, 지진 대피소 위치, 학원의 수강생 전화번호 넘기기 등)으로 분류 게임과 퀴즈에 넣음. 분류 게임의 해설은 정의문 대신 「이 상황에서 왜 그 용어인지」로, 끝맺음은 가르는 기준 한 문장으로 씀. 정답(239쪽)은 넣지 않음.
- 236쪽 인터뷰 4문답은 카드 4장으로 요약해 다시 씀.

## 선생님 준비물
- 카드 뉴스 제작 도구(선생님이 알려 주는 도구)와 완성 파일 제출 장소. 저장소에는 넣지 않음.
- (선택) 다른 침해 사례를 찾을 때 쓸 사이트(선생님이 알려 주는 사이트, 5분 안).

## 확인할 점
- 핵심 질문은 210쪽(디지털 기술과 사회 변화) · 222쪽(정보 보호와 보안)의 핵심 질문을 그대로 씀. 마무리는 프로젝트와 이어지는 222쪽 질문으로 답하게 함.
- 05 단원 용어 카드 · 분류 게임의 용어 표기(웨어러블, 메타버스, 데이터 엔지니어, 악성 코드, 해킹, 정보 공급자 · 정보 사용자, 개인 정보 보호법)는 Ⅴ단원 교과서 표기를 따름. 다른 Ⅴ단원 차시(u5-digital-impact · u5-digital-career · u5-info-protection · u5-info-security) 화면과 맞추어 보지 않았으므로, 그쪽 표기와 다르면 05 문장을 맞춰야 함.
- 04 카드의 「모의 해킹」은 교과서에 뜻풀이가 없어 풀어 쓰지 않고 원문 낱말 그대로 둠.
- 01 사례 찾기에서 「저녁 7시 ○○학원 앞」(있는 곳을 알려 주는 정보)을 개인 정보로 판정함. 교과서가 위치 정보를 다루는 방식과 맞음을 확인함. 「응원 구호 · 좋아요 수 · 응원 댓글 수」는 개인 정보가 아닌 것으로 둠.
- 퀴즈 5-3의 오답 「방화벽」은 Ⅴ단원 정보 보안 부분에 나오는 용어(교과서에 있음을 확인), 「학교 생활 규정」은 제도 · 규칙 성격의 오답으로 둠.
- 235쪽 역량 4개(지식 정보 처리 · 창의적 사고 · 협력적 소통 · 공동체 역량)는 03 역량 칩으로, 237쪽 역량 Check 12개는 u4-review와 같은 목록(교과서와 같음)으로 씀.
- 02 카드 미리 보기는 학생 화면에서만 그려지고 메모로만 저장됨(파일 저장 · 전송 없음).

## 검토 반영(1차)
- 퀴즈 5-3: 237쪽 7번과 같은 상황 → 학원이 수강생 전화번호를 광고 업체에 넘긴 상황으로, 줄기에서 「개인 정보」 낱말을 빼고, 오답에 제도 · 규칙 성격의 「학교 생활 규정」을 넣음.
- 05 데이터 엔지니어 카드 · 해설: 237쪽 6번 뼈대 대신 「하루 수백만 건 주문 기록이 서버에 쌓이도록 통로를 짓고 창고를 정리한다」 장면 문장으로 새로 씀.
- 50분: 01 「다른 사례 찾기」를 선택으로 접음, 02 카드 초안 필수는 2~4장(1 · 5장은 「시간이 되면」), 03 역량 칩을 선택으로 접음, 마무리 13분 확보. 질문폼 3번 근거가 25분 무렵에 닿게 50분 흐름을 고침.
- 시작 화면: `roles` 라벨을 「역할 나누기(이름 대신 번호나 별명으로)」로, 안내 문장도 「모둠원은 이름 대신 번호나 별명으로」로 맞춤(MEMOLIST 이름도).
- 분류 게임 해설을 「이 상황에서 왜 그 용어인지」로 바꾸고 끝맺음의 정의 나열을 가르는 기준 한 문장으로 줄임. 「손목」 → 안경 · 반지, 「3차원 가상 공간」 → 「온라인 속 학교 운동장」.
- 분류 카드 시제를 섞고(현재 4 · 과거 3) 기술 묶음에 헷갈릴 카드(눈앞에 화살표를 띄우는 안경)를 더해 7장으로.
- 악성 코드 카드는 프로그램 동작(컴퓨터가 느려지고 메일이 저절로 퍼짐)으로, 해킹 카드는 사람이 비밀번호를 추측해 몰래 들어가는 행동으로 경계를 분명히 함(몰래 연락처를 보내는 앱 카드는 뺌).
- 퀴즈 5-1: 「학교와 학생이 함께」(둘 다형) → 동아리 부장이 부원 연락처를 모아 관리할 때의 역할을 묻는 문항으로(사용자와 공급자의 역할이 겹침).
- 퀴즈 4-1: 교과서에 없는 「모의 해킹」 풀이 → 인터뷰 속 정보 보안이 더 중요해지는 까닭(초연결 사회)으로. 04 카드의 모의 해킹 풀이도 뺌.
- 확인할 점의 위치 정보 문장을 「교과서가 위치 정보를 다루는 방식과 맞음을 확인」으로 바꿈.
- 사례 문장의 버튼 글을 가상 값 「저녁 7시 ○○학원 앞」으로, 지시문 · 결과 문장을 「알아보거나, 연락하거나, 있는 곳을 알 수 있게 하는 정보」로 판정 기준과 맞춤.
- 가상 인물 「하린」 → 「ㄱ 학생」(퀴즈 속 인물은 ㄴ · ㄷ 학생).
- 퀴즈 1-1: 정답 「스스로 정한다」 낱말 연결 · 길이 단서 → 「위치 정보 제공을 거절했다」와 비슷한 길이의 그럴듯한 오답(약관을 읽지 않고 동의, 가입 축하 쿠폰 받기)으로.
