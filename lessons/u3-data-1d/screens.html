하나로 묶어 관리할까?

「반 친구 25명의 티셔츠 치수를 어떻게 저장하지?」
선미는 학급 단체 티셔츠를 만들려고 친구들의 상의 치수를 조사해 정리하려고 해요. 25명의 치수를 변수에 저장하려면 변수 25개를 만들어야 하고, 학생 수가 늘어나면 변수를 더 만들어야 해요. 더 편리한 방법은 없을까요?

오늘은 여러 개의 값을 하나로 묶는 1차원 데이터를 순서가 있는 리스트와, 키로 값을 찾는 딕셔너리로 표현해 봐요. 코드를 한 줄씩 실행하며 리스트의 칸과 딕셔너리의 키가 어떻게 바뀌는지 따라가요.

선미가 25명의 치수를 변수로 저장하려면 25개의 변수를 만들어야 해요. 학생 수가 늘어나면 늘어난 만큼 변수를 더 만들어야 하지요. 이렇게 변수를 한 개씩 만들어서 대량의 데이터를 관리하는 것은 비효율적이에요. 이때 여러 개의 변수를 하나로 관리하는 방식을 이용하면 편리하게 데이터를 관리할 수 있어요.

일반적으로 여러 개의 값이 모이면 1차원 데이터가 되고, 여러 개의 1차원 데이터가 모이면 2차원 데이터가 돼요. 이렇게 확장해 나가면 3차원, 4차원 … n차원 데이터를 만들 수 있고, 1차원·2차원·3차원을 선이나 면, 입체로 표현하기도 해요.

02

리스트로 표현한 1차원 데이터

교과서 127쪽 · 리스트, 인덱스, 값 참조·수정, append()

쉽게 말하면리스트는 값을 대괄호 [ ] 안에 한 줄로 세워 저장해요. 칸마다 0부터 번호(인덱스)가 붙어서, 번호로 값을 꺼내거나 바꿔요.

우리 반 학생들의 상의 치수를 관리할 때 학생마다 따로 저장하지 않고 함께 모아 1차원 데이터처럼 관리할 수 있어요. 파이썬에서 1차원 데이터는 여러 개의 값을 담는 컨테이너형으로 표현해요. 순서가 있는 컨테이너형으로는 리스트가 있고, 순서가 없는 컨테이너형으로는 딕셔너리가 있어요.

📏 리스트 = [값 1, 값 2, 값 3]

  • [ ](대괄호) 안에 값을 ‘,’(콤마)로 구분해 저장해요.
  • 리스트의 값에 0번부터 1씩 커지는 연속적인 숫자인 인덱스를 붙여요.
  • 인덱스를 이용해 그 위치에 저장된 데이터를 수정하거나 참조할 수 있어요.
  • append()는 리스트에 값을 추가할 때 써요. 한 번에 여러 개의 값을 넣을 수 없어서, 두 개를 넣으려면 두 번 써야 해요.
95[0]85[1]100[2]95[3]90[4]

index는 0부터 시작해서 1번 학생의 데이터는 T_size[0]으로 표현해요. 마지막 학생의 인덱스는 총 학생 수에서 1을 뺀 값이에요.

# 리스트에 1차원 데이터 표현하기
T_size = [95, 85, 100, 95, 90]
print('학생의 상의 치수:', T_size)
# 인덱스를 이용해 리스트의 값 가져오기
print('1번 학생의 상의 치수:', T_size[0])
print('2번 학생의 상의 치수:', T_size[1])
# 인덱스를 이용해 리스트의 값 수정하기
T_size[0] = 100
# 1번 학생의 수정된 상의 치수 출력하기
print('1번 학생의 수정된 상의 치수:', T_size[0])
# 리스트에 값 추가하기
T_size.append(95)
T_size.append(105)
print(T_size)
학생의 상의 치수: [95, 85, 100, 95, 90]
1번 학생의 상의 치수: 95
2번 학생의 상의 치수: 85
1번 학생의 수정된 상의 치수: 100
[100, 85, 100, 95, 90, 95, 105]

모둠 친구 네 명의 줄넘기 기록을 번호순으로 저장했어요. 한 줄씩 실행하면서 오른쪽 리스트 칸의 인덱스를 봐요.

03

딕셔너리로 표현한 1차원 데이터

교과서 128쪽 · 딕셔너리, 키:값, 키로 값 참조·수정·추가

쉽게 말하면딕셔너리는 값마다 이름표(키)를 붙여 중괄호 { } 안에 저장해요. 사전에서 단어를 찾듯이 키로 값을 찾아요. 0, 1, 2 같은 인덱스는 쓰지 않아요.

딕셔너리는 { }(중괄호) 안에 키(key):값(value) 쌍을 값으로 저장해요.

딕셔너리 = { 키1: 값1 }딕셔너리명[키]
  • 사전에서 단어를 찾듯이 키를 사용해 값을 가져올 수 있어요.
  • 대괄호 안에 키를 넣어 그 키에 저장된 값을 찾거나, 새로운 ‘키:값’을 저장할 수 있어요.
  • 딕셔너리에 중복된 키는 쓸 수 없고, 이미 있는 키로 저장하면 기존 키의 값이 수정돼요.

리스트 · 순서가 있어요

T_size[0] → 0번째 칸의 값
인덱스(위치 번호)로 찾아요.

딕셔너리 · 순서가 없어요

T_size['내빈'] → '내빈' 키의 값
위치 번호가 아니라 키로 찾아요.

# 딕셔너리에 1차원 데이터 표현하기
T_size = {'내빈':95, '미송':85, '민수':100, '준서':95, '지환':90 }
print('우리 반 모든 학생의 상의 치수:', T_size)
# 키를 이용해 딕셔너리의 값 가져오기
print('내빈이의 상의 치수:', T_size['내빈'])
print('미송이의 상의 치수:', T_size['미송'])
# 키를 이용해 딕셔너리의 값 수정하기
T_size['내빈'] = 100 # 내빈이의 상의 치수를 100으로 수정
print(T_size)
# 딕셔너리에 새로운 키:값 쌍을 저장하기
T_size['재우'] = 105
print('우리 반 모든 학생의 상의 치수:', T_size)
우리 반 모든 학생의 상의 치수: {'내빈': 95, '미송': 85, '민수': 100, '준서': 95, '지환': 90}
내빈이의 상의 치수: 95
미송이의 상의 치수: 85
{'내빈': 100, '미송': 85, '민수': 100, '준서': 95, '지환': 90}
우리 반 모든 학생의 상의 치수: {'내빈': 100, '미송': 85, '민수': 100, '준서': 95, '지환': 90, '재우': 105}

🔬 코드 읽고 예측하기 · 동아리 딕셔너리

친구 이름을 키로, 동아리를 값으로 저장했어요. 한 줄씩 실행하며 오른쪽 키:값 카드를 봐요.

🎯 리스트가 알맞을까, 딕셔너리가 알맞을까?

값을 몇 번째인지(위치)로 찾을지, 이름표로 찾을지 생각하며 골라요.

05

마무리

핵심 문장 · 처음 생각과 비교 · 마무리 퀴즈 · 질문폼

변수를 하나씩 만들면 학생이 늘 때마다 변수도 늘어 관리가 어렵다. 값을 한 줄로 묶으면 1차원 데이터, 그런 줄을 여러 개 묶어 표로 만들면 2차원 데이터이고, 같은 방식으로 n차원까지 늘릴 수 있다.
리스트는 [ ] 안에 값을 콤마로 구분해 저장하는 순서가 있는 컨테이너형이다. 0부터 시작하는 인덱스로 값을 참조·수정하고, append()로 값을 추가한다.
딕셔너리는 { } 안에 키:값 쌍을 저장한다. 딕셔너리명[키]로 값을 찾거나 새 키:값을 저장하고, 중복된 키를 입력하면 기존 키의 값이 수정된다.
