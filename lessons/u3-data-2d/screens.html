「상의 치수만이 아니라 신발과 하의 치수도 모아야 해.」
지난 시간에는 우리 반 학생들의 상의 치수를 리스트 하나에 모았어요. 그런데 신발 치수, 하의 치수도 함께 관리하려면 어떻게 해야 할까요? 1차원 데이터를 모으면 2차원 데이터가 돼요.

오늘은 2차원 리스트를 행과 열로 찾아가고, 2차원 딕셔너리를 키 두 개로 찾아가요. 마지막에는 게임 캐릭터와 그래프를 다차원 데이터로 표현해 봐요.

01

2차원 리스트로 의복 치수 표현하기

교과서 129쪽 · 2차원 리스트, 행과 열, 리스트명[행번호][열번호]

쉽게 말하면리스트 안에 리스트를 넣으면 표가 돼요. 가로줄이 행, 세로줄이 열이고, [행번호][열번호] 두 개의 번호로 칸을 찾아요. 둘 다 0부터 세요.

2차원 데이터는 1차원 데이터를 모은 것이에요. 우리 반 학생들의 상의 치수뿐 아니라 신발 치수, 하의 치수도 함께 모으면 2차원 데이터를 만들 수 있어요.

  • 2차원 리스트는 리스트에 리스트를 넣어서 만들어요. 리스트에 포함된 각 리스트는 콤마로 구분해요.
  • 가로 방향으로 나열된 데이터를 행(row), 세로 방향으로 나열된 데이터를 열(column)이라고 해요.
  • 행 방향과 열 방향으로 2개의 인덱스를 갖고, 한 개 또는 두 개의 대괄호로 값에 접근해요.
  • 행과 열 모두 0부터 인덱스를 시작해요.
리스트 = [[값1, 값2, 값3], [값4, 값5, 값6]]리스트명[행번호][열번호]

          [85, 230, 'S'],
          [100, 270, 'XL'],
          [95, 235, 'L'],

# 인덱스를 이용해 2차원 리스트의 값 가져오기
print('1번 학생의 의복 치수:', class1[0])
print('2번 학생의 상의 치수:', class1[1][0])
print('2번 학생의 신발 치수:', class1[1][1])

# 2차원 리스트의 값 수정하기
class1[4][0] = 100      # 5번 학생의 상의 치수 수정
class1[4][2] = 'XL'    # 5번 학생의 하의 치수 수정
print('5번 학생의 수정된 상의 치수:', class1[4][0])
print('5번 학생의 수정된 하의 치수:', class1[4][2])

🔬 행과 열 찾기

칸을 누르면 그 칸을 꺼내는 코드가 보여요. 행 이름(0행, 1행 …)을 누르면 대괄호 한 개로 꺼낸 결과가 보여요. 익숙해지면 도전 3문제를 눌러 코드에 맞는 칸을 찾아요.

🔬 코드 읽고 예측하기 · 자리 배치표

모둠 자리 배치를 2차원 리스트로 저장했어요. 한 줄씩 실행하며 오른쪽 표의 행과 열을 봐요. 마지막에는 대괄호를 한 개만 써서 값을 넣어요.

02

2차원 딕셔너리로 의복 치수 표현하기

교과서 130쪽 · 딕셔너리 안의 딕셔너리, 딕셔너리[키][키]

쉽게 말하면딕셔너리 안에 딕셔너리를 넣어요. 첫 번째 대괄호에는 바깥쪽 키(학생 이름), 두 번째 대괄호에는 안쪽 키(상의·신발·하의)를 넣어 값을 찾아요. 번호를 외우지 않아도 돼요.
  • 2차원 딕셔너리는 딕셔너리 안에 딕셔너리가 들어 있는 형태예요.
  • 딕셔너리에서 중복된 키는 쓸 수 없지만, 내부 딕셔너리의 키는 학생마다 똑같이(상의·신발·하의) 써도 돼요.
  • 특정 값을 가져오거나 수정할 때는 대괄호에 키 값을 넣어 접근해요. 첫 번째 대괄호에는 바깥쪽 딕셔너리의 키, 두 번째 대괄호에는 내부 딕셔너리의 키를 넣어요.
딕셔너리 = { 키1 : { 키A: 값A, 키B: 값B}, 키2: {키A: 값A, 키B: 값B}}딕셔너리[키][키]

리스트나 딕셔너리에서 반복문을 사용하면 더 효율적으로 데이터를 관리할 수 있어요(반복문은 뒤에서 배워요).

class1 = {
    '내빈': {'상의': 95, '신발': 250, '하의': 'M' },
    '미송': {'상의': 85, '신발': 230, '하의': 'S' },
    '민수': {'상의': 100, '신발': 270, '하의': 'XL' },
    '준서': {'상의': 95, '신발': 235, '하의': 'L' },
    '지환': {'상의': 90, '신발': 250, '하의': 'L' }
}
# 2차원 딕셔너리에서 키를 이용하여 값 가져오기
print('미송이의 의복 치수:', class1['미송'] )
print('민수의 상의 치수:', class1['민수']['상의'])

# 2차원 딕셔너리에서 키를 이용하여 값 수정하기
class1['준서']['하의'] = 'M'
print(class1['준서'])
미송이의 의복 치수: {'상의': 85, '신발': 230, '하의': 'S'}
민수의 상의 치수: 100
{'상의': 95, '신발': 235, '하의': 'M'}

🔬 키 두 개로 찾아가기

바깥쪽 키(이름)와 안쪽 키(종류)를 차례로 눌러 코드를 만들어요. 같은 값을 2차원 리스트로 꺼내는 코드도 함께 보여요. 도전에서는 문제에 맞는 코드를 만들어요.

03

함께 해결하기 · 다양한 방법으로 데이터 구조 표현

교과서 131쪽 · 게임 캐릭터를 딕셔너리로, 그래프를 2차원 리스트와 2차원 딕셔너리로

쉽게 말하면표가 아닌 것도 다차원 데이터로 나타낼 수 있어요. 캐릭터의 능력치는 딕셔너리로, 점과 선으로 이루어진 그래프의 연결 관계는 2차원 리스트나 2차원 딕셔너리로 나타내요.

🎮 1. 게임 캐릭터의 정보를 딕셔너리로

캐릭터 gogo의 능력치(교과서 131쪽 그림을 다시 그림)

그림에서 능력치 여섯 가지의 값을 읽어 2차원 딕셔너리로 나타내요. 바깥쪽 키는 캐릭터 이름 'gogo', 안쪽 키는 능력치 이름이에요.

gojeongbo = {
    'gogo': {'공격력': 150,
             # 나머지 능력치를 이어서 써요
            }
}
  • 1-1 캐릭터(gogo)의 정보를 딕셔너리로 표현해요.
  • 1-2 캐릭터의 체력을 200으로 수정한 뒤 출력해요.

두 문제는 04 코랩 노트북에서 직접 코드로 써요.

🕸️ 2. 그래프를 2차원 리스트와 2차원 딕셔너리로 (응용하기)

그래프는 객체를 나타내는 정점과 정점을 잇는 간선으로 이루어져요. 연결 관계를 이렇게 나타내요.

2차원 리스트

행 번호 = 출발 정점, 열 번호 = 도착 정점. 연결되어 있으면 1(또는 간선의 숫자), 연결되지 않았으면 0 또는 ×를 넣어요.

2차원 딕셔너리

키 = 정점, 값 = 그 정점과 연결된 정점들(리스트), 간선에 숫자가 있으면 {연결된 정점: 숫자} 딕셔너리로 넣어요.

먼저 연습해요 · 교과서와 다른 새 그래프예요. 표의 칸을 눌러 0과 1을 바꾸고 확인을 눌러요.

교과서 131쪽 그래프 · 04 코랩 노트북에서 2차원 리스트와 2차원 딕셔너리로 나타내요. 연결되지 않았을 때는 0 또는 ×를 넣어요.

마무리

핵심 문장 · 처음 생각과 비교 · 마무리 퀴즈 · 질문폼

학생마다 [상의, 신발, 하의]처럼 한 줄씩 있는 데이터를 여러 줄 묶으면 표 모양의 2차원 데이터가 된다. 2차원 리스트는 리스트에 리스트를 넣어 만들고, 가로 방향 데이터를 행, 세로 방향 데이터를 열이라 한다. 리스트명[행번호][열번호]로 값에 접근하며 행과 열 모두 0부터 시작한다.
2차원 딕셔너리는 딕셔너리 안에 딕셔너리가 들어 있는 형태이다. 딕셔너리[키][키]처럼 첫 번째 대괄호에 바깥쪽 키, 두 번째 대괄호에 내부 딕셔너리의 키를 넣어 값을 가져오거나 수정한다.
문제를 해결하려면 데이터에 알맞은 다차원 데이터 구조를 고른다. 캐릭터의 능력치는 딕셔너리로, 그래프의 연결 관계는 2차원 리스트(행 = 출발, 열 = 도착)나 2차원 딕셔너리(키 = 정점)로 나타낼 수 있다.
