퀴즈 13문항(정답 위치 ①4 ②5 ③4).

**질문폼(info-u3-data-2d) 근거** — 1번 ← 01 행과 열 찾기·자리 배치표(`gridRes`·`trSeat`·`rcWhy`), 2번 ← 02 키 두 개로 찾아가기(`dictRes`·`cmpWhy`), 3번 ← 03 새 그래프로 연습하기(`adjRes`·`adjWhy`). 셋 다 27분 무렵까지 끝남. 코랩 실습(교과서 그래프 표현)은 질문폼 근거로 쓰지 않음.

**50분 흐름** — 도입(3분) 1차원 → 2차원, 처음 생각 → **01(3~12분)** 행·열 설명과 예제 결과 확인, 행과 열 찾기(자유 1분 + 도전 3문제), 자리 배치표 예측(2분), 메모 → **02(12~19분)** 2차원 딕셔너리 설명·예제, 키 두 개로 찾아가기(도전 3문제), 메모 → **03(19~27분)** 캐릭터 그림·뼈대는 훑기만, 그래프 표현 방법, 새 그래프 연습 ①(3분), 메모, 교과서 그래프 그림 확인 → **04(27~43분)** 코랩 열기·로그인·사본 저장(3~4분), 예제 따라 하기 → 130쪽 1·2번 → 131쪽 1번(캐릭터) → 메모·개념 정리 → 마무리(43~50분). 131쪽 2번(응용하기)과 더 해 보기는 먼저 끝낸 학생용(03 연습 ②는 접어 둠).

**코랩 노트북(`assets/two_dim_data.ipynb`)** — 교과서코드 129~131쪽을 바탕으로 만듦. 출력은 비운 채 저장. 로컬 python3로 모든 칸을 실행해 확인함(빈칸 문제 칸은 시험할 때만 답을 넣어 실행, 130쪽 1번의 KeyError는 의도한 오류, input()에는 있는 키·없는 키를 넣어 시험).
- 예제 따라 하기: 129·130쪽 본문 코드. 129쪽 Tip(1행에 형식의 리스트 입력)대로 class1 리스트를 맨 앞에 넣음. 130쪽은 리스트와 같은 이름 class1을 다시 쓰므로 마크다운에 「이제부터 class1은 딕셔너리」 한 줄.
- 130쪽 스스로 해결하기: 1번은 교과서가 주는 문제 코드(`print(class1['한준'])`) 그대로 두고 까닭은 화면 메모에. 2번은 빈칸 뼈대 + try except·f-문자열 설명 + 힌트, 실행 칸은 비움(정답 코드 없음).
- 131쪽 함께 해결하기: 1-1·1-2는 교과서처럼 첫 줄만 준 뼈대, 2번(응용하기)은 학생용 교과서에 인쇄된 일부(그래프 ① 리스트 0·1행과 딕셔너리 키 0·3, 그래프 ② 리스트 A·C·D행과 딕셔너리 A·B·E)만 보여 주고 나머지는 빈칸. 실행 칸은 비움.
- 더 해 보기(선택): 모둠 시간표를 2차원 리스트·2차원 딕셔너리로.

**줄인 것** — 131쪽 캐릭터 그림(gogo)은 넣지 않고 능력치 그림만 SVG로 다시 그림. 130쪽 스스로 해결하기 1번의 오류 까닭은 화면에서 미리 설명하지 않음(노트북에서 직접 확인). 01 자리 배치표의 「대괄호 한 개로 수정」은 129쪽 말풍선 질문과 같은 원리를 **다른 자료**로 보여 줌(교과서 예 `class1[4] = 100`의 결과는 화면에 없음). 03 연습 그래프는 교과서와 다른 새 그래프만 정답 확인을 하고, 교과서 그래프 ①·②의 표현(함께 해결하기 답)은 화면·노트북·이 문서 어디에도 넣지 않음. 개념 정리하기는 교과서 131쪽 문장을 옮기지 않고 새 상황 문장 빈칸으로.

**확인할 점**
- 129쪽 형식 표의 세 번째 학생 이름이 「인수」인데, 126쪽 그림 Ⅲ-8과 128·130쪽은 「민수」. 화면은 「민수」로 통일함.
- `작업자료/교과서코드_3단원/130쪽/130_2차원_딕셔너리_학생들_의복_치수_표현.py`의 `print('민수의 상의 치수:', class1['미송']['상의'])`는 키가 「미송」이라 85가 나옴(교과서 쪽은 `class1['민수']['상의']` → 100). 화면·노트북은 교과서 쪽대로 고침.
- 131쪽 응용하기 그래프 ②의 2차원 리스트에서 연결되지 않은 칸을 `x`로 쓰는데, 파이썬에서 `x`는 값을 넣지 않은 변수라 그대로 실행하면 오류(NameError)가 남. 노트북 힌트에 「x = 0처럼 먼저 값을 넣거나 0을 쓴다」를 덧붙임.
- 130쪽 스스로 해결하기 2번의 `f'…{ }…'`(f-문자열)는 교과서에 설명이 없어 노트북 힌트에 한 줄 설명을 넣음.
- 131쪽 그래프 ②에서 A와 D 사이에 두 간선(A→D, D→A)이 겹쳐 그려져 있음. SVG로 다시 그릴 때 두 선을 나란히 떼어 그리고 숫자를 각 선 옆에 둠. 화살표 방향은 교과서 그림 그대로 옮김(그림만 보고 읽기 어려우면 선생님 확인 필요).
- 03 「행 = 출발 정점, 열 = 도착 정점」은 교과서 본문에 문장으로 없고 131쪽 예시(그래프 ② A행)에서 읽어 낸 약속. 화면 카드에 이 약속을 밝혀 둠.

**검토 반영(1차)**
- 131쪽 개념 정리와 같은 문장을 사례형으로: 마무리 5-1을 통째로(요일별 [최고, 최저] 7일치를 리스트 하나에 담은 데이터는?, 극단어 「만」이 든 보기도 없앰). key3 첫 문장을 「학생마다 한 줄씩 있는 데이터를 여러 줄 묶으면 표 모양의 2차원 데이터」로 고침.
- 퀴즈 3-2를 「연결된 정점을 모두 고른 것은?」으로, 오답은 틀린 조합(0, 1 / 0, 1, 2)으로(정답 ③→②). 분포 ①4 ②5 ③4.
- 키 두 개로 찾아가기: 도전에서 맞힌 뒤에는 키 버튼과 확인 버튼을 잠그고 「다음」만 누르게 함. 문항별 결과(한 번에 맞힘/다시 해서 맞힘)를 `dictRes`에 기록.
- 행과 열 찾기: 도전이 끝난 뒤 칸을 눌러도 오류가 나지 않게 막음(qi 범위 검사). 분량을 줄이려고 도전을 5문제 → 3문제로(칸 2 + 행 1). 131쪽 1번은 그대로 필수.
- 그림의 aria-label에서 간선·능력치 값(함께 해결하기 답이 되는 내용)을 빼고 「교과서 131쪽 그래프 ②」처럼 이름만 남김.
- 자리 배치표 예측의 보기를 짧은 것 → 긴 것 순서로, 「1행 0열만」(극단어) 보기를 「1행 0열 값이 '빈자리'가 된다」로. 시작 화면 메모 안내를 「적어 보세요」로(입력 칸이라 그릴 수 없음).
- 교과서 그래프 ②의 간선 숫자 위치를 손봄: A→D(7)·D→A(9)는 B→E 선과 겹치지 않게 두 선의 위쪽 양옆에, B→E(6)는 B 쪽 위에.
