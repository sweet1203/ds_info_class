**오렌지3 확인 결과(교과서 ows·설치된 오렌지3 3.40 소스로 확인)**
- 교과서 ows의 Formula 식은 `0 if 습도+태양광_발전량_kW_>150 else 1`(Values Y, N), Select Rows 조건은 `이상치 is N`. 실제 데이터에서 결측치는 산란일사량 1개·풍속 1개, 규칙에 걸리는 이상치는 5개, 남는 데이터는 52,553개(화면에 씀).
- Data Table은 줄을 하나도 고르지 않으면 전체 데이터를, 줄을 고르면 고른 줄만 다음 위젯으로 보낸다. 그래서 흐름도는 Formula → Select Rows, Select Rows → Data Table (2)·Scatter Plot (1)로 바로 잇고, 교과서처럼 Data Table을 거치는 연결도 된다고 안내했다.
- Merge Data는 숫자형 ID를 스스로 짝짓지 않고 처음에 **Row index**로 맞춘다(문자열 meta만 자동으로 찾음). 두 파일은 줄 순서가 같아(15,000줄 모두 User_ID 일치) 결과는 같지만, 교과서 설명(User_ID 기준)에 맞게 User_ID ↔ User_ID로 바꾸라고 설정 표에 적었다.
- Discretize의 Natural binning(desired bins 3) 결과는 40·60 구간(실제 데이터 40세 미만 7,502명, 40~60세 4,405명, 60세 이상 3,093명).

**다음 차시와 잇기** — 04 끝에 「File → Save As로 칼로리 전처리 저장, 빅데이터 시각화에서 이어서 작업」을 두었다(u2-visualize가 지난 시간 저장한 .ows를 연다고 안내함). 시각화 위젯(Box Plot·Distributions 등)은 넣지 않았고, 「합친 데이터로 더 알아보고 싶은 것」 메모만 둠.

**50분 흐름(검토 반영 후)** — 도입(3분) 오렌지3 실행·태양광 파일 내려받기 → 01(6분) 정의·처리 과정, 분류 게임 + 한 줄 메모 → **02(9분 무렵 시작, 8분)** 작은 표 4단계 + 메모 → **03(17분 무렵 시작, 15분)** 태양광 실습, 진행 체크 바로 아래 `solarSteps`를 실습하면서 적기 → 04(32분 무렵, 4분) 합치기 체험(브라우저) + 메모. 오렌지3 칼로리 실습은 접어 둔 선택 활동(시간이 남으면, 아니면 빅데이터 시각화 처음 5분 — u2-visualize 02의 「나. 파일이 없거나 지난 시간 칼로리 실습을 하지 않았다면」 안내와 맞춤) → 05(3분) → 마무리(7분). 질문폼 근거 활동(01·02·03)은 모두 30분 안에 시작.

**줄인 것** — 71쪽 데이콘 내려받기·QR, 교과서 자료실 안내는 「선생님이 알려 주는 폴더」로 바꿈. 오렌지3 화면 캡처는 쓰지 않고 SVG 흐름도와 설정 표로. 71쪽 「데이터를 불러오는 방법」(CSV File Import·Datasets·SQL Table 위젯), 72쪽 산점도 옵션 목록(Show color regions 등)과 Impute 기능 전체 목록은 실습에 필요한 것(Remove instances with unknown values, Average/Most frequent, Show all data on mouse hover)만 남김. 75쪽 개념 정리하기는 그대로 옮기지 않고 새 상황 빈칸 4개로.

**확인할 점**
- 73쪽 ➎ 조건문 「0 if 습도 + 태양광 발전량_kW_> 150 else 1」은 `발전량` 앞이 띄어쓰기라 그대로 입력하면 오류가 난다. 오렌지3는 속성 이름의 공백·괄호를 `_`로 바꾸므로 `태양광_발전량_kW_`가 맞다(교과서 ows도 이렇게 저장됨). 화면에는 바른 식을 쓰고 Select Feature에서 골라 넣으라고 안내.
- 72쪽 ➌ 「Feature Stastisics」는 오타(→ Feature Statistics).
- 72쪽 ➌ 「‘습도’와 ‘태양광 발전량(kW)’ 합이 150을 넘는」 기준은 단위가 다른 두 값을 더한 것이라 근거 설명이 없다. 화면에서는 「습도가 높은데 발전량도 높은, 흐름에서 벗어난 점」을 찾는 규칙으로만 소개했다.
- 72쪽 날개 「Model-based imputer: 가장 가까운 값으로 처리함」은 실제 기능(모델로 값을 예측해 채움)과 조금 다르다. 화면에는 넣지 않음.
- 74쪽 ➌ 「영향을 미치지 않는 ‘Gender’」는 성별이 칼로리에 영향이 없다는 근거가 없다. 화면에서는 「참고만 하기 위해 meta로」만 씀.
- 75쪽 Merge Data의 기본 맞춤이 Row index라는 점(위 「오렌지3 확인 결과」)은 교과서에 나오지 않는다.
- 70쪽 날개의 데이터 축소·데이터 변환은 본문 세 작업 밖의 용어라 분류 게임에는 넣지 않고 한 줄 소개만 했다. 75쪽 나이 구간 나누기(Discretize)가 세 작업 가운데 무엇인지는 교과서가 밝히지 않아 화면에서도 분류하지 않음.

**선생님 준비물** — 드라이브 「선생님이 알려 주는 폴더」에 `태양광 발전.xlsx`(교과서 소스 코드 71쪽), `calories.csv`·`exercise.csv`(74쪽, 지난 차시와 같은 파일). 학생 노트북에 오렌지3 설치 확인.
