# u2-visualize 설계표 — 빅데이터 시각화 · 빅데이터 정리 (교과서 76~83쪽)

## 필수 실습과 선택 실습을 나눈 까닭
- **필수 ① 칼로리 데이터(박스 플롯 · 산점도)** — 76쪽 학습 목표(분석 도구로 시각화, 결과 해석)의 중심이고, 지난 시간 전처리한 워크플로를 그대로 이어 쓸 수 있어 준비 시간이 가장 짧다(위젯 2개만 붙이면 됨). 박스 플롯(통곗값)과 산점도(관계)는 같은 데이터에서 서로 다른 것을 보여 주므로 도입 질문(해석이 다른 이유)에 바로 답하게 해 준다. 같은 화면의 분포도와 심장 박동 수·체온 산점도는 설정만 바꾸는 반복이라 선택으로 접었다.
- **필수 ② 윤동주 시 워드 클라우드** — 비정형 데이터 시각화의 대표 예이고 위젯 3~4개로 끝나며 파일 하나(17KB)만 있으면 된다. 결과가 바로 눈에 보여 81쪽 「생각해 보기(정형·비정형 시각화 비교)」를 필수 ①과 짝지어 할 수 있다.
- **선택: 학교 위치 지도(79쪽)** — Geo·Timeseries 추가 기능과 지도 바탕 그림(인터넷)이 필요하고, 데이터(3.1MB)가 CP949 인코딩이라 글자 깨짐 대응이 필요할 수 있다. 개념(정형 데이터의 정보 종류)은 03 화면과 분류 게임으로 다룬다.
- **선택: 은하 이미지 · FIFA(80쪽)** — 은하는 폴더 3개(150장) 내려받기가 필요하고, FIFA는 5.7MB 데이터 + 선수 사진을 인터넷 주소에서 불러와 학교망에서 느리거나 막힐 수 있다. 이미지 데이터 시각화의 개념은 04 카드로 다룬다.
- **선택: 데이터랩(76쪽)** — 외부 사이트에 의존하고 오렌지3와 별개라, 01 실험실(브라우저 안 체험)로 같은 목표(그래프로 비교해 보기)를 대신하고 원래 활동은 접어 두었다.

## 50분 흐름 (시작 화면 「50분 계획」과 같음)
준비(2분) 오렌지3 실행·파일 3개 내려받기 → 01(8분, ~10분) 개념 훑기, 실험실 미션 2개 이상 → **02(17분, ~27분)** 칼로리 데이터 준비(가: 저장 파일 열기 1분 / 나: File 2개 → Merge Data(User_ID 짝) → Discretize 5분) · 필수 ①-가 박스 플롯 · ①-나 산점도 · 메모 → 03(3분, ~30분) 정형 데이터, 분류 게임 → **04(9분, ~39분)** 필수 ② Corpus 불러오기~워드 클라우드 → 05(5분, ~44분) 맞춤 활동(과정·기능), 빈칸, 성취도 → 마무리(6분) 핵심 질문, 퀴즈, 질문폼. u2-preprocess가 칼로리 오렌지3 실습을 선택으로 내렸으므로, 많은 반에서 02의 「나」 경로(5분)가 기본이라고 보고 시간을 잡았다. 질문폼 근거는 27분 무렵까지 닿는다. 선택 실습은 필수를 일찍 마친 학생용. 오렌지3는 시작 화면에서 먼저 켜게 해 01을 보는 동안 열리도록 했다.

## 줄인 것
- 교과서 실습 화면 캡처는 쓰지 않고, 위젯 연결은 SVG 흐름도(교과서 ows 파일의 연결을 그대로 따름), 설정값은 표로 안내.
- 77~80쪽 실습의 결과 수치와 결과 문장은 학생이 직접 확인할 결과라 화면과 이 문서에 적지 않았다. 회귀선 기울기 숫자는 축의 단위에 따라 달라 보여 「오른쪽 위로 올라가는 방향」으로만 읽게 했다.
- 79쪽 추가 기능 설치(Options → Add-ons)는 수업 중에 하지 않고 선생님이 미리 설치하는 것으로(설치 후 재시작이 필요해 시간이 많이 걸림). 화면에는 「카테고리가 안 보이면 선생님께」만 안내.
- 80쪽 FIFA 데이터 「캐글에서 검색·내려받기」(회원 가입 필요)는 선생님 폴더 파일로 바꿈.
- 82쪽 맞춤 활동 2(관심 분야 데이터를 수집해 시각화)는 시간상 **두 속성 + 데이터를 구할 곳 + 시각화 방법 고르기**까지만 하고, 실제 수집·시각화는 「시간이 넉넉하면」으로 둠.
- 81쪽 개념 정리하기 문장은 옮기지 않고, 새 상황 문장 3개(기온 기록 선그래프, 응원 영상·소감 글, 반 친구 표)로 빈칸 고르기를 만듦.
- 실험실 그래프는 가상 데이터(시드 고정 난수, 교과서 데이터 아님). 박스 플롯은 수염을 최솟값·최댓값까지 그리고 이상치 점은 따로 표시하지 않음. 사분위수라는 말은 쓰지 않고 「상자: 가운데에 모인 절반의 값」으로만 풀어 씀(과정안 「4등분하여 확인한다는 점만」).

## 선생님 준비물 (선생님이 알려 주는 폴더)
- **필수**: `calories.csv` · `exercise.csv`(74·77쪽 폴더, 지난 시간과 같은 파일 — 워크플로를 저장하지 못한 학생용), `윤동주 시.csv`(81쪽 폴더, 17KB).
- **오렌지3 추가 기능**: **Text**(필수 ②)는 꼭 미리 설치. Geo · Timeseries · Image Analytics는 선택 실습용. 설치 뒤 오렌지3 재시작 필요.
- **선택**: `1. 청주대학교_지방교육재정연구원_초중등학교위치_.csv`(79쪽, 3.1MB), `은하 이미지` 폴더(80쪽, 나선은하·불규칙은하·타원은하 각 50장), `CLEAN_FIFA23_official_data.csv`(80쪽, 5.7MB — 같은 폴더의 zip 14MB는 필요 없음).
- 76쪽 선택 활동용 검색어 트렌드 사이트 주소(화면에는 주소를 쓰지 않음).
- **인코딩**: `윤동주 시.csv`와 학교 위치 csv는 **CP949(EUC-KR)** 로 저장되어 있다(직접 열어 확인). 오렌지3 버전에 따라 한글이 깨질 수 있으니 **UTF-8로 다시 저장한 사본**을 폴더에 두는 것을 권장. (calories·exercise는 영문이라 문제없음.)

## 확인할 점
- 81쪽 4번 위젯 이름 「Proprocess Text」는 오타(→ Preprocess Text). 화면은 바로잡음.
- 81쪽 데이터 이름 「윤동주 시(100.csv)」와 실제 파일 이름 「윤동주 시.csv」가 다르고, 본문은 「윤동주 시 50개」인데 파일은 53편(53행)이다. 화면은 파일 이름 그대로, 분류 게임 카드는 「50여 편」으로 씀.
- 78쪽 결과 설명 문장에 조사 오류(「2차 곡선을 형태로」 → 「2차 곡선 형태로」)가 있다. 화면에는 결과 문장을 옮기지 않고 「직선처럼/휘어지며 올라가나요?」로 물음.
- 51쪽 옆글은 비정형 데이터의 예로 「문자」를 들고, 79쪽 옆글은 정형 데이터가 포함하는 정보로 「문자(성별, 이름, 주소)」를 든다. 화면에서는 **표의 칸에 든 문자 정보 = 정형**, **형식 없는 긴 글(시 본문, 소감 글) = 비정형**으로 구분해 분류 게임과 빈칸을 만들었다.
- 75쪽 「User_ID라는 공통 속성이 있으므로 두 데이터를 합하면」만 보면 저절로 합쳐질 것 같지만, 오렌지3 Merge Data는 처음 짝이 Row index다. 02 준비의 「나」 경로에 「짝을 User_ID ↔ User_ID로 바꿔요」를 넣어 u2-preprocess 안내와 맞춤. u2-preprocess가 칼로리 오렌지3 실습을 선택으로 내렸으므로 「나」 경로(5분)를 기본으로 보고 50분 흐름을 잡았다.
- 77쪽 박스 플롯 실습은 Merge Data에, 78쪽 산점도는 Discretize에 연결한다(교과서 77쪽 ows와 같음). 02 흐름도도 이 연결을 따름.
- 77쪽 그림의 「표준편차」 표시는 오렌지3 박스 플롯의 평균·표준편차 선을 가리킨다. 화면은 77쪽 옆글 정의만 용어 카드로 두고 그림 읽기는 중앙값·최솟값·최댓값에 집중.
- 79쪽 Geo Map 지도 바탕과 80쪽 FIFA 선수 사진(데이터 안의 사진 주소)은 인터넷 연결이 필요하다. 학교망에서 막히면 선택 실습을 건너뛰어도 필수 활동과 질문폼에는 지장이 없다.
- 시작 화면의 「오늘의 질문」은 76쪽 도입 질문 두 문장을 한 문장으로 합침. 핵심 질문은 66쪽(빅데이터 중단원).
- 76쪽 선택 활동(검색어 두 개 비교)의 예시 키워드는 교과서와 다른 것(줄넘기 · 마스크)으로 바꿈.

## 검토 반영(1차)
- 실습 번호를 「필수 실습 ①-가 박스 플롯 / ①-나 산점도」, 「필수 실습 ② 워드 클라우드」로 통일(흐름도 이름표·메모 모아 보기 이름도). 03 지도 선택 실습 요약줄은 「04 워드 클라우드까지 마친 뒤」.
- 02 준비 카드를 접지 않고 두 갈래로 펼침: 「가. 저장 파일이 있으면 열기」 / 「나. 없거나 지난 시간 칼로리 실습을 하지 않았다면(5분): File 2개 → Merge Data(calories → Data, exercise → Extra Data, 짝 User_ID ↔ User_ID) → Discretize(Age, Natural binning, 3)」. 시작 화면에서 calories.csv · exercise.csv도 함께 내려받게 하고, 50분 계획을 01 10분 · 02 17분 · 03 3분 · 04 9분 · 05 5분 · 마무리 6분으로 고침. 실험실 미션은 「두 개 이상」으로.
- 05 빈칸 고르기에서 81쪽 개념 정리의 정의 구절을 빼고 상황만 남김(기온 숫자 표 → 선그래프로 바꾼 일, 응원 영상과 소감 글, 명렬표).

## 검토 반영(2차)
- 공용 chips는 「 · 」를 저장 구분자로 쓰므로, 칩 이름 「히스토그램 · 분포도」를 「히스토그램(분포도)」로 바꿈(새로 고침 뒤 표시가 사라지고 중복이 붙던 문제).
- 설계표 02 · 05 행과 확인할 점의 옛 내용(3분 복구 접기, 맞춤 활동 3개 필수)을 지금 화면에 맞게 고침. 교과서 실습의 결과 수치·결과 문장은 이 문서에서도 지움.
- 03 선택 실습: Time Slice에 붙이는 Geo Map (1)은 「설정은 위 Geo Map과 같게(위도 · 경도 · 학교급구분)」로 안내.
- 02 박스 플롯: 오렌지3 3.40 `owboxplot.py`(box_group)를 확인한 결과 상자 높이만큼의 노란 세로선이 중앙값(값 표시는 상자 아래), 파란 짧은 세로선이 평균(값 표시는 위), 평균 양옆 파란 가로선이 평균 ± 표준편차다. 이 구분을 한 줄로 안내함.
- 04 Preprocess Text: Orange3-Text `owpreprocess.py`의 FilteringModule 기본값이 Stopwords(영어)라서, 「Stopwords는 체크를 끄고 Regexp만」으로 안내(Regexp 기본 패턴은 문장 부호를 지움).
