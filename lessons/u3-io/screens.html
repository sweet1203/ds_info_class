02

print() 함수와 input() 함수

교과서 122쪽 · 표준 출력 print() 함수, 표준 입력 input() 함수, int() 함수

쉽게 말하면print()는 괄호 안의 내용을 화면에 보여 주고, input()은 키보드로 입력받은 값을 문자열로 돌려줘요. 입력받은 숫자로 계산하려면 int()로 바꿔야 해요.

🖥️ 표준 출력 print() 함수

  • 괄호 안의 내용을 출력해요. 여러 개의 값은 ‘,’(콤마)로 구분해요.
  • 출력한 뒤에는 새로운 줄에서 시작해요.
  • 괄호 안에 변수의 값이나 변수를 포함한 수식도 넣을 수 있어요. 수식을 넣으면 연산한 결과를 출력해요.
fruit = '청포도'
print('내가 좋아하는 과일은', fruit, '입니다.')
a = 7
b = 5
print(a,'*', b, '의 계산 결과는', a * b, '입니다.')
내가 좋아하는 과일은 청포도 입니다.
7 * 5 의 계산 결과는 35 입니다.

콤마로 구분한 값들은 한 칸씩 띄어 출력돼요. 대화식 모드(코랩에서는 칸의 마지막 줄)에서는 print() 없이 수식이나 변수만 써도 값이 보여요.

⌨️ 표준 입력 input() 함수

  • 괄호 안의 문자열을 모니터에 보여 주고, 키보드로 입력받은 값을 문자열로 저장해요.
  • 입력받은 값을 저장하려면 변수에 대입해요.
age = input('몇 살이세요?')
print('당신은', age, '살이군요.')
몇 살이세요?19
당신은 19 살이군요.
input() 함수로 입력받은 값은 문자열로 저장되므로 정수로 바꾸고 싶을 때는 정수 변환 int() 함수를 써요. 자료형을 바꾸는 함수로 int(), float(), list(), tuple() 등이 있어요.

🔬 직접 입력하고 실행하기 · 내년에는 몇 살?

▶ 실행을 누르면 아래 실행 화면에 질문이 나와요. 값을 입력하고 Enter를 눌러요. 오른쪽 변수 표에서 age의 자료형을 꼭 봐요. 그다음 int()를 뺀 코드로 바꿔 다시 실행해요.

📚 지식 키우기 · 함수란? (125쪽, 보충·심화)

프로그래밍을 하다 보면 특정 작업을 반복해서 하게 돼요. 이때 특정 기능을 수행하는 코드를 따로 작성해 함수로 만들어 두고 필요할 때 호출해 써요. 함수는 함수명, 기능에 필요한 값을 입력받는 변수인 매개 변수, 정의된 기능을 수행하는 명령문, 수행 결과를 되돌려주는 반환값으로 구성돼요. 함수를 쓰려면 함수명에 인수를 함께 넣어 호출해요.

  • 내장 함수(파이썬이 기본으로 제공): print(), input(), str(), abs(n), divmod(m, n), max(시퀀스) …
  • 외장 함수(import 명령어로 불러와 사용): import random 뒤 random.randint(m, n) …
  • 사용자 정의 함수: 사용자가 직접 정의해서 사용(144쪽에서 배워요).

함수의 장점: 같은 기능이 필요한 곳에서 다시 쓸 수 있어 코드의 중복이 줄고, 기능을 바꿀 때 그 함수만 고치면 되며, 함수 내부를 몰라도 기능을 쓸 수 있어요.

03

파일입출력은 어떻게 활용할까?

교과서 123쪽 · 파일 처리 과정, 파일입출력 모드, 파일 처리 함수

쉽게 말하면프로그램이 끝나도 남겨 두고 싶은 결과는 파일에 써 두고, 많은 데이터는 파일에서 읽어 와요. 먼저 파일을 열고, 읽거나 쓰고, 다 쓰면 닫아요.

프로그램을 작성할 때 파일로 저장된 대량의 데이터를 읽어 오거나, 다음에 다시 사용하려고 결괏값을 파일로 저장해야 하는 경우가 있어요. 이때 파일에 데이터를 읽고 쓰려고 파일입출력을 활용해요.

파일 변수 = open(파일명, 파일입출력 모드)

open()

파일의 데이터를 처리하려면 우선 open() 함수를 사용해 파일을 열어요.

파일명

작업할 파일명을 지정할 때 다른 경로에 있는 파일이면 경로를 지정해야 해요.

파일입출력 모드

작업 목적에 맞게 어떤 형식으로 할지 모드를 정해요.

모드뜻
'r' 읽기파일의 데이터를 읽어요. 파일이 없으면 오류가 생겨요.
'w' 쓰기파일에 데이터를 써요. 파일이 있으면 기존 데이터는 삭제되고, 파일이 없으면 새로 만들어요.
'a' 추가파일에 데이터를 이어 써요. 파일에 있던 데이터는 유지돼요.

'r'read() 파일 전체 내용을 반환해요.
readline() 한 줄을 읽어 오고, 파일 포인터의 위치를 다음 줄로 이동해요.
readlines() 파일 포인터 위치 이후의 모든 줄을 읽어서 각 줄을 요소로 갖는 리스트로 반환해요.
'w' 'a'write() 파일 포인터의 현재 위치에 내용을 작성해요.

파일 포인터는 파일에서 입출력 동작이 일어나는 위치(깜빡깜빡하는 위치)예요.

파일 처리가 끝난 뒤에는 파일 변수.close()로 파일을 닫아 줘요. open()으로 열었으면 읽거나 쓴 다음 꼭 close()로 마무리하는 습관을 들여요.

📄 파일 쓰기와 파일 읽기 (123쪽 코드와 같은 구조, 파일 이름과 내용만 바꿈)

# 파일 쓰기
f = open('나의_다짐.txt', 'w')
f.write('하루에 물 여덟 잔 마시기\n')
f.write('잠들기 전 휴대폰 내려놓기\n')
f.close()
# 파일 읽기
f = open('나의_다짐.txt', 'r')
a = f.read()
print(a)
f.close()

05

마무리

핵심 문장 · 처음 생각과 비교 · 마무리 퀴즈 · 질문폼

계산기 앱은 값을 받고(입력) → 계산하고(처리) → 결과를 보여 준다(출력). 키보드로 받는 쪽은 표준 입력, 모니터로 보여 주는 쪽은 표준 출력이고, 이 둘을 묶어 표준입출력이라 부른다.
print()는 괄호 안의 내용을 출력하고 여러 값은 콤마로 구분한다. input()은 입력받은 값을 문자열로 저장하므로, 정수로 계산하려면 int()로 변환한다.
결과를 남겨 두거나 많은 데이터를 불러올 때는 파일입출력을 쓴다. open()으로 열 때 모드를 고르고('r' 읽기, 'w' 새로 쓰기, 'a' 이어 쓰기), read()나 write()로 다룬 뒤 close()로 닫는다.
