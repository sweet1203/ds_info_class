4 중첩 제어 구조

다양한 상황이 발생하는 실생활 문제를 해결하기 위해서는 하나의 제어 구조가 아닌 여러 가지 제어 구조를 복합적으로 활용하여 프로그래밍해야 해요. 그래서 조건문 안에 조건문이 포함되어 있거나 반복문 안에 조건문이 포함되는 등, 제어 구조 내부에 다른 제어 구조를 포함하여 작성하는데 이를 중첩 제어 구조라고 해요. 예를 들어, if문 안에 if문이 들어 있거나 if문 안에 elif문이 포함된 구조 또는 for문이나 while문 같은 반복문을 이용해 중첩 제어 구조를 만들 수 있어요.

in 연산자 A in B의 형식으로 사용해서 A가 B에 포함되어 있으면 참, 포함되어 있지 않으면 거짓을 반환해요. 예) '여' in '여자' → True
논리 연산자 and, or, not이 있어요. and는 A와 B 모두 참일 때 참, or는 A와 B 둘 중 하나라도 참일 때 참, not은 논릿값을 뒤집어서 참이면 거짓을, 거짓이면 참을 반환해요.

1 for문

반복 구조는 주어진 반복 횟수나 조건을 만족하는 동안 반복하여 실행하는 제어 구조예요. for문은 주어진 반복 범위만큼 명령어를 반복하여 실행하며, 일반적으로 반복할 횟수가 정해져 있을 때 사용해요.

  • 반복 범위에 있는 값들이 변수에 순서대로 들어가면서 반복돼요.
  • 반복 범위에는 리스트, 튜플, 문자열, range 함수 등이 올 수 있어요.
  • 반복 범위만큼 for문에 속한 명령어를 실행해요.

쉽게 말하면range()는 「몇부터 몇 전까지, 몇씩」 정수 범위를 만들어 주는 함수예요. for문의 반복 범위에 넣으면 정해진 횟수만큼 반복할 수 있어요. 끝 값은 범위에 들어가지 않는다는 점을 기억해요.

2 range() 함수

range() 함수는 for문과 함께 자주 사용되는 함수로, 특정 구간의 정수 범위를 만들어 줘요.

range(시작, 끝, 간격)

시작

시작하는 숫자이며, 생략하면 시작 범위를 0으로 설정해요.

끝

끝 범위를 넣으며, 끝-1까지로 범위를 설정해요. 생략할 수 없어요.

간격

시작 숫자부터 간격 숫자만큼 증가하는 범위를 만들어요. 생략하면 간격 크기를 1로 설정해요.

range() 함수 예시만들어지는 정수
range(0, 10, 2)0, 2, 4, 6, 8
range(5, 10)5, 6, 7, 8, 9
range(5)0, 1, 2, 3, 4
range(5, 0, -1)5, 4, 3, 2, 1
i의 값: 0 i의 값: 1 i의 값: 2

반복되는 명령어는 어떻게 표현할까? ③ while문과 난수

교과서 140쪽 · while문, 무한 루프, random 모듈, 스스로 해결하기(while문과 난수) · 코랩 실습

쉽게 말하면while문은 「조건이 참인 동안」 계속 반복해요. 몇 번 반복할지 미리 정해지지 않은 경우에 써요. 반복할 때마다 조건으로 돌아가 다시 확인하므로, 조건이 언젠가 거짓이 되도록 만들어야 해요.

3 while문

while문은 조건을 만족하는 동안 명령문을 반복하여 실행하는 제어 구조로, 주로 반복 횟수가 미리 정해지지 않은 경우에 사용돼요. while문의 조건식을 문제 해결 논리에 맞게 작성하지 않으면 while문을 나가지 못하고 무한 루프에 빠질 수 있어요.

  • while 뒤에 조건을 작성하고, 그 뒤에 콜론(:)을 붙여요.
  • while 뒤의 조건이 참이면 명령을 실행해요.
  • while문 안의 마지막 명령을 실행한 후에는 while 뒤의 조건으로 돌아가요.

🎲 업다운 게임 · while문이 도는 모습 보기

컴퓨터가 1~100 사이의 정수를 무작위로 하나 골랐어요. 수를 말하면 「정답보다 크다.」, 「정답보다 작다.」로 알려 줘요. 오른쪽에서 한 번 말할 때마다 반복 조건을 다시 확인하는 모습을 봐요.

random 모듈 파이썬에서 미리 만들어진 모듈을 사용하면 쉽게 프로그래밍할 수 있어요. 무작위로 생성한 숫자(난수)가 필요할 때는 random 모듈을 이용해요.

4 break와 continue

반복문을 실행하다가 반복을 완전히 그만두거나 현재 반복문만 건너뛰어야 하는 경우가 있어요. 이때 break나 continue를 사용해 반복문을 제어할 수 있어요.

break

반복문을 완전히 끝내고 다음 명령으로 이동해요. 보통 if문과 함께 사용해요.

continue

현재 실행만 중단하고 다시 반복문으로 돌아가 반복을 이어서 실행해요.

중첩 제어 구조는 if문 안의 if문, 반복문 안의 선택문처럼 여러 제어 구조를 겹쳐 쓴 구조다. 반복문 안에 선택문, 반복문 안에 반복문, 선택문 안에 선택문 등으로 복잡한 실생활 문제를 해결한다.
for문은 반복 범위의 값을 변수에 차례로 넣으며 반복하고, 반복 횟수가 정해져 있을 때 쓴다. range(시작, 끝, 간격)은 시작부터 끝-1까지 간격만큼 증가하는 정수 범위를 만든다.
while문은 조건을 만족하는 동안 반복하고, 반복 횟수가 정해지지 않았을 때 쓴다. break는 반복을 완전히 끝내고, continue는 현재 실행만 건너뛰고 반복을 이어 간다.
