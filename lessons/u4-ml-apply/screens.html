주요 용어: SDGs · 기계학습으로 해결할 수 있는 문제

01

기계학습으로 어떤 문제를 해결할 수 있을까?

교과서 188쪽 · 해결할 수 없는 문제와 해결할 수 있는 문제

쉽게 말하면기계학습은 데이터에서 패턴을 학습해 예측해요. 그래서 데이터에 패턴이 없거나, 학습할 데이터가 충분하지 않으면 풀기 어려워요. 반대로 프로그래밍으로 규칙을 일일이 적기 어려웠던 문제도, 패턴이 담긴 데이터가 넉넉하면 풀 수 있어요.
🎲

기계학습으로 해결할 수 없는 문제

복권 당첨 번호처럼 완전히 무작위로 정해지는 숫자는 패턴이 존재하지 않아 예측할 수 없어요. 또 기계학습 모델은 데이터가 많이 필요해서, 특정한 상황에서 충분한 양의 데이터가 없으면 해결하기 어려워요. 데이터의 특성과 문제의 복잡성에 따라 알맞은 방법과 기술을 골라야 해요.

✅ 기계학습으로 해결할 수 있는 문제

🌦️ 기후 예측

기후 과학자들은 기온, 습도, 바람 속도 등의 데이터로 미래의 기후 패턴을 예측할 수 있어요.

회귀 주식 시장 동향, 질병 진행 속도 예측 등

🩺 의료 진단

의사들은 환자의 증상과 진단 검사 결과를 바탕으로 특정 질병을 분류하고 예측할 수 있어요.

분류 스팸 메일 탐지, 신용 카드 사기 탐지 등

🛍️ 고객 세분화

마케팅 전문가들은 구매 패턴이 비슷한 고객 그룹을 찾아 그에 맞는 마케팅 전략을 세울 수 있어요.

군집 사회 경제적 그룹 식별, 유전자 분석 등

🎯 기계학습으로 풀 수 있을까?

카드의 상황을 읽고, 패턴이 있는지와 학습할 데이터가 충분한지를 따져 골라요.

02

SDGs 관련 문제를 기계학습으로 어떻게 해결할까?

교과서 189~191쪽 · 지속가능발전목표 · 기계학습 프로젝트 수행 과정

쉽게 말하면SDGs(지속가능발전목표)는 유엔(UN)이 2015년에 세계적으로 약속한 17개 목표예요. 2030년까지 빈곤, 교육, 보건, 환경 같은 문제를 해결해 지구와 인류에게 더 나은 미래를 만들려는 것이지요. 이 가운데에는 인공지능 기술로 해결할 수 있는 문제도 있어요.
🌾

목표 2 · 식량 안보와 지속 가능한 농업

흉년이 잦아 곡식 수확량이 줄고 있는 개발 도상국의 식량 문제를 돕는 카네기 멜론 대학교의 프로젝트예요. 데이터를 수집하고 기계학습으로 분석해 수확량을 늘리는 특성이 무엇인지 찾아요. 가뭄과 열에 강한 곡식인 수수의 수확량을 늘리는 것이 목표예요.

🌊

목표 14 · 해양 생태계 보전

멸종 위기 동물인 듀공은 움직임이 빨라 추적하기 어려웠어요. 호주 머독 대학교 연구팀은 퀸즐랜드 대학교 인공지능 연구팀과 함께, 드론으로 찍은 바다 항공 사진을 인공지능 프로그램에 입력하고 기계학습으로 듀공의 위치를 찾아냈어요.

🔁 기계학습 프로젝트 수행 과정

이 과정을 따르면 문제 정의로 목표와 방향이 분명해지고, 불필요한 작업을 막고, 모델 평가와 성능 개선에도 쓸모 있는 결과를 얻을 수 있어요. ①·②는 Ⅱ단원 빅데이터에서 해 봤으니, 오늘은 ③ 모델 학습부터 해요.

1문제 상황 이해하기문제의 범위를 정하고 목표와 요구 사항을 세워 문제를 정의해요.
2데이터 수집 및 전처리하기데이터를 모으고 불필요한 데이터 제거, 결측치 · 이상치 처리를 해요.
3모델 학습하기선정한 알고리즘으로 모델을 학습시켜요. 하이퍼 파라미터를 조정하며 학습과 검증을 되풀이해요.
4모델 평가하기성능을 평가하고, 특성을 더 뽑거나 다른 모델을 써서 개선해요.

03

칼로리 소모량을 예측해 볼까?

교과서 192~193쪽 · 문제 1 · 지도학습(회귀) · 오렌지3 실습

쉽게 말하면운동 시간 · 심장 박동 수 · 체온 · 키 · 몸무게 같은 독립 변수로 칼로리 소모량이라는 종속변수(연속형 실수)를 예측해요. 데이터의 80%로 선형 회귀 모델을 학습시키고, 남겨 둔 20%로 얼마나 잘 맞히는지 평가해요.
1 데이터 수집 및 전처리하기Ⅱ단원(74쪽)에서 두 파일을 합친 칼로리 데이터를 써요.
2 모델 학습하기Select Columns로 역할을 정하고, Data Sampler로 나눠 Linear Regression으로 학습해요.
3 모델 평가하기Predictions에 테스트 데이터를 넣어 예측값과 평가 지표를 봐요.
💡 먼저 평가 지표 미리 보기오렌지3가 열리는 동안 바로 아래 체험으로 MAE와 R2를 익혀요(3분).

📏 먼저 해 보기 · 평가 지표 미리 보기 (새로 만든 6명의 테스트 데이터)

두 모델이 같은 6명의 칼로리 소모량을 예측했어요. 모델을 바꿔 가며 오차와 MAE, R2가 어떻게 달라지는지 봐요. 점이 대각선(예측값 = 실젯값)에 가까울수록 잘 맞힌 거예요.

MAE (Mean Absolute Error) · 오차의 절댓값을 평균한 값. 「평균 몇 kcal쯤 어긋나는지」를 알려 줘요. 작을수록 좋아요.
R2 (R squared, 결정계수) · 회귀 모델의 정확도를 나타내는 지표. 1에 가까울수록 성능이 우수해요.

🍊 준비: 칼로리 데이터 흐름 열기

가. 「칼로리 전처리」 파일을 저장해 두었다면

  1. File → Open으로 Ⅱ단원에서 저장한 「칼로리 전처리」 워크플로(.ows)를 열어요.
  2. 아래 흐름도의 회색 위젯(calories · exercise · Merge Data)이 있으면 준비 끝이에요.

나. 파일이 없다면 (3분)

  1. 선생님 폴더에서 받은 「전처리한 칼로리 소모량 데이터」 워크플로를 File → Open으로 열어요.
  2. calories File 위젯을 더블 클릭해 calories.csv를, exercise File 위젯에서 exercise.csv를 다시 골라요(파일 위치가 컴퓨터마다 달라서예요).
  3. Merge Data의 Data Table을 열어 Calories와 Age · Duration이 한 표에 있는지 봐요.

✍️ 내 모델의 평가 결과

Features 구성이나 Data Sampler 설정이 다르면 친구와 값이 조금 다를 수 있어요.

🔬 시간이 남으면 · 독립 변수를 바꿔 보기 (모델 평가 및 개선)

모델 평가하기 단계에서는 특성을 더 뽑거나 빼 보며 성능을 개선해요. Select Columns에서 Features를 바꾸면 Predictions의 값이 바로 바뀌어요.

  1. Features에 Height · Weight만 남기고 나머지를 Ignored로 옮겨 R2와 MAE를 봐요.
  2. 이번에는 Duration만 남겨 봐요.
  3. 다시 7개를 모두 Features로 돌려 놓아요.
📝 스스로 해결하기 · 실제 데이터(설문지)로 예측하기 (선택 · 선생님 안내가 있을 때)
  1. 스마트 워치나 건강 앱으로 운동 후 신체 정보(키, 체온, 운동 시간, 몸무게, 나이, 성별, 1분 동안 심장 박동 수)를 기록하는 온라인 설문지를 만들어 공유해요. 선생님이 만든 설문지를 써도 돼요.
  2. 새 File 위젯의 주소 칸에 선생님이 알려 주는 설문 결과 주소를 넣고, 이 위젯을 Predictions의 Data로 이어 칼로리 소모량을 예측해요. 열 이름은 학습 데이터와 같아야 해요(Height, Body_Temp, Duration …).

개인 정보가 드러나지 않게 이름은 적지 않아요.

  • Predictions에 평가 지표가 안 보여요 → 창 아래의 Show performance scores를 켜요. Target이 정해지지 않았으면 Select Columns를 다시 봐요.
  • Predictions 줄 수가 12,000개예요 → 훈련 데이터가 들어간 거예요. 연결선을 더블 클릭해 Remaining Data로 바꿔요.
  • 오렌지3가 안 열려요 → 위의 「평가 지표 미리 보기」로 MAE와 R2를 익히고, 모델 A의 값으로 메모를 채워요. 실습은 다음 시간 처음에 이어서 해요.

🧩 어떤 유형으로 풀까?

예측하고자 하는 값이 숫자(연속형)인지, 정해진 범주인지, 레이블이 없는지 따져 골라요.

🌌 선택 실습 ① 은하의 종류 분류하기 (오렌지3 · Image Analytics 설치와 인터넷 필요 · 15분 이상)

이미지 데이터를 쓰려면 먼저 Options → Add-ons…에서 Image Analytics를 설치해요. 선생님이 알려 주는 폴더에서 은하 이미지 폴더(종류별 폴더 3개)를 내려받아요.

Import ImagesData → ImagesImage EmbeddingEmbeddings → DataData SamplerData Sample → DataLogistic RegressionModel → PredictorsPredictionsEvaluation ResultsConfusion MatrixSelected Data → DataImage Viewer
  1. Import Images로 은하 이미지 폴더를 열고 Image Embedding에 이어요. 이미지 임베딩은 이미지를 고정된 길이의 숫자로 바꾸는 과정으로, 이미지의 특징과 정보를 요약한 수치로 나타내요.
  2. Data Sampler에서 훈련 데이터와 테스트 데이터를 8:2로 정하고, Logistic Regression을 이어 80%의 훈련 데이터를 학습해요.
  3. Logistic Regression과 Data Sampler를 Predictions에 잇고, Data Sampler 쪽 연결선은 Remaining Data → Data로 바꿔요.
  4. Predictions에서 예측값과 실젯값을 비교하고 평가 지표 CA(Classification Accuracy, 정확도)를 봐요.
  5. Confusion Matrix(혼동 행렬)를 이어 어떤 종류를 잘 분류하고 어떤 종류를 헷갈리는지 보고, 잘못 분류한 칸을 골라 Image Viewer로 그 은하 이미지를 확인해요.

임베딩은 인터넷으로 이미지를 보내 계산하므로 시간이 걸려요. 상단 메뉴 Window에서 「Display Widgets on Top」을 켜면 위젯 창 여러 개를 함께 볼 수 있어요.

🚢 선택 실습 ② 불법 조업 의심 선박 군집화하기 (오렌지3 · Geo 설치 필요 · 15분 이상)

AIS는 GPS로 선박의 위치와 상태 정보를 자동으로 모으고 주고받는 시스템이에요. 조업 전에 AIS를 끄고 조업을 마친 뒤 다시 켜는 선박은 불법 조업을 의심할 수 있어요. Options → Add-ons…에서 Geo를 설치하고, 선생님이 알려 주는 폴더에서 ais_disabling_events.csv를 내려받아요.

FileDataSelect RowsMatching Data → DataSelect ColumnsDatak-MeansDataGeo Map
  1. File로 파일을 열고 나라를 뜻하는 flag 속성의 종류를 categorical로 바꿔요. (File 위의 ⚠️는 범주형 변수 vessel_class의 값이 많아 성능이 떨어질 수 있다는 경고예요.)
  2. Select Rows에 조건을 넣어요. 우리나라 해역 인근을 보려면 gap_end_lat(다시 켠 위도) 30~50, gap_end_lon(다시 켠 경도) 120~135, 나라를 보려면 flag를 특정 나라로 정해요. Geo Map으로 위치를 시각화해요.
  3. 대한민국 국적 선박을 고른 Select Rows에 Select Columns를 이어 gap_end_lat · gap_end_lon만 Features에 두고 나머지는 Ignored로 옮겨요.
  4. Unsupervised 카테고리의 k-Means를 잇고, Geo Map에서 군집 결과를 확인해요. 군집의 개수와 학습 횟수(Re-runs)를 바꿔 보며 결과를 비교해요.

k-평균으로 만든 군집을 관리 지역으로 정하면 불법 조업을 막는 데 도움이 될 수 있어요.

💻 선택 활동(심화) · k-평균 알고리즘 코드로 군집화하기 (코랩 · 10분)

반복 횟수를 1, 2, 3, 4로 늘려 가며 군집의 중심이 어떻게 움직이는지 그림으로 확인하는 노트북이에요. 앞부분은 따라 하고, 뒷부분 「스스로 해결하기」는 힌트를 보며 직접 완성해요.

기계학습은 데이터의 패턴을 학습해 예측한다. 무작위라 패턴이 없거나 학습할 데이터가 모자란 문제는 풀기 어렵다.
SDGs 같은 사회 문제는 문제 상황 이해 → 데이터 수집 및 전처리 → 모델 학습 → 모델 평가 순서로 풀며, 예측하려는 값에 따라 분류 · 회귀 · 군집을 고른다.
칼로리 소모량처럼 연속형 값을 예측하는 회귀 모델은 테스트 데이터로 평가하고, R2는 1에 가까울수록, MAE는 작을수록 잘 예측한 것이다.
