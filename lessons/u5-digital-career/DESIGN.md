퀴즈 12문항(정답 위치 ①4 ②4 ③4). 질문폼(info-u5-digital-career) 1번 ← 01 직업 탭·분류 게임·`roleWhy`, 2번 ← 04-1 `myJob`·`jobIot`~`jobAi`, 3번 ← 04-2·3 역량 그래프·`needPick`·`compPlan`. 접어 둔 과정·기능 활동과 선택 활동(보충·심화)은 퀴즈·질문폼이 묻지 않음. 메모 모아 보기에서 접어 둔 칸의 메모(`jobWhy`, 과정·기능, 규칙 2, 성취도 점검, 보충·심화)는 쓴 묶음만 보임.

**50분 흐름** — 도입(3분) 희망 진로 분야·처음 생각 → 01(6분) 키·몸무게 비교, 직업 탭 3개, 분류 게임 6장, `roleWhy`(9분 무렵), 수요가 줄어드는 직업은 말로 → 02(4분) 스마트폰 흐름, 카드 3장 뒤집기, 관심 직업 칩, 퀴즈 → 03(5분) 다섯 역량 카드, 분류 게임 6장, 퀴즈 → **04(18분 무렵 시작, 11분)** 말풍선 두 칸 이상(23분 무렵), 역량 슬라이더·그래프(25분 무렵), 필요한 역량과 실천 계획 `compPlan`(28분 무렵) → 05(7분) 맞춤 활동 1번과 규칙 1개, 접어 둔 활동은 시간이 되는 만큼 → 마무리(11분) 개념 정리하기·성취도 평가, 학업 계획 점검, 퀴즈, 질문폼.

**줄인 것** — 216쪽 [그림 Ⅴ-4]는 그림 대신 직업 탭의 과거 → 디지털화 문장으로. 217쪽 직업 소개는 카드로 옮기고 그림은 쓰지 않음. 218쪽 [그림 Ⅴ-5]의 말풍선은 카드 아래 작은 글로. 219쪽 스스로 해결하기의 「예」는 예시 답안이라 옮기지 않고, 말풍선에 들어갈 요소(어떤 기술이 / 무엇에 쓰여 / 무엇이 달라지는지)만 안내함. 그래프는 교과서처럼 오각형으로 새로 그림. 220쪽 맞춤 활동 1번의 「예」(축사 과거·현재)는 옮기지 않고, 이미 본 사례와 다른 사례를 찾게 함. 개념 정리하기는 새 상황 문장으로. 221쪽 보충 활동의 진로 정보 사이트 주소는 쓰지 않고 「선생님이 알려 주는 진로 정보 사이트」로.

**확인할 점**
- 과정안 1-2 전개 첫 발문이 「인간과 인공지능의 역할은 어떻게 변화하고 있을까?」로 Ⅳ단원 제목이 들어가 있음 → 교과서 216쪽 제목 「디지털 기술의 활용으로 사람의 역할은 어떻게 달라졌을까?」를 씀.
- 과정안 1-2는 216~219쪽만 다루고(2시간), 220~221쪽 단원 정리는 과정안에 없음 → 총괄 결정으로 한 차시(50분)에 함께 넣고, 맞춤 활동 1번·규칙 1개만 필수, 나머지는 접어 둠.
- 219쪽 그래프의 「예」는 예시 답안이라 옮기지 않음. 화면에는 합계/25점만 보여 줌.
- 219쪽 1번 「그림으로 표현해 보자」는 화면에서 말풍선 글로 대신함(그림 그리기 도구 없음). 손으로 그리게 하려면 교과서 칸을 함께 써도 됨.
- 216쪽 [그림 Ⅴ-4] 심판 사례의 과거 문장(「잘못된 판정을 내릴 수 있다」)은 문장 조각이 섞여 있어 PDF 배치대로 과거 칸에 둠.
- 218쪽 역량 이름은 그림에서 「컴퓨팅 사고」, 209쪽 단원 핵심 역량 목록에서는 「컴퓨팅 사고력」으로 다르게 적혀 있음 → 이 화면은 218~219쪽 표기 「컴퓨팅 사고」를 따름.
- 맞춤 활동 1번에서 「이미 본 사례와 다른 사례」를 요구해 조금 어려울 수 있음. 떠오르지 않으면 같은 사례라도 자기 말로 쓰게 할지 선생님 판단 필요.

**검토 반영(1차)** — 퀴즈 2-3을 단원 정리 문항과 겹치지 않게 급식 주문·만족도 기록 장면으로(줄기에서 「데이터」 뺌, 오답 환경 빅데이터 전문가), 2-2를 강가 수질 측정 장치 장면으로(줄기에서 「개발」 뺌), 2-1 오답을 다른 주목받는 직업으로, 3-3 오답을 컴퓨팅 사고력·디지털 문화 소양으로. 분량: 01 `shrinkJob`을 말로 하는 발문으로, 분류 게임 8→6장(「~하는 일」 꼴로 주어 통일, 길이 맞춤), 02 카드 3장만 뒤집기·`jobWhy` 접음, 03 분류 게임 6장, 04의 개념 정리하기·성취도를 마무리로 옮김, 05는 맞춤 활동 1번·규칙 1개만 필수(규칙 2·성취도 점검·보충/심화는 통째로 접음) → `compPlan`이 30분 안. 오각형 그래프 viewBox를 넓히고 overflow:visible로 좌우 레이블 잘림 해결. 슬라이더를 하나라도 움직이면 다섯 값 모두 저장. 개념 정리 빈칸 2번을 역량 이름을 나열하지 않는 상담원 장면으로. 말풍선 틀을 교과서 문형 대신 「어떤 기술이 / 무엇에 쓰여 / 무엇이 달라지는지」로.
