「모임 장소는 박물관이야.」 「주소는?」
친구가 모임 장소의 주소를 묻자 곧바로 문자로 주소를 보내 줘요. 우리는 컴퓨팅 시스템으로 멀리 있는 친구에게도 어렵지 않게 문자나 사진을 보내요. 이렇게 멀리 있는 친구와 데이터를 주고받는 방법은 무엇일까요?

오늘은 네트워크를 이루는 장치를 알아보고, 운영체제와 상황에 맞는 공유 방법을 익혀요. 클라우드로 폴더를 직접 공유해 보고, 패킷이 지나가는 가장 빠른 경로를 찾은 뒤 네트워크 단원을 정리해요.

01

네트워크를 구성하는 장치는 무엇일까?

교과서 18쪽 · 컴퓨팅 시스템의 구성과 네트워크 장치

쉽게 말하면컴퓨팅 시스템은 데스크톱 컴퓨터만 뜻하지 않아요. 스마트폰, 태블릿처럼 소프트웨어로 제어하는 모든 기계와 전자 장치, 그리고 데이터와 네트워크, 네트워크 장비까지 모두 포함하는 말이에요.

🧩 컴퓨팅 시스템의 구성과 네트워크 장치 (그림 Ⅰ-7을 다시 그림)

하드웨어는 입력 장치, 출력 장치, 중앙 처리 장치, 기억 장치, 네트워크 장치로 구성되고, 이를 제어하는 소프트웨어는 시스템 소프트웨어와 응용 소프트웨어로 구성돼요.

🪟 소프트웨어

기기의 한정된 자원을 효율적으로 관리하는 시스템 소프트웨어와, 사용자에게 편리한 작업 환경을 주는 응용 소프트웨어

🧠 중앙 처리 장치

CPU라고 불러요. 프로그램을 실행(연산)하고 각 장치를 제어하는, 컴퓨팅 시스템의 두뇌

💾 기억 장치

프로그램과 데이터를 저장해 두는 장치. 중앙 처리 장치를 위한 주기억 장치와 대용량의 보조 기억 장치로 구분

⌨️ 입출력 장치

사용자가 처리할 데이터를 입력하고 처리 결과를 출력하는 장치

💻📱컴퓨팅 시스템

🌐 네트워크 장치

유무선 통신망에서 서로 연결된 컴퓨팅 기기들과 데이터를 공유하고 전송하도록 도와주는 장치

  • 랜 카드 외부 네트워크와 제일 먼저 접속하는 장치로, 컴퓨터 본체의 확장 슬롯에 꽂아 써요.
  • 스위치 소규모 네트워크 환경에서 여러 기기를 서로 연결하고, 대용량의 패킷 처리로 효율적인 데이터 전송을 해요.
  • 라우터 경로를 결정하고 스위칭하는 장치로, 데이터 패킷이 목적지까지 갈 수 있는 길을 검사해 어떤 길이 가장 적절한지 결정해요.

🔗 장치와 역할 짝짓기

왼쪽에서 장치를 하나 고른 뒤, 오른쪽에서 알맞은 역할을 눌러요. 위 그림을 보지 않고 먼저 도전해 봐요.

02

학급 친구에게 내 데이터를 공유하려면?

교과서 19~20쪽 · 클라우드, 운영체제별 공유 설정

쉽게 말하면같은 네트워크의 컴퓨터끼리는 공유 폴더, 가까이 있는 같은 운영체제의 휴대폰끼리는 블루투스·에어드랍, 멀리 있거나 운영체제가 다르면 인터넷으로 어디서든 여는 클라우드가 편해요.

☁️ 클라우드(cloud)

지난해 체험 학습에서 찍은 사진을 지금은 다른 반이 된 친구에게 공유하려고 해요. 이럴 때는 유선 또는 무선으로 연결된 네트워크 환경과 운영체제에 따른 공유 환경을 설정해 데이터를 쉽게 보낼 수 있어요. 문자, 메신저, 클라우드 같은 공유 기능을 쓸 수 있지요.

클라우드는 인터넷을 통해 접근할 수 있는 서버에 데이터, 소프트웨어 등의 자원을 저장해 사용자가 언제 어디서든 이용할 수 있는 환경이에요.

🖥️ 개인용 컴퓨터 운영체제에서 공유 설정 (그림 Ⅰ-9 · Ⅰ-10)

🔒 학교 컴퓨터에서는 따라 하지 않아요. 설정 화면이 열리더라도 하지 않아요. 학교 네트워크의 다른 사람에게 내 폴더가 보일 수 있어요. 아래 화면 설명으로 흐름만 익혀요.

윈도

📁 체험 학습 사진 속성
일반공유보안이전 버전사용자 지정
네트워크 파일 및 폴더 공유공유(S)…고급 공유고급 공유(D)…
  1. 공유하려는 폴더의 속성 창을 열어요.
  2. [공유] 탭에서 사용자들이 이용할 수 있도록 권한을 허용해요.
  3. 친구들은 네트워크에서 내 컴퓨터를 찾아, 내 폴더를 자기 컴퓨터에 있는 폴더처럼 볼 수 있어요.

맥 OS

● ● ● 공유
파일 공유 화면 공유 공유 폴더 ＋ / －
  1. [시스템 설정] → [일반] → [공유] → [파일 공유]를 켜요.
  2. 원하는 폴더를 공유 폴더로 추가해요.
  3. 원하는 파일을 공유 폴더에 넣으면 다른 친구들과 쉽게 공유할 수 있어요.

📲 모바일 운영체제에서 공유 설정 (그림 Ⅰ-11 · Ⅰ-12)

안드로이드 · 블루투스

원하는 파일을 고른 뒤 ‘공유 - 블루투스’를 선택 → 목록에서 보낼 스마트 기기 선택 → 받는 기기에서 수락하면 파일이 전송돼요.

iOS · 에어드랍

공유할 파일을 누른 뒤 왼쪽 아래의 공유 버튼 → 에어드랍(AirDrop)을 누르면 주변 사용자와 파일을 공유할 수 있어요.

이 공유 방법들은 운영체제가 같은 경우에 쓸 수 있어요. 수업 중에는 선생님 안내가 있을 때만 직접 해 봐요.

네트워크 기술이 발달하면서 전 세계의 멀리 떨어진 친구와도 네트워크에서 소통할 수 있게 되었어요. 다양한 컴퓨팅 시스템이 네트워크에 연결되어 거리에 상관없이 파일은 물론 실시간 방송, 영상 같은 다양한 데이터를 공유할 수 있어요.

03

자료 공유 시 주의할 점

교과서 20쪽 · 지식 키우기

쉽게 말하면공유는 편리하지만, 한 번 보낸 데이터는 되돌리기 어려워요. 보내기 전에 꼭 필요한지, 안전한지, 누구까지 볼 수 있는지, 보내도 되는 것인지 확인해요.
🎯

① 필요한 것만

꼭 필요한 데이터만 친구나 주변 사람들과 공유해요.

🦠

② 악성 프로그램 검사

공유하기 전에 바이러스 같은 악성 프로그램이 들어 있는지 검사해요.

🪪

③ 개인 정보 유출 주의

여러 사람이 데이터를 함께 보게 되므로 개인 정보가 새어 나가지 않게 각별히 신경 써요.

🔑

④ 접근 권한 차등

데이터나 폴더별로 접근 권한을 다르게 주어 필요 이상으로 공유되는 것을 막아요.

©️

⑤ 저작권·불법 데이터 확인

저작권 문제가 있거나 불법 데이터는 아닌지 살펴보고, 문제가 생길 수 있으면 다른 사람에게 보내지 않아요.

🚦 이렇게 공유해도 될까?

상황을 읽고 괜찮은지, 멈추고 다시 생각해야 하는지 골라요. 해설에서 다섯 가지 중 무엇과 관련 있는지 확인해요.

04

함께 해결하기 · 네트워크 활용

교과서 21쪽 · 실습 · 분석

쉽게 말하면먼저 클라우드 서비스로 폴더를 공유해 친구들에게 링크를 안내해 봐요. 그다음 데이터(패킷)가 도시 A에서 도시 F까지 갈 때 어느 길이 가장 빠른지 직접 찾아봐요.

☁️ 1. 클라우드 서비스로 폴더 공유하기 (실습)

⏳ 로그인을 기다리는 동안에는 아래 2. 경로 찾기부터 해도 돼요.

클라우드 서비스는 서비스 제공업체가 호스팅해 인터넷에서 공유 서비스에 쉽게 접근하도록 해 주는 서비스로, 인프라·플랫폼·소프트웨어를 모두 아우르는 말이에요. 교과서처럼 구글 드라이브로 해 보고, 선생님이 다른 서비스(원 드라이브 등)를 알려 주면 그것으로 해도 돼요.

📁 연습용 새 폴더만 공유해요. 이름이 「공유 연습」 같은 새 폴더를 만들어 그 폴더만 공유해요. 개인 자료(사진, 성적, 연락처 등)가 든 폴더는 공유하지 않아요. 확인이 끝나면 공유를 해제해요.

한 단계씩 하고 체크해요

로그인할 계정은 선생님이 알려 주는 계정을 써요. 학교 계정은 학교 밖 사람과의 공유가 막혀 있을 수 있어요.

🔗 공유 링크는 이 화면에 붙여 넣지 않아요. 선생님이 정한 곳(학급 게시판 등)에 안내해요.

🛣️ 2. 패킷이 가장 빨리 도착하는 경로 찾기 (분석)

A 도시(서울)에서 출발해 F 도시(보스턴)에 도착할 때까지 데이터(패킷) 전송에 걸리는 시간(빨간 숫자)을 경로에 맞게 표에 채우고, 가장 빠른 경로를 생각해 봐요. A에서 시작해 이웃한 도시를 차례로 눌러 경로를 만들어요. 지나간 구간의 시간은 오른쪽 표에 저절로 채워져요(구간 시간은 오가는 방향이 같다고 보고 두 칸을 함께 채워요).

네트워크 정리 · 컴퓨팅 시스템과 네트워크

교과서 21~23쪽 · 맞춤 활동, 학업 성취도 점검, 선택 활동

지식·이해 1. 내가 쓰는 컴퓨팅 시스템에서 네트워크 구성 요소 찾기

지금 교실이나 집에서 찾을 수 있는 것을 모두 골라요.

과정·기능 2. 멀리 사는 친구에게 사진 앨범 공유하기 · 순서 맞추기

윈도 노트북을 쓰는 나는 방학 동안 다른 나라에 사는 펜팔 친구에게 우리 동네 사진 앨범을 보내려고 해요. 친구는 어떤 기기를 쓰는지 아직 몰라요. 과정이 뒤섞여 있어요. 첫 단계는 ②예요. 나머지를 앞뒤가 맞는 순서대로 눌러요.
