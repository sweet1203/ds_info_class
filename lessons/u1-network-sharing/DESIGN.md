퀴즈 13문항(정답 위치 ①4 ②5 ③4). 질문폼(info-u1-network-sharing) 1번 ← 01 짝짓기, 2번 ← 04 클라우드 실습 `cloudPerm`·`cloudWho`·`cloudWhy`, 3번 ← 04 경로 찾기 `routeTried`·`fastRoute`.

**50분 흐름** — 도입(3분) → 01(6분) 그림 보고 짝짓기 → 02(7분) 화면 설명으로 운영체제별 공유, 분류 게임 → 03(4분) 다섯 가지, 분류 게임 → **04(20분 무렵 시작, 14분)** 클라우드 공유 실습 8분 + 경로 찾기 6분 → 05(8분) 맞춤 활동·점검, 선택 활동은 시간이 되는 만큼 → 마무리(6분) 학업 계획 점검·질문폼.

**줄인 것** — 윈도·맥 폴더 공유는 학교 PC 관리자 권한 문제로 직접 설정하지 않고 화면 설명만(교과서 QR 설정 영상 대신). 그림 Ⅰ-8·Ⅰ-9~Ⅰ-12의 화면 캡처는 쓰지 않고 글·CSS 그림으로. 21쪽 원 드라이브·개인 클라우드는 「선생님이 알려 주면 그것으로」 한 줄로. 선택 활동(보충·심화)의 그리기는 글로 적기로 바꿈. 이 소단원 개념 정리하기 문장은 그대로 옮기지 않고 새 문장 빈칸으로(05에 둠).

**확인할 점**
- 21쪽 표는 행이 출발 도시, 열이 도착 도시인데 예시 칸이 B→A 2, C→B 1처럼 거꾸로 가는 방향도 들어 있음 → 구간 시간은 방향과 상관없이 같다고 보고, 학생이 지나간 방향의 칸을 채우게 함. 그림의 구간 시간: A–B 2, B–C 1, C–F 2, A–D 3, D–C 1, C–E 4, D–E 2, E–F 1(PDF 그림에서 읽음, 숫자 위치가 선 사이라 C–F 2와 D–C 1은 한 번 더 확인 필요).
- 22쪽 순서 문제에서 ①(운영체제 확인)과 ②(공유 방법 찾기)는 어느 쪽을 먼저 해도 말이 됨 → 화면에서는 교과서 문장을 옮기지 않은 새 상황으로 바꾸고, 정답 하나로 채점하지 않고 앞뒤 조건만 점검(새 상황에서도 ①·④의 앞뒤는 자유).
- 20쪽 지식 키우기 ③ 「모든 데이터를 여러 사람이 공유하므로」는 문장이 어색 → 「여러 사람이 데이터를 함께 보게 되므로」로 풀어 씀.
- 20쪽 「공유 방법들은 운영체제가 같은 경우에만 가능해요」 → 극단어를 피해 「운영체제가 같은 경우에 쓸 수 있어요」로 씀.
- 18쪽 랜 카드 「컴퓨터 본체의 확장 슬롯에 꽂아 사용」은 데스크톱 기준(노트북·휴대폰은 내장). 교과서대로 둠.
- 21쪽 실습은 교과서대로 구글 아이디·구글 드라이브를 씀. 로그인 계정(학교 계정/개인 계정)과 공유 범위 제한은 선생님이 정해 안내해야 함. 공유 링크는 메모 칸에 붙여 넣지 말라고 안내함(진도 현황판으로 전송되므로).

**검토 반영(2차)** — 04 클라우드 실습 맨 위에 「로그인을 기다리는 동안에는 2. 경로 찾기부터」 한 줄(질문폼 3번 근거가 30분 안에 닿도록). 퀴즈 6-2 문두를 「…관리하는 것은?」으로(오답 랜 카드와 맞게), 6-3 보기를 「~를 가리키는 말이다」로 길이와 뜻을 맞춤. 퀴즈 2-3 해설에 「인터넷 없이 가까운 기기끼리」, 1-1 해설은 교과서 표현(외부 네트워크와 제일 먼저 접속하는 장치)으로. `cloudWho`에 「우리 학교 계정 사용자」 추가. 경로 찾기에서 F에 닿지 않은 만들던 경로도 이 기기에 저장해(메모 전송 없음) 새로 고침 뒤 복원.
