퀴즈 13문항(정답 위치 ①4 ②5 ③4). 질문폼(info-u5-info-security) 1번 ← 01 원칙 분류·`ruleBreak`, 2번 ← 03 사례(`casePick`·`caseWhy`)·04 기술 분류(`techPick`·`techWhy`), 3번 ← 05 실천 점수(`userScore`·`weakPlan`). 06 전체(접어 둠)와 비밀번호 점검기는 퀴즈·질문폼이 묻지 않음.

**50분 흐름** — 도입(3분) 처음 짐작 → 01(5분, 3~8분) 정의·원칙 그림, 분류 6장, `ruleBreak` 한 줄 → 02(5분, 8~13분) 위협 요소 훑기, 카드 뒤집기, 스마트폰 다시 보기 한 줄 → **03(5분, 13~18분)** 사례 탭 4개, 하나 골라 `caseWhy` → **04(5분, 18~23분)** 기술 3가지·방화벽 그림 2분, 사례에 기술 연결 메모 2분, 분류 4장·퀴즈 1분 → **05(9분, 23~32분)** 공급자·사용자 뜻 1분, 별점과 `weakPlan` 4분(27분 무렵 끝), 공급자 수칙 1분, 성취도 평가·개념 정리·퀴즈 3분 → 06(1분) 안내만 읽고 넘어감 → 마무리(7분, 33~40분) 핵심 질문 답·퀴즈·질문폼 → 남는 10분 안팎은 비밀번호 점검기, 06 맞춤 활동(모둠), 선택 활동 순으로. 못 한 06은 과제. 질문폼 근거 활동(01·03·04·05)은 모두 27분 무렵까지 끝남.

**선생님 준비물** — 없음(06 맞춤 활동 1번에서 사례를 직접 찾는 모둠이 있으면 「선생님이 알려 주는 사이트」를 알려 주기). 학생이 실제 기기 설정을 바꾸거나 실제 비밀번호를 입력하지 않도록 수업 시작 때 한 번 안내.

**줄인 것** — 228쪽 도입 그림·원칙 그림은 문장과 인라인 SVG로, 229쪽 사례 그림은 글 탭으로, 230쪽 방화벽 그림은 HTML 상자로 다시 그림(교과서 그림 파일은 쓰지 않음). 229쪽 사례 글은 사실(연도, 단지·세대 수, 피해 금액)을 그대로 두고 문장만 쉽게 풀어 씀. 231쪽 개념 정리하기와 232쪽 학업 성취도 점검 기준은 새 문장으로. 232쪽 맞춤 활동 2번의 「예」 문장은 옮기지 않고 다른 실마리 질문을 둠. 233쪽 보충 목록은 같은 낱말 목록을 쓰지 않고 새 생활 정보 카드로.

**확인할 점**
- 과정안(plan_Ⅴ-2) 2-2 표 머리에 「1-2. 디지털 사회의 진로」의 학습 목표·성취기준이 잘못 들어가 있음 → 교과서 228쪽 학습 목표를 씀. 과정안 지도상의 유의점에 나오는 「좀비 PC」는 교과서 본문에 없는 용어라 화면에는 쓰지 않고, 229쪽 Tip 문장(악성 코드가 다른 기기를 공격하는 도구로 활용됨)으로만 다룸.
- 228쪽 정보 보안 정의는 「생성, 처리, 저장, 전송 등의 전 과정」, 231쪽 개념 정리하기는 「생성, 처리, 저장, 전송, 출력 등의 전 과정」으로 「출력」이 한쪽에만 있음 → 화면은 228쪽 본문을 따름.
- 229쪽 사례 3(디도스 공격)은 디도스로 장애를 일으킨 뒤 침입해 고객 정보를 빼낸 사건인데, 옆 피해 칸은 「스마트폰이 디도스에 이용되면 인터넷망 마비, 국가 주요 기관망 마비」로 사례 내용과 결이 조금 다름 → 교과서대로 사례 글과 피해 글을 나란히 둠.
- 229쪽 파밍 풀이의 「URL」은 화면에서 「사이트의 주소」로 풀어 씀.
- 231쪽 비밀번호 수칙의 「세 가지 종류 이상의 문자」는 종류를 밝히지 않음 → 점검기는 영문 대문자, 영문 소문자, 숫자, 특수 문자 가운데 세 종류로 풀어 씀. 「다른 사람이 쉽게 알 수 없도록」은 흔한 낱말, 자판·순서대로 이어지는 글자, 같은 글자 세 번 반복, 여섯 자리 넘는 숫자를 잡는 방식으로 풀어 씀(교과서에 없는 세부 기준이라 퀴즈·질문폼에서 묻지 않음). 「고유한」은 점검할 수 없다고 화면에 밝힘.
- 233쪽 심화 「앱 사용 권한을 확인한 후 불필요한 권한을 찾아 제거해 보자」 → 수업 중 실제 기기 설정을 바꾸지 않는다는 제작 지침에 따라 가상 앱 3개 권한 점검 체험과 확인 경로(226쪽과 같은 「설정 → 애플리케이션 / 설정 → 개인 정보 보호 및 보안」)만 보여 줌.
- 233쪽 보충 목록에 224쪽 보호 목록에 없던 「영상」이 들어 있음(과정안 유의점에도 「금융, 군사, 위치, 의료, 영상」) → 얼굴이 담긴 CCTV 영상을 보호할 정보 카드로 씀.
- 230쪽 「생체 신호 인증 기술」을 전자 서명 방법으로 설명함 → 분류 게임에서 지문으로 본인 확인하고 결제하는 장면을 전자 서명으로 둠.

**검토 반영(1차)**
- 분량 줄임: 02 악성 코드 분류 게임 삭제(카드 뒤집기만), `symptomWhy` 한 줄로. 04는 기술 연결 메모를 기술 카드 바로 아래로, 분류는 4장으로 줄여 뒤로, 「정보 공급자와 정보 사용자」 카드는 05 머리로. 05는 별점·`weakPlan`을 위로, 공급자 수칙을 그 아래로, 비밀번호 점검기는 「시간 되면」으로 접음. 06은 맞춤 활동·학업 성취도 점검·선택 활동 전체를 「시간 되면·과제」로 접고, `fitCase`·`fitName`을 없애 03의 `casePick`·`caseWhy`를 이어 쓰게 함.
- 퀴즈 16→13문항: 1-1·2-2·4-2·7-1 삭제, 4-3(소스 코드)은 내용이 05로 옮겨 가 05로 옮기고 04에 암호화 상황 문항 추가. 5-2는 계정별 열람 범위 상황형으로, 7-2는 「단 한 명의 부주의가 위험한 까닭」으로, 5-1 겹치는 오답 교체, 3-1 오답에서 파밍을 빼고 정답 위치를 옮김, 7-3은 모둠 파일 사례형으로.
- 개념 정리 빈칸: 순서를 섞고 해킹·악성 코드를 따로, 모든 문장을 한 장면 문장으로.
- 비밀번호 점검기: 「이름, 생일, 학번은 알아채지 못해요」와 「영문, 숫자, 특수 문자로」 안내, 19xx·20xx 연도 패턴 추가, 낱말 목록에서 love 삭제, 판정 문구를 「세 번 이상」「여섯 개 이상」으로 맞춤.
- 별점: 같은 별을 다시 누르면 지움, 가장 낮은 항목은 6개 모두 매긴 뒤에만 안내.
- 04 분류 카드의 같은 구절 반복을 없애고, 지문 결제 카드 해설에 「교과서는 생체 신호 인증 기술을 전자 서명 방법으로 소개해요」. 07 key3 첫 문장을 228쪽 정의 그대로가 아니게 풀어 씀.
